Datapipe is a powerful, open-source streaming ETL framework developed in Rust with convenient Python bindings. It empowers data engineers to seamlessly transport billions of events daily across various platforms, including Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework boasts over 40 pre-built source and sink connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles to highly optimized Rust code. This solution is ideal for mid-sized data teams, typically with 5 to 50 engineers, who process more than a billion events daily and seek to streamline their current, often fragmented, data pipeline infrastructure. Installation is straightforward using pip; simply run `pip install datapipe-core`, or `pip install datapipe[all]` for the complete suite of connectors.
