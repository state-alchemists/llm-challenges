Datapipe is an open-source streaming ETL framework written in Rust with Python bindings designed to seamlessly move billions of events per day between Kafka, S3, Postgres, and ClickHouse. It eliminates the need for writing custom connector code by offering over forty pre-built source and sink connectors alongside a declarative transformation DSL that compiles to highly optimized Rust. This powerful tool is tailor-made for mid-size data teams of five to fifty engineers managing high-volume event streams who want to replace a patchwork of Airflow, Flink, and bespoke Python jobs. Datapipe also ensures reliable data pipelines by supporting exactly-once delivery semantics via two-phase commit protocols. To get started, you can easily install the core package using the Python package manager by running pip install datapipe-core. For teams requiring the complete set of connectors, installing datapipe with the all option will set up the entire suite.
