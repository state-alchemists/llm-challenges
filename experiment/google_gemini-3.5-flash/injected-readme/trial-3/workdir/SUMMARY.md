Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that enables efficient data movement without custom connector code. Built with data engineers in mind, it allows teams to reliably move billions of events per day across Kafka, S3, Postgres, and ClickHouse. The platform ships with over forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to highly optimized Rust code. It is designed specifically for mid-size data teams of five to fifty engineers managing massive event volumes who are looking to simplify their existing patchwork of Airflow, Flink, and bespoke Python jobs. To get started, you can easily install the core package using the standard pip install command for datapipe-core. For teams requiring the full suite of connectors, installing datapipe with the optional all bracket is also supported.
