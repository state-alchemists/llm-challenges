The LLM Challenges project provides a benchmark suite designed to evaluate how well large language model-driven coding agents perform on realistic software engineering tasks. It's intended for researchers and developers interested in assessing and comparing the capabilities of various LLMs through a standardized set of challenges. Each challenge includes instructions, scaffolding files, and a validator to ensure consistent evaluation. The suite uses the `zrb` framework and `zrb-llm-evaluator` test runner to automate the process, recording detailed logs and results for analysis. To get started, users must install `zrb-llm-evaluator` via `pipx` or `poetry`, ensure `zrb` is on their PATH with API keys configured, and then run the evaluation suite using provided `zrb-llm-evaluator run` commands. Results are outputted into an `experiment/` directory, including a human-readable `report.md`.
