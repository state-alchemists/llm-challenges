Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, built for data engineers who need to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. It comes with over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles down to optimized Rust code. The tool is aimed at mid-sized data teams managing event volumes in the billions per day and looking to replace patchworks of Airflow, Flink, and custom Python jobs. Getting started is simple: just run `pip install datapipe-core`, or install `datapipe[all]` for the full connector pack. Datapipe is open-sourced under the MIT license.
