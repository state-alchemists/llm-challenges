Datapipe is an open-source streaming ETL framework built in Rust and accessible through Python bindings, built to help data teams move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without hand-writing connector code. It comes with more than forty pre-built connectors, guarantees exactly-once delivery with two-phase commit, and offers a declarative transformation language that compiles down to fast Rust. Datapipe is made for mid-sized data teams of five to fifty engineers that are juggling high event volumes and tired of stitching together Airflow, Flink, and one-off Python scripts. Getting started is simple: just run pip install datapipe-core, or choose datapipe[all] if you want the complete set of connectors. Whether you are building real-time pipelines or modernizing a fragmented data stack, Datapipe gives you the speed and reliability of Rust with the familiarity of Python. It cuts boilerplate, reduces operational overhead, and lets your team focus on the data instead of the plumbing.
