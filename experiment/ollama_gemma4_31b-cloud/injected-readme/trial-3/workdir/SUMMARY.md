Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for high-performance data movement. It allows data engineers to seamlessly shift billions of events daily between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors and ensures exactly-once delivery through a two-phase commit system. Its declarative transformation DSL compiles directly to optimized Rust for maximum efficiency. This tool is ideal for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow and Flink. To get started, simply install the core package using pip install datapipe-core.
