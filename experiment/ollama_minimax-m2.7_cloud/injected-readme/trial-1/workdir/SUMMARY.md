Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data platforms out of the box. Datapipe guarantees exactly-once delivery using a two-phase commit protocol, ensuring data integrity even in distributed environments. Its declarative transformation DSL compiles to optimized Rust, giving high performance without requiring engineers to write low-level code. Installation is straightforward via pip, with a lightweight core package or a full connector pack available. The project targets mid-sized data teams of five to fifty engineers processing over one billion events daily, who currently juggle a mix of Airflow, Flink, and custom Python jobs, and is licensed under the MIT license.
