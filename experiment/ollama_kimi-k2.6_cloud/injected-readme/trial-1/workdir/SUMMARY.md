Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, built for data engineers who need to reliably move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It comes with over 40 pre-built connectors so you don't have to write custom integration code, and it guarantees exactly-once delivery through two-phase commit semantics. Transformations are written in a simple declarative DSL that compiles down to optimized Rust for high throughput and low latency. Datapipe is designed for mid-size data teams of five to fifty engineers who are currently juggling a mix of Airflow, Flink, and bespoke Python scripts at scale. Installing the core package is as easy as running pip install datapipe-core, while teams who want the full suite of connectors can install datapipe with the all extra. If you are processing more than a billion events per day and want a simpler, faster alternative to patchwork data infrastructure, Datapipe is built for you.
