Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it easy to connect to the most common data infrastructure out of the box. The framework provides exactly-once delivery semantics using two-phase commit, ensuring data integrity even in distributed environments. A declarative transformation DSL compiles to optimized Rust, giving teams a productive way to define data transformations without sacrificing performance. Datapipe is aimed at mid-sized data teams of five to fifty engineers handling event volumes in the billions per day, who currently maintain a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a core package available as `pip install datapipe-core` or the full connector pack with `pip install datapipe[all]`. The project is open-source under the MIT license.
