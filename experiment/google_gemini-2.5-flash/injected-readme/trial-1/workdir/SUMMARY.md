Datapipe is an open-source streaming ETL framework, built in Rust with Python support, designed for data engineers. It efficiently moves billions of events daily across various data sources like Kafka, S3, Postgres, and ClickHouse without requiring custom connector development. The framework offers over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and includes a declarative transformation language for optimized data processing. Installation is straightforward with `pip install datapipe-core`, with an option for `datapipe[all]` to access the full connector suite. It targets mid-size data teams handling large event volumes who seek to streamline their data pipelines and reduce reliance on fragmented systems.
