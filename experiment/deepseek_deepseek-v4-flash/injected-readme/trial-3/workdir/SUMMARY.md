Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to pipe billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over forty pre-built source and sink connectors, so teams can stop writing custom integration code and start moving data on day one. Datapipe guarantees exactly-once delivery through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for performance at scale. Installation is straightforward — just run pip install datapipe-core for the core package, or pip install datapipe[all] for the full connector pack. The framework targets mid-size data teams of five to fifty engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs to keep up with event volumes exceeding one billion per day. Datapipe is released under the MIT license and is free to use, modify, and deploy.
