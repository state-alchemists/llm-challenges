Datapipe is an open-source streaming ETL framework written in Rust with Python bindings designed to simplify high-throughput data movement. It allows data engineers to seamlessly transfer billions of events per day between Kafka, S3, Postgres, and ClickHouse without the need to write complex, custom connector code. The platform features over forty pre-built source and sink connectors, exactly-once delivery guarantees using two-phase commit, and a powerful declarative transformation language that compiles to high-performance Rust. This solution is specifically built for mid-size data teams of five to fifty engineers who manage massive event streams and are tired of maintaining fragmented networks of Airflow, Flink, and custom Python scripts. By consolidating these tools, teams can significantly reduce operational overhead and ensure robust, high-performance data pipelines. Getting started is as simple as running pip install datapipe-core, or installing datapipe with the all option to unlock the complete set of connector packs.
