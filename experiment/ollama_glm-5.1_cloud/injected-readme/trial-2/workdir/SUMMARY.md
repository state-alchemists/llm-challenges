Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high performance. The project targets mid-size data teams of 5 to 50 engineers who are handling event volumes in the billions per day and currently rely on a patchwork of tools like Airflow, Flink, and one-off Python jobs. Getting started is straightforward: install the core library with pip install datapipe-core, or add datapipe[all] for the full connector pack. Datapipe is released under the MIT license.
