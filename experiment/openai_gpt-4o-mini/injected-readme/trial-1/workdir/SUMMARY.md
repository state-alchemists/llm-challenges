Datapipe is an open-source streaming ETL framework built using Rust with Python bindings. It empowers data engineers to efficiently transfer billions of events daily among Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery through a two-phase commit mechanism and features a declarative transformation DSL that translates into optimized Rust. Ideal for mid-sized data teams of 5 to 50 engineers handling over a billion events per day, it serves organizations that currently rely on a mix of Airflow, Flink, and custom Python jobs. Installation is simple: running `pip install datapipe-core` will set up the basics, while `datapipe[all]` provides the complete connector pack.
