Datapipe is a powerful open-source streaming ETL framework designed to move billions of data events daily. Built with Rust and featuring Python bindings, it enables seamless high-performance connections between Kafka, S3, Postgres, and ClickHouse without requiring any custom connector code. The framework comes equipped with over forty pre-built connectors, exactly-once delivery semantics, and a declarative transformation language that compiles to highly optimized Rust code. It is designed specifically for mid-size data teams of five to fifty engineers who currently manage a complex patchwork of Airflow, Flink, and custom Python jobs. You can quickly get started by installing the core library through pip install datapipe-core. For teams requiring the complete set of connectors, installing datapipe with the all option will provide the full suite of integration tools.
