Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that enables seamless, high-volume data movement. It is designed specifically for mid-size data teams and data engineers who manage over a billion events per day across platforms like Kafka, S3, Postgres, and ClickHouse. By using Datapipe, organizations can replace their complex and fragile patchwork of Airflow, Flink, and bespoke Python jobs with a single robust solution. The framework delivers over forty pre-built source and sink connectors alongside a declarative transformation language that compiles to highly optimized Rust. Additionally, it guarantees data integrity during transit by providing exactly-once delivery semantics through two-phase commit protocols. Getting started is straightforward, as users can install the core framework directly using Python's package manager with the pip install datapipe-core command. For teams requiring the complete set of connectors, installing the package with the all option provides the full connector pack immediately.
