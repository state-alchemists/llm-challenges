Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, so teams can connect popular data platforms out of the box rather than building integrations from scratch. The framework provides exactly-once delivery semantics using a two-phase commit protocol, which is critical for data pipelines where duplicate events could cause downstream errors. A declarative transformation DSL compiles to optimized Rust, giving engineers a productive way to express data transformations while still getting Rust-level performance. Installation is straightforward via pip, with a core package available as `datapipe-core` and a full connector pack available as `datapipe[all]`. The primary audience is mid-size data teams of 5 to 50 engineers handling event volumes in the billions-per-day range, typically those replacing a patchwork of tools like Airflow, Flink, and custom Python jobs with a unified streaming solution.
