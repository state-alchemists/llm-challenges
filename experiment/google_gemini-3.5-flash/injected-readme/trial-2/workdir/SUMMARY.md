Datapipe is an open-source streaming ETL framework written in Rust with Python bindings designed to simplify complex data pipelines. It allows data engineers to seamlessly move billions of events per day between Kafka, S3, Postgres, and ClickHouse without the hassle of writing custom connector code. Out of the box, the framework ships with more than forty pre-built source and sink connectors, robust exactly-once delivery semantics, and a declarative transformation language that compiles directly to optimized Rust. This powerful tool is tailor-made for mid-size data teams of five to fifty engineers managing massive event volumes who are currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Setting up Datapipe is extremely straightforward, as you can get started by installing datapipe-core via pip. For teams needing the complete set of integration options, installing datapipe with the all extras package provides everything required to build scalable and reliable stream pipelines.
