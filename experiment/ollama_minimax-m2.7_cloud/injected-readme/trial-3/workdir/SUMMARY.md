Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, handles exactly-once delivery semantics using a two-phase commit protocol, and includes a declarative transformation DSL that compiles to optimized Rust for high performance. The target audience is mid-size data teams of 5 to 50 engineers running event volumes in the billions per day who currently rely on a patchwork of tools such as Airflow, Flink, and bespoke Python jobs. Installation is straightforward via pip, with a core package available as `datapipe-core` and a full connector pack available as `datapipe[all]`. Datapipe is distributed under the MIT license.
