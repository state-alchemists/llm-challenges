Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers managing large-scale event processing. It enables the movement of billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without custom connector development. The framework offers over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language compiling to optimized Rust. It targets mid-size data teams (5-50 engineers) handling over a billion events per day, particularly those currently relying on disparate Airflow, Flink, and Python solutions. To install, simply run `pip install datapipe-core`, or `pip install datapipe[all]` for the complete connector suite.
