Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The framework targets mid-size data teams of 5 to 50 engineers handling 1B+ daily events who currently rely on a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or use datapipe[all] for the full connector pack. Datapipe replaces fragile, hand-maintained pipelines with a single declarative framework, letting teams focus on data logic rather than infrastructure. The project is released under the MIT license.
