Datapipe is an open-source streaming ETL framework built with Rust and Python bindings, designed for high-performance data movement. It enables data engineers to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles to optimized Rust. It is specifically built for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke Python scripts. To get started, simply install the core package using pip install datapipe-core. For teams requiring the full suite of connectors, the complete pack is available via pip install datapipe[all].
