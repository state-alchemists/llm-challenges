Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect to common data infrastructure out of the box rather than building integrations from scratch. The framework provides exactly-once delivery semantics using a two-phase commit protocol, ensuring data reliability even in distributed environments. Its declarative transformation DSL compiles to optimized Rust, giving users the simplicity of a Python-friendly interface with the performance of a compiled systems language. Installation is straightforward via pip, with a core package available as `datapipe-core` or a full connector pack via `datapipe[all]`. Datapipe targets mid-size data teams of five to fifty engineers processing over one billion events daily who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs.
