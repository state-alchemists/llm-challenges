Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is aimed at mid-size data teams of 5 to 50 engineers handling event volumes in the billion-per-day range who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. Datapipe replaces fragmented pipelines with a single, declarative system that delivers production-grade reliability without the glue code. It is licensed under MIT.
