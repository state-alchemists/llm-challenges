Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect to their existing infrastructure immediately rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in failure scenarios across distributed systems. A declarative transformation DSL lets engineers define data transformations that compile to optimized Rust, combining the productivity of a Python-based workflow with the performance of a compiled language. The target audience is mid-sized data teams of 5 to 50 engineers handling event volumes in the billions per day, who are currently managing a patchwork of tools like Airflow, Flink, and custom Python jobs. To install the core package, run `pip install datapipe-core`; for the full set of connectors, use `pip install datapipe[all]`.
