Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that enables high-throughput data pipelines. It is specifically designed for mid-size data teams of five to fifty engineers who handle massive event volumes of over one billion events per day. By replacing complex patchwork systems like Airflow, Flink, and custom Python scripts, it provides a unified, reliable alternative. The framework ships with over forty pre-built source and sink connectors, exactly-once delivery semantics, and an optimized, high-performance transformation language. Data engineers can easily move events between Kafka, S3, Postgres, and ClickHouse without having to write custom connector code. Getting started is simple, as you can install the core framework using the standard python package manager command, pip install datapipe-core. For users who require the full integration capabilities, the entire connector pack is also available by installing datapipe with the all extras option.
