Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It is tailored for data engineers who need to efficiently transfer billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The framework includes over 40 pre-built source and sink connectors and guarantees exactly-once delivery semantics using a two-phase commit mechanism. It also features a powerful declarative transformation DSL that compiles to optimized Rust, ensuring high performance. Ideal for mid-sized data teams of 5-50 engineers processing over 1 billion events per day, Datapipe simplifies the management of complex data workflows that often rely on a mix of Airflow, Flink, and custom solutions. Installation is straightforward with the command: `pip install datapipe-core`, or for the full connector suite, use `pip install datapipe[all]`.
