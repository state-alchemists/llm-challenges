Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It enables data engineers to transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles to optimized Rust. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow and Flink. To get started, simply install the core library using pip install datapipe-core. For users requiring the full suite of connectors, the datapipe[all] package is available.
