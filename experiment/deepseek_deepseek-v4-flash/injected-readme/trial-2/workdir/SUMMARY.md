Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is built for data engineers who move billions of events a day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than forty pre-built source and sink connectors, offers exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles to optimized Rust. It is designed for mid-size data teams of five to fifty engineers handling event volumes above one billion events per day, particularly teams that currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installing is straightforward: run pip install datapipe-core, and add the datapipe[all] extra to get the full connector pack. Datapipe is MIT-licensed and free to use.
