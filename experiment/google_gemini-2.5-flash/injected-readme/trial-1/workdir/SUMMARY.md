Datapipe is a powerful open-source streaming ETL framework, built with Rust for performance and offering Python bindings for ease of use. It enables data engineers to efficiently move massive volumes of events—billions daily—across popular data stores like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework comes equipped with over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles to highly optimized Rust code. Datapipe is specifically designed for mid-sized data teams, typically 5-50 engineers, who manage over a billion events per day and are looking to streamline complex data pipelines currently handled by disparate systems like Airflow or Flink. Installation is straightforward via `pip install datapipe-core`, with an `[all]` option for the full connector suite.
