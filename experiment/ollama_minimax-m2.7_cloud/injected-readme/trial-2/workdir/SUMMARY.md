Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, making it easy to connect to the most common data infrastructure out of the box. The framework provides exactly-once delivery semantics using a two-phase commit approach, ensuring data reliability even in distributed systems. A declarative transformation DSL compiles to optimized Rust, giving engineers a productive way to define data transformations while still getting native performance. Installation is straightforward via pip, with a lightweight core package or a full connector pack available depending on your needs. Datapipe targets mid-sized data teams of five to fifty engineers handling event volumes in the billions per day, replacing the complexity of maintaining separate tools like Airflow, Flink, and custom Python jobs with a unified solution.
