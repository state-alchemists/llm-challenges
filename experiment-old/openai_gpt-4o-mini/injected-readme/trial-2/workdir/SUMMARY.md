Datapipe is an open-source streaming ETL framework designed for data engineers to efficiently move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The framework offers over 40 pre-built source and sink connectors, ensuring reliability through exactly-once delivery semantics using two-phase commit. With a declarative transformation DSL that compiles to optimized Rust, Datapipe streamlines complex data workflows. It is particularly suited for mid-sized data teams of 5 to 50 engineers managing event volumes exceeding 1 billion per day, transitioning from inefficient systems like Airflow and bespoke Python jobs. Installation is straightforward with the command `pip install datapipe-core`, or for the complete connector pack, use `pip install datapipe[all]`. Overall, Datapipe enhances data reliability and operational efficiency for modern data architectures.
