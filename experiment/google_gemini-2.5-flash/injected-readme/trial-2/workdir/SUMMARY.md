Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to streamline data movement for large-scale operations. It enables data engineers to efficiently transfer billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector development. The framework offers over 40 pre-built source/sink connectors, ensuring exactly-once delivery through two-phase commit, and a declarative transformation language that compiles to optimized Rust. It is ideally suited for mid-size data teams, typically 5-50 engineers, who handle event volumes exceeding 1 billion per day and are looking to consolidate their existing data pipelines from disparate systems like Airflow, Flink, and bespoke Python scripts. Installation is straightforward: simply run `pip install datapipe-core`, or `pip install datapipe[all]` to include the complete suite of connectors.
