Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed to effortlessly move billions of events daily. It offers over 40 pre-built connectors for popular data platforms like Kafka, S3, Postgres, and ClickHouse, ensuring exactly-once delivery without the need for custom code. Data engineers in mid-sized teams, typically managing over a billion events per day, will find Datapipe ideal for simplifying complex data pipelines currently reliant on a mix of Airflow, Flink, and bespoke Python solutions. Its declarative transformation language compiles to optimized Rust, providing high performance. Installation is straightforward: simply use `pip install datapipe-core`, or `datapipe[all]` for the complete connector suite. This framework aims to streamline data operations and reduce the maintenance overhead for busy data teams.
