Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. The target audience is mid-size data teams of 5 to 50 engineers processing one billion or more events daily who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward: users can install the core package with `pip install datapipe-core` or get the full connector pack with `pip install datapipe[all]`. The project is open source and released under the MIT license.
