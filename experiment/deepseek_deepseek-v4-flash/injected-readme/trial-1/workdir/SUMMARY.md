Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It helps data engineers move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than 40 pre-built source and sink connectors, offers exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. It is designed for mid-size data teams of roughly 5 to 50 engineers handling event volumes above one billion events per day, especially those currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command, pip install datapipe-core, with datapipe[all] available for the full connector pack. Datapipe is released under the MIT license.
