Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers moving billions of events per day between Kafka, S3, Postgres, and ClickHouse. It replaces the patchwork of Airflow, Flink, and custom Python jobs that mid-size data teams typically maintain, offering 40+ pre-built source and sink connectors out of the box. The framework guarantees exactly-once delivery through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for performance. Installation is straightforward via pip — pip install datapipe-core for the core package, or pip install datapipe[all] for the full connector pack. It targets data teams of 5-50 engineers operating at event volumes exceeding one billion per day. Datapipe is released under the MIT license.
