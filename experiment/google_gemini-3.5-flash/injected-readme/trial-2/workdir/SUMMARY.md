Datapipe is an open-source streaming ETL framework written in Rust with Python bindings designed to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse. It eliminates the need for writing custom connector code by offering over forty pre-built source and sink connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles to highly optimized Rust. This powerful tool is tailor-made for data engineers and mid-sized data teams of five to fifty engineers managing massive event volumes. It is particularly well-suited for teams currently struggling to maintain a fragmented patchwork of Airflow, Flink, and bespoke Python jobs. To get started, you can easily install the core package by running pip install datapipe-core. For those needing the full suite of connectors, the complete package is available by installing datapipe with all options.
