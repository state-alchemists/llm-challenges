Datapipe is an open-source streaming ETL framework designed for data engineers to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. It includes 40+ pre-built source and sink connectors, ensures exactly-once delivery semantics through a two-phase commit process, and features a declarative transformation DSL that compiles to optimized Rust. This framework primarily serves mid-sized data teams of 5 to 50 engineers managing over 1 billion events per day, looking to simplify their current data pipelines that may involve tools like Airflow and Flink. To install Datapipe, run the command 'pip install datapipe-core'. For accessing the full suite of connectors, use 'pip install datapipe[all]'. Datapipe is licensed under the MIT license.
