Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It is designed for data engineers who need to transfer billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. By providing over 40 pre-built connectors and a declarative transformation DSL, it eliminates the need for custom connector code. The framework is ideal for mid-size data teams who want to replace fragmented pipelines with a unified, optimized solution. It ensures reliability through exactly-once delivery semantics via a two-phase commit. Getting started is simple by installing the core package via pip. For full functionality, users can install the complete connector pack.
