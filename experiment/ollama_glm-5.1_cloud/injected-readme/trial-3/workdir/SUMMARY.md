Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of five to fifty engineers handling event volumes in the billions per day who are currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward: install the core package with pip install datapipe-core, or add the full connector pack with pip install datapipe[all] for access to every built-in connector.
