Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for moving billions of events per day across Kafka, S3, Postgres, and ClickHouse. It eliminates the need for custom connector code by shipping with over forty pre-built source and sink connectors out of the box. Exactly-once delivery semantics, powered by two-phase commit, ensure data integrity at any throughput. A declarative transformation DSL compiles directly to optimized Rust, so teams get expressive pipeline definitions without sacrificing performance. Datapipe is designed for mid-size data teams managing a billion or more events daily who want to retire patchwork stacks of Airflow, Flink, and ad-hoc Python scripts. Getting started is straightforward—install the core package via pip, then add the full connector pack when you need broader integrations. The project is MIT-licensed and ready for production use.
