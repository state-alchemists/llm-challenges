Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that helps data engineers move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The project is built for mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus range who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward: install the core package with pip install datapipe-core, or add datapipe[all] for the full connector pack. Datapipe is released under the MIT license.
