Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed to seamlessly move billions of events every day without the need for custom connector code. It is built specifically for mid-sized data teams of five to fifty engineers managing massive event volumes who are tired of maintaining a fragile patchwork of Airflow, Flink, and custom Python scripts. The framework comes equipped with over forty pre-built source and sink connectors, enabling reliable integration between Kafka, S3, Postgres, and ClickHouse out of the box. By leveraging a declarative transformation language that compiles to highly optimized Rust, it delivers outstanding performance alongside exactly-once delivery semantics via two-phase commit. Setting up the framework is incredibly straightforward, requiring only a simple installation of datapipe-core using pip. For teams requiring the complete integration pack, installing datapipe with the all option ensures all forty-plus pre-built connectors are immediately available.
