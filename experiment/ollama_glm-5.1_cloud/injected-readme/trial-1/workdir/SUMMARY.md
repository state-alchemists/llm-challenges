Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework targets mid-size data teams of 5 to 50 engineers handling event volumes upwards of a billion events per day, who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or pull in the full connector pack with datapipe[all] if you need the complete set of integrations. Datapipe is released under the MIT license.
