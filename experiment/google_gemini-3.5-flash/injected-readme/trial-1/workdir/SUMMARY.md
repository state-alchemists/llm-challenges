Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that enables seamless data movement without custom connector code. It is specifically designed to handle billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. This powerful tool is perfect for mid-size data teams of five to fifty engineers who want to replace their complex patchwork of Airflow, Flink, and custom Python scripts with a single unified solution. Datapipe simplifies workflows by offering over forty pre-built source and sink connectors, exactly-once delivery guarantees through two-phase commit, and a declarative transformation language that compiles to highly optimized Rust code. Setting up the framework is straightforward, requiring only a simple command to install the core package using the Python package manager. For teams that require the complete suite of connectors, the full package can be easily installed with all optional dependencies included.
