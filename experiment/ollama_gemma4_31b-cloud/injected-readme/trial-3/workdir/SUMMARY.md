Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It allows data engineers to seamlessly transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse. The platform features over 40 pre-built connectors and ensures reliability through exactly-once delivery semantics. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified solution. Users can get started quickly by installing the core package via pip. For those needing the full suite of connectors, the extended installation option is available.
