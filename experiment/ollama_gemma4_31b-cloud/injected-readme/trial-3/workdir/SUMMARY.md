Datapipe is an open-source streaming ETL framework built with Rust and Python bindings for high-performance data movement. It enables data engineers to seamlessly transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse using over 40 pre-built connectors. The platform ensures reliability with exactly-once delivery semantics and an optimized transformation DSL. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified system. Getting started is simple by running pip install datapipe-core. For those needing the complete suite of connectors, the full pack is available via pip install datapipe[all].
