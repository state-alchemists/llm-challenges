Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to handle billions of events per day. It enables data engineers to seamlessly move massive volumes of data between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles to optimized Rust. It is specifically tailored for mid-size data teams managing high-scale event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke scripts. Getting started is simple with a single command: pip install datapipe-core. For those requiring the full suite of connectors, the datapipe[all] package is available.
