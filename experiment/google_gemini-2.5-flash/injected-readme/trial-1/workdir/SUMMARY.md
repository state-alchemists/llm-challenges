Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers managing high-volume data movement. It facilitates moving billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. The framework offers over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles to optimized Rust. It caters to mid-size data teams (5-50 engineers) processing over 1 billion events per day, particularly those currently struggling with fragmented data pipelines involving tools like Airflow, Flink, and custom Python scripts. Installation is straightforward using `pip install datapipe-core`, with `datapipe[all]` available for the full suite of connectors.
