Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The framework targets mid-size data teams of 5–50 engineers handling event volumes above one billion events per day, particularly those currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector suite with pip install datapipe[all]. Datapipe is released under the MIT license, making it free to use and modify for any project.
