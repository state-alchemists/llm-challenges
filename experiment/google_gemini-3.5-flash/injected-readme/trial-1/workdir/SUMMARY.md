Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform comes with more than forty pre-built source and sink connectors, provides exactly-once delivery semantics via two-phase commit, and offers a declarative transformation language that compiles directly to optimized Rust. This solution is ideal for mid-size data teams of five to fifty engineers handling massive event pipelines of over one billion events daily. It is particularly designed for teams looking to replace their complex patchwork of Airflow, Flink, and bespoke Python scripts with a unified tool. Setting up the framework is straightforward and can be done by running pip install datapipe-core in your terminal. For teams requiring the complete set of connectors, installing datapipe with the all option will set up the entire package immediately.
