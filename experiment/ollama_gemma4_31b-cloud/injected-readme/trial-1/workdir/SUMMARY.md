Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for high-performance data movement. It enables data engineers to transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors and ensures exactly-once delivery semantics through a robust two-phase commit system. It is specifically tailored for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke Python scripts. Users can leverage a declarative transformation DSL that compiles directly to optimized Rust for maximum efficiency. Getting started is simple by running pip install datapipe-core, or pip install datapipe[all] for the complete connector pack.
