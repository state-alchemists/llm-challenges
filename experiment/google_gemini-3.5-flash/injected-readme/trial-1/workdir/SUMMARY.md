Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that enables fast and efficient event streaming. It is specifically designed to help data engineers seamlessly transfer billions of events per day between platforms like Kafka, S3, Postgres, and ClickHouse without the need to write complex custom connector code. The platform features over forty pre-built source and sink connectors, guarantees exactly-once delivery using two-phase commits, and provides a declarative transformation DSL that compiles directly to optimized Rust. This powerful tool is tailor-made for mid-size data teams of five to fifty engineers who manage massive daily event volumes and are looking to replace a patchwork of Airflow, Flink, and custom Python scripts. To get started with the core features, you can install the framework by running pip install datapipe-core in your terminal. For those who require the complete suite of connectors, the full package can be installed by running pip install datapipe with the all option.
