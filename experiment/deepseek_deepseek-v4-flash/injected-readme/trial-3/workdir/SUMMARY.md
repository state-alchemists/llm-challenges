Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over forty pre-built source and sink connectors, so teams can stop writing custom connector code and focus on their data pipelines. The framework provides exactly-once delivery semantics through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for performance. Datapipe targets mid-size data teams of five to fifty engineers who are currently stitching together Airflow, Flink, and bespoke Python jobs to handle event volumes in the billion-plus-per-day range. Installation is straightforward: run `pip install datapipe-core` for the core framework, or `pip install datapipe[all]` for the full suite of connectors. It is released under the MIT license.
