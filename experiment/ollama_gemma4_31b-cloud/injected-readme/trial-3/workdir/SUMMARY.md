Datapipe is an open-source streaming ETL framework built with Rust and Python bindings, designed for high-volume data movement. It enables data engineers to transfer billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically tailored for mid-size data teams managing massive event volumes who want to replace fragmented pipelines. To get started, simply install the core package using pip install datapipe-core. For access to the complete set of connectors, users can install the full pack via pip install datapipe[all].
