Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The framework targets mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus range who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installing Datapipe is straightforward — run pip install datapipe-core for the core engine, or pip install datapipe[all] to include the full connector pack. By combining Rust's speed with Python's accessibility, Datapipe lets teams replace fragile, hand-maintained pipelines with a single reliable framework that handles both scale and correctness out of the box.
