Datapipe is an open-source streaming ETL framework that moves billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. Built in Rust with Python bindings, it delivers high throughput and low latency while remaining accessible to data engineers who prefer Python. The framework ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is designed for mid-size data teams handling a billion or more events daily who are currently juggling a patchwork of Airflow, Flink, and hand-written Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or add the full connector pack with pip install datapipe[all]. By replacing fragmented pipelines with one unified framework, Datapipe lets teams spend less time on plumbing and more time on the data that drives their business.
