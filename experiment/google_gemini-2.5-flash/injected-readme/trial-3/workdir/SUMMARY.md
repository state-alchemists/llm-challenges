Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed for data engineers. It efficiently moves billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. The framework offers over 40 pre-built source/sink connectors, guarantees exactly-once delivery via two-phase commit, and uses a declarative transformation DSL that compiles into optimized Rust. It targets mid-size data teams, typically 5-50 engineers, who manage over 1 billion events per day and currently rely on a mix of Airflow, Flink, and custom Python solutions. Installation is straightforward with `pip install datapipe-core`, with a full connector pack available through `datapipe[all]`.
