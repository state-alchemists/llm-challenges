# Datapipe

Datapipe is a streaming ETL framework written in Rust with Python bindings.

## Overview
Datapipe is designed for data engineers moving billions of daily events between Kafka, S3, Postgres, and ClickHouse. It features pre-built source and sink connectors, exactly-once delivery via two-phase commit, and a transformation DSL compiling to optimized Rust.
