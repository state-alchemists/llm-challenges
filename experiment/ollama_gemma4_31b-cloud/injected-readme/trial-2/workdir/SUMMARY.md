Datapipe is an open-source streaming ETL framework that enables the movement of billions of events per day across Kafka, S3, Postgres, and ClickHouse. Written in Rust with Python bindings, it provides a declarative transformation DSL and over 40 pre-built connectors to eliminate the need for custom connector code. The platform is specifically designed for mid-size data teams of five to fifty engineers who are managing massive event volumes. It replaces fragmented pipelines of Airflow, Flink, and bespoke Python jobs with exactly-once delivery semantics. Getting started is simple with a single command: pip install datapipe-core. For teams requiring the full suite of connector packs, the datapipe[all] installation is recommended.
