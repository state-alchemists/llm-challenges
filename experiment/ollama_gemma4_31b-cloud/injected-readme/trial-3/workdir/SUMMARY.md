Datapipe is an open-source streaming ETL framework designed to handle the movement of billions of events per day. It allows data engineers to seamlessly transfer data between platforms like Kafka, S3, Postgres, and ClickHouse without needing to write custom connector code. The system features over 40 pre-built connectors and ensures reliability through exactly-once delivery semantics. It is specifically built for mid-size data teams managing high event volumes who want to replace complex patchworks of fragmented tools. To get started, users can simply install the core library via pip install datapipe-core. For those needing the full suite of capabilities, the complete connector pack is available through the datapipe[all] installation option.
