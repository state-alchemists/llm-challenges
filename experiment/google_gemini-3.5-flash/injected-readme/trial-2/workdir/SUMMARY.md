Datapipe is an open-source streaming ETL framework built in Rust with Python bindings designed to seamlessly move billions of events per day. By offering over forty pre-built source and sink connectors, it allows users to connect databases and storage systems like Kafka, S3, Postgres, and ClickHouse without writing any custom connector code. The framework ensures reliable data transmission through exactly-once delivery semantics using two-phase commit protocols and a declarative transformation language that compiles down to highly optimized Rust. This solution is tailor-made for mid-size data teams consisting of five to fifty engineers who handle massive event streams of one billion or more events daily. It serves as a powerful replacement for teams currently struggling to maintain a fragmented patchwork of Airflow, Flink, and custom Python scripts. Getting started is simple, requiring only a basic installation command of the core package using pip. For those needing full functionality, downloading the comprehensive connector package unlocks the platform's complete suite of integration tools.
