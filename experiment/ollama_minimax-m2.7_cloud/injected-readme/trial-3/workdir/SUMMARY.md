Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors, exactly-once delivery semantics using a two-phase commit protocol, and a declarative transformation DSL that compiles to optimized Rust for high performance. The project targets mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus per day range, replacing patchwork solutions of Airflow, Flink, and bespoke Python jobs. To install the core package, run pip install datapipe-core, or install the full connector pack with pip install datapipe[all]. Datapipe is open-source and released under the MIT license.
