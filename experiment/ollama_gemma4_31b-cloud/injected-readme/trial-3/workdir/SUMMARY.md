Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day with ease. It allows data engineers to seamlessly transfer data between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically built for mid-size data teams managing massive event volumes who want to replace complex patches of Airflow and Flink. To get started, simply install the core library using pip install datapipe-core. For access to the full suite of connectors, users can install the datapipe[all] package.
