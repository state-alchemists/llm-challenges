Datapipe is an open-source streaming ETL framework designed for data engineers. Built in Rust with Python bindings, it facilitates the movement of billions of events daily between Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. Datapipe includes over 40 pre-built source and sink connectors, ensuring exactly-once delivery semantics through a two-phase commit. It also features a declarative transformation DSL that compiles to optimized Rust, catering specifically to mid-sized data teams managing large-scale event volumes. Installation is straightforward with `pip install datapipe-core`, while a full connector pack can be obtained via `datapipe[all]`. This project targets teams of 5-50 engineers currently relying on a mix of Airflow, Flink, and custom Python jobs.
