Datapipe is an open-source streaming ETL framework, designed to simplify data movement for data engineers. It enables the transfer of billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without requiring custom connector coding. The framework comes with over 40 pre-built source and sink connectors to streamline integrations, ensuring exactly-once delivery using two-phase commit. Additionally, Datapipe features a declarative transformation DSL that compiles to optimized Rust. It is particularly beneficial for mid-size data teams handling over a billion events per day, aiming to replace their complex setups involving Airflow and Flink. Installation is straightforward; simply run `pip install datapipe-core`, or use `datapipe[all]` for the complete connector pack.
