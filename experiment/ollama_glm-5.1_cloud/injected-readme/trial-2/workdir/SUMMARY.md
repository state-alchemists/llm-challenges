Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It eliminates the need to write custom connector code by shipping with over 40 pre-built source and sink connectors out of the box. Exactly-once delivery semantics, backed by two-phase commit, ensure no events are lost or duplicated even at massive scale. A declarative transformation DSL compiles down to optimized Rust, so teams get both productivity and performance without trading one for the other. Datapipe is aimed at mid-size data teams handling a billion or more events daily who are currently juggling a patchwork of Airflow, Flink, and hand-rolled Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector set with datapipe[all]. The project is released under the MIT license.
