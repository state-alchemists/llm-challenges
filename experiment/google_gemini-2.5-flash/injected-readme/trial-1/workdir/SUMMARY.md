Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers. It allows for the efficient movement of billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework offers over 40 pre-built source/sink connectors, guarantees exactly-once delivery through two-phase commit, and features a declarative transformation DSL that compiles to optimized Rust. It is ideal for mid-sized data teams (5-50 engineers) managing high event volumes (1B+ events/day) who seek to consolidate disparate data pipelines. Installation is straightforward via `pip install datapipe-core`, with an option for `datapipe[all]` for the complete connector suite.
