Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers in mid-size teams. It helps move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The framework comes equipped with over 40 pre-built source/sink connectors, ensuring exactly-once delivery through two-phase commit. It also features a declarative transformation language that compiles into optimized Rust code. This solution aims to streamline data pipelines for teams currently managing complex setups with Airflow, Flink, and custom Python scripts. Installation is straightforward, requiring a simple `pip install datapipe-core`, with `datapipe[all]` available for the complete connector suite.
