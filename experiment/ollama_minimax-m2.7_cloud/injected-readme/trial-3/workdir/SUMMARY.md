Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it practical for teams running high-volume event pipelines at scale. The framework provides exactly-once delivery semantics through a two-phase commit mechanism, and a declarative transformation DSL that compiles to optimized Rust for strong performance. Datapipe is aimed at mid-size data teams of 5 to 50 engineers handling one billion or more events daily who would otherwise maintain a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a base package called datapipe-core and an optional full connector pack installed as datapipe with the all extra. The project is open-source and released under the MIT license.
