Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made to help data engineers move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than forty pre-built source and sink connectors and guarantees exactly-once delivery through a two-phase commit protocol. You can define transformations with a declarative DSL that compiles down to optimized Rust, so you get high performance without sacrificing ease of use. To get started, simply install the core package with pip, or choose the full connector pack if you need every integration out of the box. Datapipe is built for mid-size data teams of five to fifty engineers who are processing over a billion events per day and are tired of maintaining patched-together workflows across Airflow, Flink, and custom Python scripts.
