Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that lets data engineers move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than forty pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation language that compiles down to optimized Rust. The tool is built for mid-size data teams of five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and custom Python scripts to handle event volumes exceeding one billion per day. Installing the core library is as simple as running pip install datapipe-core, and teams that need the full suite of connectors can opt for the datapipe all package instead. With Datapipe, you get production-grade reliability and performance while keeping your infrastructure declarative and maintainable. Whether you are building real-time pipelines or batch workflows, Datapipe gives you the speed of Rust and the familiarity of Python in one cohesive platform.
