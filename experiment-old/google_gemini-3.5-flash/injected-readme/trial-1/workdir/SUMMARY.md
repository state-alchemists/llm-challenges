Datapipe is an open-source streaming ETL framework engineered in Rust with convenient Python bindings. It is designed specifically for mid-size data teams managing massive workloads exceeding one billion events per day. By replacing complex, fragmented setups of Airflow, Flink, and custom Python scripts, it enables engineers to seamlessly move event streams between systems like Kafka, S3, Postgres, and ClickHouse. Datapipe eliminates the need for custom connector code by providing over forty pre-built source and sink integrations out of the box. It guarantees highly reliable and performant operations through exactly-once delivery semantics and a declarative transformation language that compiles directly to optimized Rust. To get started, teams can easily install the core package using the standard pip package manager, or include the full connector pack for comprehensive integration options.
