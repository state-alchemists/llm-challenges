Datapipe is a high-performance open-source streaming ETL framework built in Rust with convenient Python bindings. It enables data engineers to seamlessly move billions of events daily between major platforms like Kafka, S3, Postgres, and ClickHouse. The framework eliminates the need for custom connector code by providing over 40 pre-built source and sink connectors. It is specifically designed for mid-size data teams handling massive event volumes who want to replace fragmented pipelines with a unified system. Users benefit from exactly-once delivery semantics and a declarative transformation DSL that compiles to optimized Rust. To get started, simply run pip install datapipe-core in your terminal. For the complete suite of connectors, the datapipe[all] package is available for installation.
