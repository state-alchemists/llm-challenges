Datapipe is an open-source streaming ETL framework written in Rust and available through Python bindings. It is built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is ideal for mid-size data teams of 5 to 50 engineers that process more than a billion events per day and currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. You can install the core library with pip by running pip install datapipe-core. For access to the full connector pack, install datapipe[all] instead. Datapipe is released under the MIT license.
