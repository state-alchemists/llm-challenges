Datapipe is a powerful open-source streaming ETL framework that enables data engineers to move billions of events daily across Kafka, S3, Postgres, and ClickHouse. Built with Rust and featuring Python bindings, it eliminates the need for custom connector code through over 40 pre-built source and sink connectors. The framework ensures data integrity with exactly-once delivery semantics and offers a declarative transformation DSL that compiles into high-performance Rust. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified solution. To get started, simply run pip install datapipe-core, or use pip install datapipe[all] for the complete connector suite.
