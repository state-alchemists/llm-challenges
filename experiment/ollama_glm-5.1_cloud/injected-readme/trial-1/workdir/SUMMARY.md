Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that lets data engineers move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The project is aimed at mid-size data teams of five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs to handle event volumes in the billion-per-day range. Getting started is straightforward: install the core package with a single pip command, or grab the full connector pack with the extras flag. By replacing fragmented pipelines with a single declarative framework, Datapipe reduces maintenance overhead and lets teams focus on data logic rather than infrastructure plumbing. The project is released under the MIT license, making it free to use, modify, and deploy in any environment.
