Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that simplifies massive data movement without the need for custom connector code. It is designed to reliably move billions of events per day between Kafka, S3, Postgres, and ClickHouse using over forty pre-built source and sink connectors. The platform is ideal for mid-sized data teams managing high event volumes who want to replace their complex patchwork of Airflow, Flink, and bespoke Python scripts. Datapipe ensures exactly-once delivery semantics and utilizes a declarative transformation language that compiles down to highly optimized Rust code. Getting started is straightforward, as the core package can be installed directly through pip using the datapipe-core package name. For teams requiring access to the complete suite of connectors, the full connector package can be installed by running pip install datapipe with the all extra option.
