Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, and uses a two-phase commit protocol to guarantee exactly-once delivery semantics across pipelines. Users define transformations in a declarative DSL that compiles to optimized Rust, combining the ease of Python with the performance of a compiled systems language. The project targets mid-sized data teams of five to fifty engineers handling event volumes in the billions per day, replacing fragmented stacks of Airflow, Flink, and bespoke Python jobs with a unified framework. Installation is a single pip command for the core package, or a one-liner to get the full connector pack. Datapipe is available under an MIT open-source license.
