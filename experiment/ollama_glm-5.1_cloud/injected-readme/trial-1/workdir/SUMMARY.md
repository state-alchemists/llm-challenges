Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust — so teams can pipe data at scale without writing custom connector code. The project targets mid-size data teams of 5–50 engineers handling 1B+ daily events, especially those currently juggling a patchwork of Airflow, Flink, and ad-hoc Python jobs. Getting started is straightforward: install the core package with `pip install datapipe-core`, or grab the full connector pack via `datapipe[all]`. Datapipe is released under the MIT license.
