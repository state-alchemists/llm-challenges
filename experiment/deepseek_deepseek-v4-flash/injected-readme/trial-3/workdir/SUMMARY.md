Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data teams that move over a billion events per day. It eliminates the need for custom connector code by providing 40+ pre-built source and sink connectors for systems like Kafka, S3, Postgres, and ClickHouse. Datapipe guarantees exactly-once delivery through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for production performance. It's built for mid-size data teams of 5 to 50 engineers who want to replace a patchwork of Airflow, Flink, and bespoke Python jobs with a single, unified pipeline framework. Getting started is straightforward — install the core library with `pip install datapipe-core`, or pull in every connector with `datapipe[all]`. No separate infrastructure or cluster is required to run it.
