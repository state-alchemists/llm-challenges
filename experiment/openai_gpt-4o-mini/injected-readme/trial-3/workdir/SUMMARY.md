Datapipe is an open-source streaming ETL framework tailored for data engineers who require efficient movement of billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without the hassle of custom connector development. It features over 40 pre-built source and sink connectors, ensuring exactly-once delivery through two-phase commit protocols. The framework includes a declarative transformation DSL, which compiles to optimized Rust for better performance. Installation is straightforward: simply run 'pip install datapipe-core', or use 'pip install datapipe[all]' for the complete connector package. Ideal for mid-size data teams, typically comprised of 5-50 engineers, Datapipe is designed to replace existing setups of Airflow, Flink, and custom Python jobs, making it an effective solution for managing high event volumes efficiently.
