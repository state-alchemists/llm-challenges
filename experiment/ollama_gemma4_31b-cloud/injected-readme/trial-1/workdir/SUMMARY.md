Datapipe is a powerful open-source streaming ETL framework built in Rust with Python bindings for maximum performance. It is specifically designed for data engineers at mid-size teams who manage massive event volumes of one billion or more per day. The platform eliminates the need for custom connector code by providing over forty pre-built source and sink connectors for popular services like Kafka, S3, Postgres, and ClickHouse. Users can leverage a declarative transformation DSL and exactly-once delivery semantics to ensure data integrity at scale. To get started, simply run pip install datapipe-core to install the core framework. For a complete experience with all available connectors, use the pip install datapipe[all] command.
