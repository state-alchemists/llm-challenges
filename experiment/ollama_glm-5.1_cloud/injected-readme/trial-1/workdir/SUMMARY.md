Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The project targets mid-size data teams of 5 to 50 engineers operating at 1B+ events per day who are currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or pull in the full connector pack with datapipe[all]. Datapipe is released under the MIT license, making it free to use and modify in any environment.
