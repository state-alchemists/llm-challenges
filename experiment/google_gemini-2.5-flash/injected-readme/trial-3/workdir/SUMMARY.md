Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings. It helps data engineers move billions of events daily across various data sources like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. The framework offers over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles into optimized Rust. It is ideal for mid-sized data teams managing high event volumes who currently rely on a mix of Airflow, Flink, and custom Python solutions. To install, simply run `pip install datapipe-core`, or `datapipe[all]` for the complete connector pack.
