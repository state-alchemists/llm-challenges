Datapipe is an open-source streaming ETL framework designed specifically for data engineers. Built in Rust with Python bindings, it enables users to efficiently move billions of events per day between popular platforms like Kafka, S3, Postgres, and ClickHouse. The framework includes over 40 pre-built source and sink connectors, ensuring users don't have to develop custom connectors. With its exactly-once delivery semantics and a declarative transformation DSL that compiles to optimized Rust, Datapipe simplifies complex data workflows. It's ideal for mid-sized data teams of 5 to 50 engineers dealing with heavy event volumes exceeding 1 billion events per day. Installation is straightforward via pip, with the command `pip install datapipe-core`, or by using `pip install datapipe[all]` for the complete set of connectors.
