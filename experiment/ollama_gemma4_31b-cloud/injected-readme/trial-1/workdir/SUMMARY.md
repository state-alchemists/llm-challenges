Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for high-performance data movement. It enables data engineers to transfer billions of events daily between services like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework is ideal for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified solution. Key features include over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL that compiles to optimized Rust. Getting started is simple with a single command: pip install datapipe-core. For those requiring the complete set of connectors, the full pack is available via pip install datapipe[all].
