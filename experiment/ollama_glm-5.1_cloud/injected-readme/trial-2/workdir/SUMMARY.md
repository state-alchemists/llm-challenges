Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that moves billions of events per day across Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. The framework is built for mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus range who currently juggle a patchwork of Airflow, Flink, and ad-hoc Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all]. Datapipe is licensed under MIT and designed to replace fragile pipeline maintenance with a single, high-performance framework.
