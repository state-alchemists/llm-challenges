Datapipe is an open-source streaming ETL framework, built with Rust and offering Python bindings. It enables data engineers to efficiently move billions of events daily between various data stores like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework provides over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation DSL for optimized performance. It is designed for mid-size data teams (5-50 engineers) handling over 1 billion events per day, offering a unified solution to replace fragmented data pipelines often built with tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via `pip install datapipe-core`, with a full connector pack available via `datapipe[all]`.
