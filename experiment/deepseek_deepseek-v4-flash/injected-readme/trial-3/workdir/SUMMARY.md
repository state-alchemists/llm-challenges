Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with 40+ pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It's designed for mid-size data teams of 5-50 engineers handling event volumes of 1 billion or more events per day, especially those currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command: pip install datapipe-core, or pip install datapipe[all] for the full connector pack. Datapipe is MIT-licensed and free to use.
