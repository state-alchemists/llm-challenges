Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for efficiently moving vast amounts of event data. It targets data engineers in mid-size teams (5-50 engineers) who handle over a billion events daily and seek to replace complex, custom data pipelines. Datapipe simplifies this by offering 40+ pre-built connectors, ensuring exactly-once delivery with two-phase commit, and providing a declarative transformation language that optimizes to Rust. To get started, users can install the core library via `pip install datapipe-core`, with an option for `datapipe[all]` for the complete connector pack. This framework aims to streamline data operations, reducing the need for extensive custom code in existing Airflow, Flink, and Python job environments.
