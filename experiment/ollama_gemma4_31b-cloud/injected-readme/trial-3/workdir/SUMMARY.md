Datapipe is a high-performance open-source streaming ETL framework built in Rust with convenient Python bindings. It is specifically designed for data engineers who manage massive workloads, moving billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. The framework eliminates the need for custom connector code by providing over 40 pre-built source and sink connectors. It ensures data integrity through exactly-once delivery semantics and uses a declarative DSL that compiles into optimized Rust for maximum efficiency. This tool is ideal for mid-size data teams of 5 to 50 engineers looking to replace fragmented pipelines with a unified system. You can get started quickly by installing the core package via pip install datapipe-core. For the complete suite of connectors, simply use pip install datapipe[all].
