Datapipe is an open-source streaming ETL framework built with Rust and Python bindings for high-performance data movement. It enables data engineers to seamlessly transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse. The platform simplifies infrastructure by providing over 40 pre-built connectors and guaranteed exactly-once delivery. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified system. Users can leverage a declarative transformation DSL that compiles into optimized Rust for maximum efficiency. To get started, simply run pip install datapipe-core. For those requiring the full suite of connectors, the datapipe[all] package is available.
