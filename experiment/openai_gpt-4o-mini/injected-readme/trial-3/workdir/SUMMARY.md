Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors, ensures exactly-once delivery with two-phase commit, and features a declarative transformation DSL that compiles to optimized Rust. Mid-size data teams, consisting of 5 to 50 engineers dealing with 1B+ events per day, will find Datapipe valuable as it simplifies replacing a patchwork of tools like Airflow and Flink. To install, execute 'pip install datapipe-core' for the core package or 'pip install datapipe[all]' to include the full connector pack.
