Datapipe is an open-source streaming ETL framework tailored for data engineers needing to transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework offers over 40 pre-built source and sink connectors, ensuring exactly-once delivery through a two-phase commit process. It features a declarative transformation DSL that compiles to efficient Rust code. Installation is straightforward with the command 'pip install datapipe-core,' or for the full connector pack, use 'datapipe[all].' Datapipe is particularly aimed at mid-sized data teams, comprising 5 to 50 engineers, dealing with event volumes exceeding one billion per day, often transitioning from a mix of Airflow, Flink, and custom Python solutions.
