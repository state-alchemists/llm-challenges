Datapipe is an open-source streaming ETL framework built in Rust with Python bindings to simplify high-volume data movement. It is designed for mid-sized data teams of five to fifty engineers managing over one billion daily events who want to replace a complex patchwork of Airflow, Flink, and custom Python scripts. The framework allows data engineers to seamlessly transport data between Kafka, S3, Postgres, and ClickHouse without writing any custom connector code. It provides over forty pre-built source and sink connectors, exactly-once delivery guarantees through two-phase commits, and a declarative transformation language that compiles down to highly optimized Rust. To get started, you can easily install the core package using the standard Python package manager with the pip install datapipe-core command. For the complete set of connectors, users can install the all version of the library instead.
