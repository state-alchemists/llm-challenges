Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data platforms out of the box rather than building integrations from scratch. Datapipe provides exactly-once delivery semantics using a two-phase commit protocol, giving teams confidence that every event is processed exactly once even across distributed systems. A declarative transformation DSL compiles to optimized Rust, letting engineers express data transformations in a readable way while still benefiting from Rust's performance. Installation is straightforward with a single pip command, and a full connector pack is available for teams that need everything included. Datapipe is aimed at mid-size data teams of five to fifty engineers handling event volumes in the billions per day, replacing patchwork solutions of Airflow, Flink, and bespoke Python jobs with a unified framework. It is open source and released under the MIT license.
