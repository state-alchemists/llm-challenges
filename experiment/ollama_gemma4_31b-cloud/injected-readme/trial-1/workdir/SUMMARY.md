Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform offers over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is ideal for mid-size data teams managing high event volumes who want to replace a patchwork of bespoke scripts and tools. To get started, simply install the core package using pip install datapipe-core. For teams needing the full suite of connectors, the datapipe[all] package is available.
