Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. The project targets mid-size data teams of 5 to 50 engineers handling 1 billion-plus events daily who currently juggle Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core library with pip install datapipe-core, or add the full connector pack with datapipe[all]. Datapipe is released under the MIT license.
