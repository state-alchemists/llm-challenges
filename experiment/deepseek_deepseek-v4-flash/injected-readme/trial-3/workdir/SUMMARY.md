Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between Kafka, S3, Postgres, and ClickHouse. It removes the need to write custom connector code by shipping with more than 40 pre-built source and sink connectors, and it guarantees exactly-once delivery through two-phase commit semantics. A declarative transformation DSL compiles down to optimized Rust, so pipelines stay readable without sacrificing performance. Datapipe is aimed at mid-size data teams of roughly 5 to 50 engineers who are processing over a billion events per day and currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is simple: install the core package with pip install datapipe-core, or add the datapipe[all] extra for the full connector pack. The project is MIT-licensed and ready to drop into existing data infrastructure.
