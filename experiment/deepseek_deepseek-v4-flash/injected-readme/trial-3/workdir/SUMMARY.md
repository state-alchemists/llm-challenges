Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than 40 pre-built source and sink connectors, delivers exactly-once semantics through two-phase commit, and lets you express transformations in a declarative DSL that compiles down to optimized Rust. It is built for mid-size data teams of five to fifty engineers who process event volumes in the billion-per-day range and currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command: pip install datapipe-core. For the full connector pack, install datapipe[all] instead. Datapipe is released under the MIT license.
