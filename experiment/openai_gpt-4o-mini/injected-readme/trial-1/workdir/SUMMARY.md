Datapipe is an open-source streaming ETL framework aimed at data engineers, enabling the movement of billions of events daily between systems such as Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It offers over 40 pre-built source and sink connectors, ensuring exactly-once delivery through a two-phase commit mechanism, and features a declarative transformation DSL compiled to optimized Rust for performance. This framework is particularly useful for mid-sized data teams of 5-50 engineers handling high event volumes, currently relying on a mixture of Airflow, Flink, and custom Python jobs. To install Datapipe, run 'pip install datapipe-core'. For the complete connector pack, use 'pip install datapipe[all]'. The project is licensed under MIT.
