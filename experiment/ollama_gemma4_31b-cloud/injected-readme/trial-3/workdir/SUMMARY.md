Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events daily. It enables data engineers to seamlessly transfer data between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The system features over 40 pre-built connectors and guarantees exactly-once delivery via a two-phase commit process. It is specifically tailored for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a single, optimized solution. To get started, simply run pip install datapipe-core. For those needing the full suite of connectors, the datapipe[all] package is available.
