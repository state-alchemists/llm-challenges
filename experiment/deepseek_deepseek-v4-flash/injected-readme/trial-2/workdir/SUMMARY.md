Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over forty pre-built source and sink connectors, delivers exactly-once processing semantics through two-phase commit, and provides a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes exceeding one billion per day. Installation is straightforward via pip with `pip install datapipe-core`, and the full connector suite is available as `datapipe[all]`. The project is released under the MIT license and is available on GitHub.
