Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that enables fast and reliable high-volume data movement. Designed specifically for data engineers, the platform allows teams to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without having to write any custom connector code. It comes equipped with over forty pre-built source and sink connectors, offers exactly-once delivery semantics through a two-phase commit system, and features a declarative transformation language that compiles into highly optimized Rust code. The framework is tailored for mid-size data teams of five to fifty engineers who handle event volumes in the billions per day and are looking to replace their complex, fragmented setups of Airflow, Flink, and bespoke Python jobs. Setting up Datapipe is extremely straightforward and can be completed by installing the datapipe-core package via pip. For teams needing the complete suite of connectors, the full package can be installed by running the pip command with the all option.
