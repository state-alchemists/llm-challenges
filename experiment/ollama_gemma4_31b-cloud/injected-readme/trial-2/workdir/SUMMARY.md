Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It allows data engineers to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically designed for mid-size data teams managing high event volumes who want to replace complex patches of Airflow, Flink, and custom Python jobs. To get started, simply run pip install datapipe-core. For the complete set of connectors, use pip install datapipe[all].
