# 2026-06-15

## Activity
- Created `MIGRATION.md` containing a comprehensive Zrb v2 migration guide for developers.
- Explicitly detailed all six breaking changes between the v1 and v2 specifications:
  1. Endpoint URL path `/v2/` prefixing.
  2. Transition of the custom `X-Auth-Token` header to standard `Authorization: Bearer <token>`.
  3. Modification of task ID field types from `integer` to `UUID string`.
  4. Renaming of task `done` field to `completed`.
  5. Required `project_id` field on task creation endpoints.
  6. Migration of response structures from raw lists to paginated envelopes.
- Included comprehensive before/after code blocks and a step-by-step checklist.
