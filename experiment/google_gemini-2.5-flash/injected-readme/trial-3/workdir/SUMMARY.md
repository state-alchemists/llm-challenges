Datapipe is an open-source streaming ETL framework, built in Rust with convenient Python bindings, designed to streamline data movement for high-volume environments. It empowers data engineers to effortlessly transfer billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse without needing custom connector development. The project boasts over 40 pre-built source/sink connectors, guarantees exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles to highly optimized Rust code. This robust solution is ideal for mid-size data teams, typically 5-50 engineers, who manage over a billion events per day and are looking to replace complex, fragmented data pipelines involving tools like Airflow or Flink. Getting started is simple: install the core library with `pip install datapipe-core`, or `pip install datapipe[all]` for the comprehensive connector suite.
