Datapipe is an open-source streaming ETL framework tailored for data engineers needing to transfer billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse, without the hassle of custom connector code. It features over 40 pre-built source and sink connectors, ensures exactly-once delivery semantics via two-phase commit, and offers a user-friendly transformation DSL that compiles to optimized Rust. Mid-sized data teams, typically comprising 5-50 engineers, can streamline their operations, especially those managing over 1 billion events per day and currently relying on a mix of Airflow, Flink, and custom Python jobs. Installation is straightforward: simply run 'pip install datapipe-core' for the core functionality, or 'pip install datapipe[all]' to access the full suite of connectors.
