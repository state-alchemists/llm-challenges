Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers managing massive event volumes. It enables moving billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse without needing custom connector code. The framework includes over 40 pre-built source/sink connectors, ensuring exactly-once delivery through two-phase commit mechanisms. It also features a declarative transformation DSL that compiles into highly optimized Rust code for efficient data processing. Datapipe is ideal for mid-sized data teams, typically 5-50 engineers, who handle over a billion events per day and currently rely on a complex mix of Airflow, Flink, and custom Python solutions. To get started, users can simply install it via pip.
