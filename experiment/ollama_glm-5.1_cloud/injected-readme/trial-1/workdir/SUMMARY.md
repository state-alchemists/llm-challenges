Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The framework is aimed at mid-size data teams of 5 to 50 engineers handling event volumes in the billion-per-day range who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Installing Datapipe is straightforward: run pip install datapipe-core to get started, or install datapipe[all] for the full connector pack. The project is released under the MIT license.
