Datapipe is an open-source streaming ETL framework designed to help data teams seamlessly move billions of events per day between platforms like Kafka, S3, Postgres, and ClickHouse. Built in Rust with Python bindings, it offers exceptional performance by compiling a declarative transformation DSL into highly optimized Rust code. The platform simplifies complex data integration by shipping with over forty pre-built source and sink connectors, eliminating the need to write custom connector code. It is specifically built for mid-size data teams of five to fifty engineers who are currently managing a complex patchwork of Airflow, Flink, and custom Python scripts. Datapipe guarantees reliable data delivery with its robust exactly-once semantics achieved through a two-phase commit architecture. Getting started is straightforward, as you can easily install the core package by running pip install datapipe-core. For teams requiring the full suite of integration features, installing datapipe with the all extra option enables the complete connector pack.
