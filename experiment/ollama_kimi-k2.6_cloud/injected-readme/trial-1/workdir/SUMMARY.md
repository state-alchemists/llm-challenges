Datapipe is an open-source streaming ETL framework that helps data teams move massive volumes of events between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. Built in Rust with Python bindings, it is designed for mid-size data teams processing billions of events per day who are tired of maintaining patchwork workflows across Airflow and Flink. The framework includes over 40 pre-built source and sink connectors, exactly-once delivery semantics, and a declarative transformation language that compiles down to optimized Rust. You can get started quickly by installing the core library with pip, and if you need the complete set of connectors, there is a full pack available as well. Datapipe lets you focus on building your data pipelines rather than managing infrastructure, all while keeping latency low and throughput high. It is released under the MIT license.
