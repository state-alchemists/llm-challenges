Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for moving billions of events daily. It provides over 40 pre-built connectors for popular data systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. Datapipe ensures exactly-once delivery through two-phase commit and offers a declarative transformation language that compiles to optimized Rust. This tool is ideal for mid-sized data engineering teams managing high event volumes (over 1 billion events per day) who currently rely on complex setups involving Airflow, Flink, and custom Python jobs. To install, simply run `pip install datapipe-core`, or `datapipe[all]` for the complete connector suite.
