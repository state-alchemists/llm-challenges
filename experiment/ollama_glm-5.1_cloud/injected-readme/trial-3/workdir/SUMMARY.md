Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus daily range, particularly those juggling a patchwork of Airflow, Flink, and custom Python jobs. Installation is straightforward — a core install is available via pip install datapipe-core, and the full connector pack can be added with the datapipe[all] extra.
