Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It lets data engineers move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is built for mid-size data teams of 5 to 50 engineers running event volumes above one billion events per day who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command, pip install datapipe-core, and the full connector pack is available by installing datapipe[all]. Datapipe is licensed under MIT.
