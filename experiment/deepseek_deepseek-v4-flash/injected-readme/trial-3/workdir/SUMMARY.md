Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, engineered for data teams that need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and provides a declarative transformation DSL that compiles down to optimized Rust. The project is designed for mid-size data teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs and want a single, high-performance pipeline layer. Installation is straightforward: run `pip install datapipe-core` to get the core framework, or `pip install datapipe[all]` for the full set of connectors. Datapipe is released under the MIT license and is available on GitHub as an open-source project.
