Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation DSL that compiles to optimized Rust. Datapipe is aimed at mid-size data teams of 5 to 50 engineers running event volumes in the billion-per-day range, especially those currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command: pip install datapipe-core, or pip install datapipe[all] for the full connector pack. The project is open source under the MIT license.
