Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It targets mid-size data teams of roughly 5 to 50 engineers that run event volumes of one billion or more per day and currently rely on a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is simple: run pip install datapipe-core to get the core framework, or install datapipe[all] for the full connector pack. The project is open source and released under the MIT license.
