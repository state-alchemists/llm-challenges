Datapipe is a powerful open-source streaming ETL framework designed for high-volume data movement. Built with Rust for performance and offering Python bindings for ease of use, it simplifies complex data pipelines. It enables data engineers to efficiently transfer billions of events daily across popular platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. Featuring over 40 pre-built connectors, Datapipe ensures exactly-once delivery through two-phase commit and provides a declarative transformation language that optimizes directly to Rust. This framework is ideal for mid-sized data teams managing over a billion events daily, helping them replace fragmented data solutions like Airflow or Flink with a unified, robust system. Installation is straightforward, requiring a simple `pip install datapipe-core`, with an option for `datapipe[all]` to access the complete connector suite.
