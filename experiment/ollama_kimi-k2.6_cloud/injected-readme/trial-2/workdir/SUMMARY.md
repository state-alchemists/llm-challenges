Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to reliably move billions of events daily across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than forty ready-made source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation language that compiles down to high-performance Rust. The tool is aimed at mid-sized data teams of five to fifty engineers currently juggling a mix of Airflow, Flink, and one-off Python scripts to handle event volumes exceeding one billion per day. Getting started is simple with a standard Python package manager. Install datapipe-core for the essential framework, or choose datapipe-all to unlock every available connector in one step.
