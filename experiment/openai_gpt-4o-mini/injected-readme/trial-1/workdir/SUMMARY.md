Datapipe is an open-source streaming ETL framework designed for data engineers who need to transfer billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse, without having to write custom connector code. It comes equipped with over 40 pre-built source and sink connectors and offers exactly-once delivery semantics through a two-phase commit mechanism. The platform also features a declarative transformation DSL that compiles down to optimized Rust for efficient processing. Installation is straightforward: simply run 'pip install datapipe-core' for the core package, or 'pip install datapipe[all]' to access the complete connector pack. Datapipe is specifically tailored for mid-sized data teams managing substantial event volumes, helping to streamline their existing workflows that may involve tools like Airflow and Flink.
