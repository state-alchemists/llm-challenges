Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers. It efficiently moves billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. The project includes over 40 pre-built source/sink connectors, ensuring exactly-once delivery through two-phase commit, and offers a declarative transformation DSL that compiles to optimized Rust. It caters to mid-size data teams managing high event volumes (1B+ events/day) who currently rely on disparate systems like Airflow, Flink, and custom Python jobs. To install, simply run `pip install datapipe-core`, or `datapipe[all]` for the complete connector pack.
