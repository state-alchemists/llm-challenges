Datapipe is an open-source streaming ETL framework, built with Rust and offering Python bindings. It helps data engineers efficiently move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework provides over 40 pre-built source and sink connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation DSL that compiles to optimized Rust code. It is ideal for mid-sized data teams, typically with 5-50 engineers, who manage over a billion events per day and are looking to streamline their existing complex data pipelines. Installation is straightforward, requiring a simple `pip install datapipe-core`, with an option to install the full connector pack using `datapipe[all]`.
