Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to efficiently move billions of events daily. It provides over 40 pre-built connectors for popular data systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. A key feature is its declarative transformation language, which compiles into optimized Rust, ensuring high performance. Datapipe guarantees exactly-once delivery semantics through a two-phase commit system. It is ideal for mid-sized data teams, typically 5-50 engineers, who handle over a billion events per day and are looking to consolidate their disparate Airflow, Flink, and custom Python jobs. Installation is straightforward, requiring only `pip install datapipe-core`, with an option for `datapipe[all]` to include the full connector pack.
