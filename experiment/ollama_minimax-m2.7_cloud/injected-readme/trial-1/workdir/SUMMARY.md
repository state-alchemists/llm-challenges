Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than 40 pre-built source and sink connectors out of the box, so teams can connect to common data infrastructure immediately. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in distributed environments. Its declarative transformation DSL compiles to optimized Rust, giving users the ease of writing transformations in a simple syntax while still benefiting from Rust's performance. Installation is straightforward via pip, with the core package installed as datapipe-core and the full connector pack available as datapipe with the all extras flag. The tool targets mid-size data teams of roughly 5 to 50 engineers who are processing over one billion events daily and currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs.
