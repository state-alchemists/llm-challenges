Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, built for data engineers who need to reliably move billions of events every day across systems like Kafka, S3, Postgres, and ClickHouse. It comes with more than forty pre-built connectors, so you can wire up sources and sinks without writing custom integration code. Under the hood, it guarantees exactly-once delivery using two-phase commit, and its declarative transformation DSL compiles down to optimized Rust for high throughput. The project is aimed at mid-sized data teams—roughly five to fifty engineers—already juggling Airflow, Flink, and custom Python scripts at the billion-events-per-day scale. You can get started in minutes by installing the core package with pip: just run pip install datapipe-core. If you want the complete set of connectors, install datapipe[all] instead.
