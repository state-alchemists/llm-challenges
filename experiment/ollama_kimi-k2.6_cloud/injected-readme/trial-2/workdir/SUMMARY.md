Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data engineers move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than forty pre-built source and sink connectors, exactly-once delivery guarantees via two-phase commit, and a declarative transformation language that compiles down to optimized Rust. The framework is purpose-built for mid-sized data teams of five to fifty engineers who currently maintain patchwork pipelines across Airflow, Flink, and bespoke Python jobs while processing over a billion events per day. Getting started takes a single pip command: install the datapipe-core package for the essentials, or include the all extras to unlock the complete connector pack. Whether you are replacing fragile one-off scripts or scaling an existing streaming architecture, Datapipe turns complex data movement into simple declarative configuration. Stop writing custom connectors and start building pipelines that scale reliably from day one.
