Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus range per day, especially those currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installing Datapipe is straightforward — run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` for the full connector pack. By combining Rust's performance with Python's accessibility, Datapipe lets teams replace fragile, custom pipelines with a single declarative framework that scales to production workloads out of the box.
