Datapipe is an open-source streaming ETL framework, built with Rust and offering Python bindings, designed to help data engineers efficiently move billions of events daily across various platforms like Kafka, S3, Postgres, and ClickHouse. It eliminates the need for custom connector development by providing over 40 pre-built source/sink connectors, ensuring exactly-once delivery through two-phase commit. The framework also features a declarative transformation DSL that compiles into optimized Rust code for high performance. It targets mid-sized data teams, typically 5-50 engineers, who manage over a billion events per day and currently rely on a complex mix of Airflow, Flink, and custom Python jobs. To get started, users can install `datapipe-core` via `pip`, with an option for `datapipe[all]` for the complete connector suite.
