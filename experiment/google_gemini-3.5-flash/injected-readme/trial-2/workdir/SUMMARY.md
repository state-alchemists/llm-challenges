Datapipe is a high-performance, open-source streaming ETL framework designed to move billions of events daily without the need for custom connector code. Built in Rust with Python bindings, it combines the speed of compiled code with a declarative transformation domain-specific language that optimizes processing automatically. With more than forty pre-built source and sink connectors, the platform seamlessly bridges Kafka, Amazon S3, PostgreSQL, and ClickHouse while guaranteeing exactly-once delivery semantics. This framework is perfect for mid-size data engineering teams managing massive event streams who want to replace a fragile patchwork of Airflow, Flink, and bespoke Python jobs with a unified solution. Getting started is simple, as you can quickly install the core package through your command line with the command pip install datapipe-core. For teams requiring the full capabilities of the platform, installing the package with the all extras option provides the complete connector suite.
