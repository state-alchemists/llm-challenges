Datapipe is an open-source streaming ETL framework written in Rust, featuring Python bindings. It allows data engineers to seamlessly transfer billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom code. With over 40 pre-built connectors and exact-once delivery via two-phase commit, Datapipe ensures reliable data handling. It also includes a declarative transformation DSL compiled to optimized Rust for enhanced performance. Ideal for mid-size data teams handling substantial event volumes, Datapipe simplifies data management so teams can focus on analysis rather than infrastructure. Installation is straightforward with a simple pip command: `pip install datapipe-core`, or for the full connector pack, use `pip install datapipe[all]`.
