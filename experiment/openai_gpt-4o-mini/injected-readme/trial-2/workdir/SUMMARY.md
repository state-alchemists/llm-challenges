Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, tailored for data engineers needing to transfer billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without custom connector coding. Featuring over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery semantics through a two-phase commit process. The framework includes a declarative transformation DSL that compiles into optimized Rust for enhanced performance. Ideal for mid-size data teams of 5-50 engineers managing over 1 billion events daily, Datapipe consolidates and streamlines existing tools like Airflow and Flink into a cohesive solution. Installation is straightforward with the command `pip install datapipe-core`, and for full connector capabilities, users can install `datapipe[all]`. The project is licensed under MIT.
