Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data teams moving over a billion events per day. It provides 40+ pre-built connectors for Kafka, S3, Postgres, ClickHouse, and other common data systems, eliminating the need to write and maintain custom connector code. The framework delivers exactly-once processing guarantees through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for production performance. Datapipe is built for mid-size data teams of 5 to 50 engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python pipelines. Installing it is straightforward — just run pip install datapipe-core for the core framework, or pip install datapipe[all] to get the full suite of connectors. Datapipe is MIT-licensed and available on GitHub.
