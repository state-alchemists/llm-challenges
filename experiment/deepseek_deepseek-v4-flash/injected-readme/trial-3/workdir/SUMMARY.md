Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data teams who move billions of events per day. It handles the heavy lifting between Kafka, S3, Postgres, and ClickHouse so engineers don't have to write and maintain custom connector code. The framework ships with over 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. It's designed for mid-size data teams — five to fifty engineers — who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs and need a unified, high-throughput alternative. Installation is straightforward: run `pip install datapipe-core` for the core library, or `pip install datapipe[all]` for the full connector pack.
