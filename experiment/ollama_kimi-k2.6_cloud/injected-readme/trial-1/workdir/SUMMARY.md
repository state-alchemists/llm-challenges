Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to move massive event streams between systems like Kafka, S3, Postgres, and ClickHouse without hand-writing connector code. It comes with over forty pre-built source and sink connectors, exactly-once delivery guarantees backed by two-phase commit, and a declarative transformation language that compiles down to optimized Rust. The tool is aimed at mid-sized data teams of five to fifty engineers who are processing more than a billion events per day and are fed up with maintaining fragile patchworks of Airflow, Flink, and custom Python scripts. You can get started in seconds by running pip install datapipe-core, or choose pip install datapipe[all] if you want the complete connector pack out of the box. With Datapipe, you spend less time plumbing pipelines and more time deriving value from your data.
