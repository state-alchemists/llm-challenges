Datapipe is an open-source streaming ETL framework developed in Rust, featuring Python bindings designed specifically for data engineers. It enables the seamless transfer of billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. With over 40 pre-built source and sink connectors, it guarantees exactly-once delivery through a two-phase commit process. Datapipe also boasts a declarative transformation DSL, which compiles to optimized Rust for superior performance. Ideal for mid-sized data teams handling high event volumes, it aims to simplify the management of existing ETL workflows. Installation is straightforward: simply run `pip install datapipe-core`, and for the complete connector pack, include the option `datapipe[all]`.
