Datapipe is an open-source streaming ETL framework, built with Rust and offering Python bindings. It helps data engineers efficiently move massive daily event volumes across various data platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework boasts over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and provides a declarative transformation DSL that optimizes to Rust code. It is ideal for mid-sized data teams managing over a billion events per day, especially those currently maintaining complex data pipelines with tools like Airflow and Flink. Installation is straightforward with `pip install datapipe-core`, with an option for the full connector pack via `datapipe[all]`.
