Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework targets mid-size data teams of 5 to 50 engineers operating at 1B+ events per day who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is as simple as running `pip install datapipe-core`, with a full connector pack available via `datapipe[all]`. By combining Rust performance with Python accessibility, Datapipe eliminates the need to maintain fragile, hand-rolled pipelines while delivering the reliability and scale that high-volume event processing demands. The project is released under the MIT license.
