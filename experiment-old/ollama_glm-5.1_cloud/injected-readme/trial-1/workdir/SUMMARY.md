Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The project targets mid-size data teams of 5 to 50 engineers who handle upward of a billion events daily and currently rely on a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core library with pip install datapipe-core, or add the full connector pack with pip install datapipe[all]. Datapipe is licensed under MIT and welcomes community contributions.
