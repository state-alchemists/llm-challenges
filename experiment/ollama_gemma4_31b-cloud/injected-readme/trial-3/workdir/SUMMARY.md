Datapipe is an open-source streaming ETL framework built with Rust and Python bindings, designed to move billions of events daily between Kafka, S3, Postgres, and ClickHouse. It eliminates the need for custom connector code by providing over 40 pre-built source and sink connectors. The platform ensures data integrity with exactly-once delivery semantics and features a declarative transformation DSL that compiles to high-performance Rust. This tool is ideal for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke scripts. Getting started is simple with a single command: pip install datapipe-core. For users requiring the complete suite of connectors, the full pack is available via pip install datapipe[all].
