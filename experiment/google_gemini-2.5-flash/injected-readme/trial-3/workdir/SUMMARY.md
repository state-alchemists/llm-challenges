LLM Challenges is a comprehensive benchmark suite designed to rigorously evaluate the performance of LLM-driven coding agents on realistic software engineering tasks. This project is ideal for researchers, developers, and evaluators seeking deep insights into how LLMs handle complex problems such as bug fixes, feature development, code refactoring, and security challenges. It utilizes the `zrb` framework and `zrb-llm-evaluator` to run diverse test cases against various LLM models, producing detailed logs and performance reports. To begin, users must install `zrb-llm-evaluator` via `pipx` or `poetry` and ensure the `zrb` tool is configured with the necessary API keys. This setup allows for immediate execution of the evaluation suite, providing actionable data on agent capabilities.
