Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse. By offering over forty pre-built source and sink connectors, it eliminates the need for data engineers to write complex custom connector code from scratch. The platform is ideal for mid-size data teams managing massive event pipelines who are looking to replace their fragile patchwork of Airflow, Flink, and bespoke Python jobs. It ensures absolute reliability with exactly-once delivery semantics powered by a two-phase commit mechanism, and includes a declarative transformation language that compiles to optimized, high-performance Rust. Getting started is simple, as the core library can be installed instantly using the standard pip command for the datapipe-core package. Data teams requiring the comprehensive set of integrations can quickly upgrade to the full package with all connector packs included.
