Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to help data engineers efficiently move billions of events daily. It facilitates seamless data transfer between popular systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework offers over 40 pre-built connectors, ensuring exactly-once delivery through a two-phase commit process, and features a declarative transformation language that compiles to optimized Rust code. It is ideal for mid-size data teams, typically 5-50 engineers, who manage over a billion events per day and are looking to streamline their data pipelines, often replacing complex setups involving Airflow, Flink, and custom Python scripts. Installation is straightforward: simply use `pip install datapipe-core`, or `datapipe[all]` for the complete suite of connectors.
