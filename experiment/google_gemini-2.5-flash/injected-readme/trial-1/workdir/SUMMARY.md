Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed for efficiently moving billions of events daily between various data systems like Kafka, S3, Postgres, and ClickHouse. It offers over 40 pre-built source and sink connectors, eliminating the need for custom connector code. The framework ensures exactly-once delivery through two-phase commit and provides a declarative transformation language that compiles to optimized Rust. Datapipe is ideal for mid-size data teams, typically 5-50 engineers, who handle event volumes exceeding one billion events per day and currently manage complex data pipelines with tools like Airflow, Flink, and custom Python scripts. Installation is straightforward: simply use `pip install datapipe-core`, with an option to install `datapipe[all]` for the full connector pack.
