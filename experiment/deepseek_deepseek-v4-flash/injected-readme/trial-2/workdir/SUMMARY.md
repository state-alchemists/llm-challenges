Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers moving billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, supports exactly-once delivery semantics through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. The project is aimed at mid-size data teams of 5 to 50 engineers who currently juggle a patchwork of Airflow, Flink, and custom Python jobs to keep their pipelines running. Installation is straightforward — you can install the core package with `pip install datapipe-core`, or add the full connector pack with `pip install datapipe[all]`. The framework is licensed under MIT and designed to eliminate the need for custom connector code at scale.
