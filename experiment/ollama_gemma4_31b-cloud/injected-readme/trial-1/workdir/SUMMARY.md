Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. It is specifically tailored for mid-size data teams who need to replace complex patchworks of legacy jobs with a high-performance, reliable solution. The framework features over 40 pre-built connectors and ensures exactly-once delivery semantics through a two-phase commit process. Users can leverage a declarative transformation DSL that compiles directly to optimized Rust for maximum efficiency. Getting started is simple by running pip install datapipe-core in your terminal. For those requiring the full suite of connectivity, the complete connector pack is available via pip install datapipe[all].
