Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it practical for teams that want to connect disparate data systems quickly and reliably. The framework provides exactly-once delivery semantics using a two-phase commit approach, which is critical for data integrity in high-volume production environments. Its declarative transformation DSL compiles to optimized Rust, giving data teams a productive developer experience in Python while delivering Rust-level performance. To get started, teams can install the core package with a single pip command, or install the full connector pack for access to all integrations. Datapipe targets mid-size data teams of five to fifty engineers processing over one billion events daily who are currently managing a patchwork of tools like Airflow, Flink, and custom Python jobs.
