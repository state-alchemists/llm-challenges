LLM Challenges is a benchmark suite designed to evaluate the performance of LLM-driven coding agents on realistic software engineering tasks. It's intended for researchers and engineers who want to rigorously test and compare different language models in various scenarios, including bug fixes, feature implementation, refactoring, and safety challenges. To get started, users need to install `zrb-llm-evaluator` using `pipx` or `poetry`, ensuring `zrb` is configured with appropriate API keys on their system path. The suite then allows for comprehensive evaluation across a grid of models and test cases, producing detailed reports on agent performance. It supports both frontier API models and locally-pulled Ollama Cloud models, with automatic resume functionality for ongoing evaluations.
