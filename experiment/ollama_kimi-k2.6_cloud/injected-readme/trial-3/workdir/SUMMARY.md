Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation DSL that compiles down to optimized Rust. The tool is aimed at mid-size data teams of five to fifty engineers who are currently juggling Airflow, Flink, and custom Python scripts to handle event volumes exceeding one billion per day. Installation is straightforward: just run pip install datapipe-core, or choose datapipe[all] if you want the complete set of connectors. Datapipe helps these teams replace their patchwork of tools with a single, reliable framework that scales. It is released under the MIT license.
