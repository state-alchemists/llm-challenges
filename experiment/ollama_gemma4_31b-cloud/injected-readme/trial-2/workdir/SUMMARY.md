Datapipe is an open-source streaming ETL framework built with Rust and Python bindings for high-performance data movement. It allows data engineers to shift billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The system features over 40 pre-built connectors and ensures exactly-once delivery via a two-phase commit process. It is specifically designed for mid-size data teams handling massive event volumes who want to replace fragmented pipelines of Airflow and Flink. Users can get started quickly by installing the core library via pip. For those needing the complete set of connectors, the full pack is also available.
