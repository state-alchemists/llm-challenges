Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers moving billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, delivers exactly-once semantics through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of 5 to 50 engineers who currently maintain a patchwork of Airflow, Flink, and custom Python jobs and need a unified, high-throughput pipeline. Installation is straightforward — run `pip install datapipe-core` for the core library, or `pip install datapipe[all]` to get the full connector pack. Datapipe is released under the MIT license.
