Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers moving billions of events per day between Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so teams can wire up pipelines without writing custom connector code. Exactly-once delivery semantics are handled through a two-phase commit protocol, and a declarative transformation DSL compiles down to optimized Rust at runtime. The target audience is mid-size data teams of 5 to 50 engineers who currently manage a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is as simple as running `pip install datapipe-core`; for the full connector pack, install `datapipe[all]`. Licensed under MIT, Datapipe gives teams a single, coherent framework to replace their fragmented streaming infrastructure.
