Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between popular data systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it easy to connect to the tools teams already use. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in distributed environments. The framework includes a declarative transformation DSL that compiles to optimized Rust, allowing engineers to express complex data transformations efficiently. It is aimed at mid-size data teams of 5 to 50 engineers handling event volumes in the billions per day, who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installing Datapipe is straightforward: run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` to include the full connector pack with all available integrations.
