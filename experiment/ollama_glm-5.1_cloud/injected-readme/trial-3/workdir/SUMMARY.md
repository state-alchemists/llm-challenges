Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high performance. The framework targets mid-size data teams of 5–50 engineers handling 1B+ daily events who currently rely on a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all]. Datapipe is licensed under MIT and is ready for production workloads where throughput and correctness are non-negotiable.
