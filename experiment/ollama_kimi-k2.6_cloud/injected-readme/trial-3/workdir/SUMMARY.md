Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, giving data engineers a fast, reliable way to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over forty pre-built connectors and exactly-once delivery guarantees, so teams can stop writing custom integration code. A declarative transformation DSL compiles straight to optimized Rust, keeping pipelines expressive and blazingly fast. Datapipe is purpose-built for mid-sized data teams of five to fifty engineers who are tired of stitching together Airflow, Flink, and one-off Python scripts to handle high-volume workloads. Getting started is as easy as installing datapipe-core through pip, and you can unlock the full connector pack with a single extra flag. Whether you are modernizing a patchwork data stack or launching a new pipeline, Datapipe gives you a unified platform that scales with your ambition.
