Datapipe is a high-performance open-source streaming ETL framework, built with Rust and offering Python bindings. It caters to mid-sized data teams managing over a billion events daily, providing a robust alternative to custom-built data pipelines. The framework includes more than 40 pre-built connectors for popular data stores like Kafka, S3, Postgres, and ClickHouse, ensuring exactly-once delivery through two-phase commit. Its declarative transformation language compiles directly to optimized Rust, simplifying complex data movements. Installation is straightforward via `pip install datapipe-core`, with an option for a full connector pack using `datapipe[all]`.
