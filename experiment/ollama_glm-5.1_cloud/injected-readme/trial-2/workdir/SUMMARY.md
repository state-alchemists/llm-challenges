Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high performance. The framework targets mid-size data teams of 5 to 50 engineers handling 1B+ events daily, especially those currently juggling a patchwork of Airflow, Flink, and ad-hoc Python jobs. Getting started is straightforward — install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all]. By combining Rust-level throughput with a Python-friendly interface, Datapipe lets teams replace fragmented pipelines with a single, declarative, production-grade framework.
