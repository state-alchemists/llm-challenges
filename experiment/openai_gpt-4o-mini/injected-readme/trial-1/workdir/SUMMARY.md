Datapipe is an open-source streaming ETL framework tailored for data engineers handling large volumes of events. Written in Rust with Python bindings, it enables the seamless transfer of billions of events daily among systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. With over 40 pre-built connectors, Datapipe guarantees exactly-once delivery using two-phase commit semantics. Additionally, it features a declarative transformation DSL that compiles down to efficient Rust. Ideal for mid-size data teams of 5-50 engineers, Datapipe is designed for those managing event volumes exceeding 1 billion events per day. To install, simply run 'pip install datapipe-core', or for the complete connector pack, use 'pip install datapipe[all]'. When ready to leverage its capabilities, Datapipe will streamline your data workflows and enhance productivity.
