Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data engineers move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The tool is aimed at mid-size data teams of 5 to 50 engineers who are handling event volumes exceeding one billion per day and are currently juggling a mix of Airflow, Flink, and custom Python jobs. You can get started quickly by installing the core package with pip, or choose the full connector pack for broader integration support. With its focus on eliminating boilerplate and ensuring reliable data movement, Datapipe lets teams scale their pipelines without scaling their maintenance burden.
