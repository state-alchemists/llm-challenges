Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to streamline data movement for high-volume event processing. It empowers data engineers to transfer billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse without needing to develop custom connector code. The framework comes equipped with over 40 pre-built source/sink connectors, guarantees exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles to highly optimized Rust code. Datapipe is ideal for mid-sized data teams, typically 5-50 engineers, who manage more than one billion events daily and seek to replace complex setups involving Airflow, Flink, and custom Python scripts. Installation is straightforward: users can integrate the core framework by running `pip install datapipe-core`, with an option to install `datapipe[all]` for the complete connector suite. This solution aims to simplify and enhance the efficiency of their data infrastructure.
