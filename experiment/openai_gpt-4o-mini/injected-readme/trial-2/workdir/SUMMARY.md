Datapipe is an open-source streaming ETL framework designed for data engineers who need to efficiently transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse without coding custom connectors. It features over 40 pre-built source and sink connectors and ensures exactly-once delivery semantics through two-phase commit. Additionally, Datapipe includes a declarative transformation DSL that compiles to optimized Rust for performance. The framework targets mid-size data teams, typically with 5 to 50 engineers, managing high event volumes exceeding 1 billion per day. Installation is straightforward with a single command: `pip install datapipe-core`, or use `datapipe[all]` for the complete connector pack.
