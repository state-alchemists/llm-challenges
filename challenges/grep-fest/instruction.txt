This codebase still uses a deprecated authentication function `legacy_auth`
in dozens of places. Migrate every call site to the new `new_auth` function.

Both functions are defined in `app/auth.py`. The signature change is:

```python
# OLD
legacy_auth(user_id)                     -> bool

# NEW
new_auth(user_id, scope="read")          -> bool
```

For every call site:
- Replace `legacy_auth(<user>)` with `new_auth(<user>, scope="read")`.
- If the surrounding code clearly does a write/mutation (look for nearby
  `create_`, `update_`, `delete_`, `save_`, `write_`, or `POST`/`PUT`/`PATCH`
  HTTP verbs in the same function), use `scope="write"` instead.

  call sites within this repo after your migration.
