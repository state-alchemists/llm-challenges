Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so teams can stop writing custom glue code and focus on their data pipelines instead. Datapipe delivers exactly-once processing semantics through two-phase commit, and its declarative transformation DSL compiles directly to optimized Rust for performance. The framework is built for mid-size data teams of 5 to 50 engineers running event volumes above one billion events per day who currently patch together Airflow, Flink, and bespoke Python jobs. Getting started is as simple as running pip install datapipe-core, or pip install datapipe[all] for the full connector suite. Datapipe is MIT-licensed and ready for production use.
