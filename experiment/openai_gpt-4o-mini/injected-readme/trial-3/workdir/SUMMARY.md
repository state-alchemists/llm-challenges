Datapipe is an open-source streaming ETL framework crafted in Rust, featuring Python bindings. It is tailored for data engineers who need to handle the transfer of billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without the hassle of creating custom connector code. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery through a two-phase commit mechanism. Additionally, it includes a declarative transformation DSL that compiles into optimized Rust code. Installation is straightforward with the command 'pip install datapipe-core', and for those requiring the complete connector pack, the command is 'pip install datapipe[all]'. This framework is ideal for mid-size data teams managing an event volume exceeding 1 billion events per day.
