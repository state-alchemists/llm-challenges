Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it easy to connect to the most common data infrastructure without starting from scratch. The framework provides exactly-once delivery semantics through two-phase commit, ensuring data reliability even in distributed environments. It also includes a declarative transformation DSL that compiles to optimized Rust, allowing engineers to define transformations in a simple, readable way while benefiting from Rust's performance. Datapipe is aimed at mid-size data teams of five to fifty engineers handling event volumes in the billion-plus range per day, who are currently managing a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a base package available as datapipe-core and a full connector pack available as datapipe[all]. The project is open-source and released under the MIT license.
