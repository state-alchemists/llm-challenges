Datapipe is a powerful open-source streaming ETL framework built in Rust with Python bindings, designed to handle billions of events per day. It is the ideal solution for mid-size data engineering teams who need to move massive volumes of data between Kafka, S3, Postgres, and ClickHouse without the burden of writing custom connector code. The framework provides over 40 pre-built connectors and ensures reliability through exactly-once delivery semantics. Users can leverage a declarative transformation DSL that compiles directly to optimized Rust for maximum performance. To get started, simply run pip install datapipe-core, or use pip install datapipe[all] for the complete connector suite. Datapipe eliminates the need for maintaining complex patchworks of disparate data tools.
