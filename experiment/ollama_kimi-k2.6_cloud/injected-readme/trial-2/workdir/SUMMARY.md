Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to reliably move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse. It comes with more than forty pre-built source and sink connectors, so you can stop writing custom connector code and start shipping pipelines faster. Built-in exactly-once delivery semantics keep your data accurate, while a declarative transformation DSL compiles down to optimized Rust for serious performance. Datapipe is built for mid-size data teams of five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs at the billion-events-per-day scale. Getting started is as simple as installing the core package with pip. If you want the complete connector pack, you can install the full extras instead.
