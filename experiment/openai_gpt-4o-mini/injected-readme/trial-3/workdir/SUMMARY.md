Datapipe is an open-source streaming ETL framework written in Rust, featuring Python bindings. It caters specifically to data engineers who need to transfer billions of events daily among platforms like Kafka, S3, Postgres, and ClickHouse without the hassle of custom connector code. The framework includes over 40 pre-built source and sink connectors, ensuring exactly-once delivery semantics through a two-phase commit mechanism. Additionally, Datapipe provides a declarative transformation DSL that compiles to optimized Rust code for enhanced performance. Installation is straightforward; simply run 'pip install datapipe-core', and for the complete connector pack, use 'datapipe[all]'. This tool is ideal for mid-sized data teams involving 5 to 50 engineers handling event volumes exceeding one billion events per day.
