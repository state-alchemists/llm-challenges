Datapipe is a high-performance, open-source streaming ETL framework written in Rust with Python bindings, built to streamline modern data pipelines. It is designed for mid-size data teams handling massive event volumes of over one billion events per day who want to replace complex, patchwork architectures with a unified solution. Instead of writing custom connector code, data engineers can easily move events between Kafka, S3, Postgres, and ClickHouse using more than forty pre-built source and sink connectors. The framework ensures reliable data delivery with exactly-once delivery semantics and optimizes execution through a declarative transformation language that compiles to Rust. Setting up the platform is simple and can be completed by running pip install datapipe-core or pip install datapipe[all] for the full suite of connectors. By unifying and accelerating streaming operations, Datapipe helps engineering teams eliminate bespoke pipeline maintenance and focus on delivering high-quality data.
