Datapipe is an open-source, high-performance streaming ETL framework written in Rust that features intuitive Python bindings. Designed to streamline data movement, it allows teams to seamlessly transfer billions of events per day between popular platforms like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework comes equipped with over forty pre-built source and sink connectors, robust exactly-once delivery guarantees, and a declarative transformation DSL that compiles directly to optimized Rust. It is specifically tailored for mid-size data teams of five to fifty engineers who handle massive real-time event volumes and want to simplify their patchwork of Airflow, Flink, and bespoke Python scripts. Setting up the framework is quick and easy using the standard Python package installer. Engineers can install the core package to get started immediately, or choose the complete installation with all pre-packaged connectors included.
