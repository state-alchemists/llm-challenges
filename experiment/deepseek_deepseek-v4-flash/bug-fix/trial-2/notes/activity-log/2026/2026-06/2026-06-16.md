## 18:16 — Bug fix: job queue duplicate processing + vanishing failures
**Request**: Find root causes and fix duplicate processing and vanishing failures in a background job processor.
**Skills used**: core-coding
**Actions**:
- Fixed `job_queue.py:dequeue` — swapped `await asyncio.sleep(0.01)` to *after* the status assignment (`job["status"] = "processing"`). Previously the sleep sat between the status check and the assignment, creating a race window where all concurrent workers saw "pending" and claimed the same job.
- Fixed `worker.py:process_job` — added `queue.fail(job["id"], str(e))` call in the `except` block. Previously the exception was caught and logged but the queue was never notified, leaving jobs stuck in "processing" forever.
**Outcome**: completed. Running `main.py` shows Done: 10, Failed: 2, Stuck: 0 — all matching expectations. No duplicate processing observed.
