Datapipe is a high-performance, open-source streaming ETL framework written in Rust with convenient Python bindings. This powerful tool is purpose-built for data engineers who need to seamlessly move billions of daily events between critical systems like Kafka, S3, Postgres, and ClickHouse without writing any custom connector code. The platform comes equipped with over forty pre-built source and sink connectors to simplify data movement across your stack. By providing exactly-once delivery semantics via two-phase commits and a declarative transformation language that compiles down to highly optimized Rust, Datapipe ensures both reliability and outstanding performance. It is specifically designed for mid-size data teams of five to fifty engineers running massive event pipelines who want to transition away from maintaining a complex patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward, as you can install the core package by running pip install datapipe-core, or access the entire suite of connectors using datapipe[all].
