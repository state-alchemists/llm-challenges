Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect their data infrastructure out of the box rather than building and maintaining bespoke integrations. Datapipe guarantees exactly-once delivery through a two-phase commit protocol, ensuring data integrity even in distributed, high-throughput environments. Its declarative transformation DSL compiles to optimized Rust, giving teams the expressiveness of a domain-specific language with the performance of a compiled systems language. Installation is straightforward via pip, with a core package for lightweight use and a full connector pack available for teams that need every integration. Datapipe is aimed at mid-size data teams of five to fifty engineers processing over one billion events daily who are currently juggling multiple tools like Airflow, Flink, and custom Python jobs to achieve similar results.
