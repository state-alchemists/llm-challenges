Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to reliably move billions of events every day. It ships with more than forty pre-built connectors for systems like Kafka, S3, Postgres, and ClickHouse, so you can wire up pipelines without writing custom connector code. Built-in exactly-once delivery semantics and a declarative transformation DSL that compiles to optimized Rust keep your data accurate and your throughput high. It is designed for mid-sized data teams of five to fifty engineers who are currently juggling a mix of Airflow, Flink, and bespoke Python jobs at serious scale. Getting started is simple: install the core package with pip and add the full connector pack whenever you are ready to expand. Whether you are replacing a fragile patchwork of tools or building a new streaming platform from scratch, Datapipe gives you the speed of Rust with the flexibility of Python.
