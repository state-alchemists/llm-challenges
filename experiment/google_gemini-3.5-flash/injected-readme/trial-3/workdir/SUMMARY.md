Datapipe is an open-source streaming ETL framework written in Rust with Python bindings designed to seamlessly move billions of events per day between Kafka, S3, Postgres, and ClickHouse without custom connector code. It features over forty pre-built source and sink connectors, guarantees exactly-once delivery semantics using a robust two-phase commit protocol, and includes a declarative transformation DSL that compiles directly to optimized Rust. This high-performance tool is purpose-built for data engineers and mid-sized data teams of five to fifty engineers managing event volumes exceeding one billion daily events. It is the perfect upgrade for teams currently struggling to maintain a fragmented patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is simple, as you can easily install the core package by running pip install datapipe-core in your terminal. To unlock the complete suite of integration capabilities, you can install the full connector pack with the datapipe[all] package option.
