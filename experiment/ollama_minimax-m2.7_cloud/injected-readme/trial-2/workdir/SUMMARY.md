Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data platforms out of the box rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, which is critical for workloads where data integrity cannot be compromised. The framework includes a declarative transformation DSL that compiles down to optimized Rust, giving engineers a productive high-level interface while still benefiting from Rust's performance. It is aimed at mid-sized data teams of five to fifty engineers handling event volumes in the billions per day, often those who are currently juggling Airflow, Flink, and hand-rolled Python jobs to keep their pipelines running. To get started, install the core package with `pip install datapipe-core` or get the full connector pack with `pip install datapipe[all]`. Datapipe is released under the MIT license.
