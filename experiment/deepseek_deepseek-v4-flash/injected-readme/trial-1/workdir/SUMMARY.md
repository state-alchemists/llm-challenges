Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than 40 pre-built source and sink connectors, exactly-once delivery semantics backed by two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. Datapipe is aimed at mid-size data teams of 5 to 50 engineers running event volumes above one billion events per day, especially those currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is a single command: pip install datapipe-core, with datapipe[all] available for teams that want the full connector pack. The project is released under the MIT license.
