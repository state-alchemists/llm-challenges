Datapipe is an open-source streaming ETL framework written in Rust with high-performance Python bindings. It is specifically designed to help data engineers seamlessly move billions of daily events across Kafka, S3, Postgres, and ClickHouse without having to write any custom connector code. The platform simplifies complex data pipelines by offering over forty pre-built source and sink connectors alongside guaranteed exactly-once delivery semantics. Additionally, a declarative transformation DSL compiles directly into highly optimized Rust for maximum execution speed. This solution is ideal for mid-sized data teams running large-scale event operations who want to replace their fragmented patchwork of tools like Airflow, Flink, and custom Python scripts. Getting started is straightforward, as users can install the core package using the standard Python package manager. For those requiring the complete suite of connectors, the full package can be installed with a single extended command.
