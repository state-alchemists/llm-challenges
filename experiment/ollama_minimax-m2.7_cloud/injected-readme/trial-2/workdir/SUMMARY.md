Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it easy to connect popular data infrastructure out of the box. The framework provides exactly-once delivery semantics using a two-phase commit protocol, ensuring data integrity across pipelines. A declarative transformation DSL compiles to optimized Rust, giving teams a productive way to define data transformations that run at high performance. Datapipe targets mid-sized data teams of five to fifty engineers processing one billion or more events daily who currently juggle a mix of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip: run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` to include the full connector pack.
