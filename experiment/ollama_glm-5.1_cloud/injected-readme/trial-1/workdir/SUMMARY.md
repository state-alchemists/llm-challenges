Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework targets mid-size data teams of 5–50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs and need a unified, performant alternative. Getting started is straightforward: install the core library with pip install datapipe-core, or pull in the full connector pack with datapipe[all] for access to every available integration. Datapipe is released under the MIT license.
