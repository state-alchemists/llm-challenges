Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It comes with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs to handle event volumes in the billions per day. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. Datapipe is released under the MIT license.
