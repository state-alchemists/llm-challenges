Datapipe is an open-source streaming ETL framework developed in Rust with Python bindings. It empowers data engineers to efficiently transfer billions of events daily among Kafka, S3, Postgres, and ClickHouse without needing custom connector code. The framework includes over 40 pre-built source and sink connectors, and supports exactly-once delivery semantics through a two-phase commit process. Additionally, it features a declarative transformation DSL that compiles into optimized Rust code. Datapipe is particularly suited for mid-sized data teams of 5-50 engineers that handle more than a billion events each day, typically using a mix of Airflow, Flink, and ad-hoc Python jobs.
