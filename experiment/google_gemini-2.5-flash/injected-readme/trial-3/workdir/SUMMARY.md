Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to efficiently move billions of events daily between various data systems like Kafka, S3, Postgres, and ClickHouse. It provides a robust solution for data engineers, eliminating the need for custom connector development through its 40+ pre-built connectors and declarative transformation language. The framework ensures data integrity with exactly-once delivery semantics via a two-phase commit system. Datapipe is ideal for mid-sized data teams, typically 5-50 engineers, who handle over a billion events per day and seek to streamline complex data pipelines often managed with a mix of Airflow, Flink, and custom Python scripts. Installation is straightforward using `pip install datapipe-core`, with an option to install `datapipe[all]` for the complete connector suite.
