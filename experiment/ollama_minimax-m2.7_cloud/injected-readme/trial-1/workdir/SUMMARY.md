Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors, exactly-once delivery semantics using two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The framework targets mid-size data teams of 5 to 50 engineers handling event volumes in the billion-plus per day range, replacing patchwork solutions involving Airflow, Flink, and bespoke Python jobs. Installation is straightforward via pip, with a core package available as `pip install datapipe-core` and a full connector pack available as `pip install datapipe[all]`. Datapipe is released under the MIT license.
