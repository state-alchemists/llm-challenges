Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to handle billions of events daily. It facilitates seamless data movement between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery semantics using a two-phase commit system. It also features a declarative transformation DSL that compiles to optimized Rust, streamlining the data processing workflow. Installation is straightforward: simply run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` to include the full connector pack. This framework is particularly suitable for mid-size data teams managing event volumes exceeding one billion events per day.
