Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed to streamline data movement for engineering teams. It allows users to easily transfer billions of events per day between Kafka, Amazon S3, Postgres, and ClickHouse without writing any custom connector code. The platform is equipped with over forty pre-built source and sink connectors, ensures exactly-once delivery semantics via two-phase commit, and features a declarative transformation domain-specific language that compiles directly to highly optimized Rust code. It is ideally suited for mid-sized data teams of five to fifty engineers managing massive event volumes who are currently maintaining a complex patchwork of Airflow, Flink, and custom Python jobs. Getting started is simple, as you can quickly install the core package using the standard pip package manager by installing datapipe-core. For teams requiring the complete set of connectors, the comprehensive pack can be installed by specifying datapipe with the all option.
