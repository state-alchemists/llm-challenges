Datapipe is an open-source streaming ETL framework built with Rust and Python bindings, designed to help data engineers efficiently move massive volumes of event data. It provides over 40 pre-built connectors for popular data sources like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework ensures exactly-once delivery through two-phase commit and features a declarative transformation language that compiles into optimized Rust code. Datapipe is ideal for mid-size data teams handling over a billion events daily, especially those currently managing complex data pipelines with a mix of Airflow, Flink, and custom Python scripts. To get started, users can install the core library via `pip install datapipe-core`, with an option for a full connector pack using `datapipe[all]`.
