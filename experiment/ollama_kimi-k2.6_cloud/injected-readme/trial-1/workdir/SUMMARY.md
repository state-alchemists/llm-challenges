Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events every day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework is built for data engineers and mid-sized data teams—roughly 5 to 50 engineers—who handle event volumes exceeding one billion per day and currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Datapipe replaces that fragile mosaic with a single, reliable platform so teams can focus on insights instead of infrastructure plumbing. You can install the core library by running pip install datapipe-core in your terminal. For the full suite of connectors, use pip install datapipe[all].
