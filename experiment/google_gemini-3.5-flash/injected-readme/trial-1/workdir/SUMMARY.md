Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that is designed to help data engineers move billions of events per day without writing custom connector code. It seamlessly connects various popular data systems, including Kafka, S3, Postgres, and ClickHouse, using over forty pre-built source and sink connectors. By utilizing two-phase commit protocols, the framework ensures exactly-once delivery semantics for reliable and accurate data transfer. Additionally, its declarative transformation language compiles directly to optimized Rust to guarantee high-performance data processing. This platform is specifically tailored for mid-size data teams of five to fifty engineers managing event volumes in the one billion plus events per day range. Getting started with the framework is straightforward as you can install the core package using the standard Python pip tool with the datapipe-core package name. For teams requiring the complete set of pre-built integrations, installing the datapipe package with the all extra option will set up everything needed to begin.
