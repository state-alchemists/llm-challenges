Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with more than forty pre-built source and sink connectors, so you rarely have to write custom connector code. Under the hood it guarantees exactly-once delivery semantics through a two-phase commit, and it gives you a declarative transformation DSL that compiles down to optimized Rust for high throughput. Datapipe is aimed at mid-size data teams with five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes north of one billion per day. Getting started is simple: install the core package with pip, or grab the full connector pack if you want everything out of the box.
