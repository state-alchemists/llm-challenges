Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that moves billions of events per day across Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is designed for mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes exceeding one billion events per day. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all] for access to every integration out of the box. Datapipe replaces fragile custom pipelines with a single declarative framework, letting engineers focus on data logic instead of connector maintenance. It is released under the permissive MIT license.
