Datapipe is an open-source streaming ETL framework created for data engineers needing to transfer billions of events daily between systems such as Kafka, S3, Postgres, and ClickHouse without custom connector coding. It includes over 40 pre-built source and sink connectors and guarantees exactly-once delivery through two-phase commit. The framework also features a declarative transformation DSL compiled to optimized Rust. To install, users can simply run the command 'pip install datapipe-core', and to access the complete set of connectors, they should use 'datapipe[all]'. Datapipe targets mid-size data teams managing extensive event volumes who typically maintain a mix of Airflow, Flink, and custom Python jobs.
