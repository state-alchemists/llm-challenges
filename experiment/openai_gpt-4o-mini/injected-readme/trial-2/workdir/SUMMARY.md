Datapipe is an open-source streaming ETL framework designed specifically for data engineers. Built in Rust with Python bindings, it allows users to efficiently move billions of events per day between platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. With over 40 pre-built connectors and exactly-once delivery semantics via a two-phase commit, it offers a robust solution for managing high event volumes. The framework also features a declarative transformation DSL that compiles to optimized Rust, enhancing performance. Installation is straightforward with the command 'pip install datapipe-core', or use 'datapipe[all]' for the full connector pack. Ideal for mid-size data teams managing event loads of over 1 billion daily, Datapipe streamlines data workflows by consolidating various tools into one efficient system.
