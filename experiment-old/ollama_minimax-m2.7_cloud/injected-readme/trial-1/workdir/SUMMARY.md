Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it practical for teams that want to avoid building and maintaining their own integration components. The framework provides exactly-once delivery semantics through a two-phase commit mechanism, which is critical for data pipelines where duplicate or lost events would cause problems. Datapipe also includes a declarative transformation DSL that compiles to optimized Rust, allowing engineers to define data transformations in a readable way while still achieving high performance. The tool targets mid-size data teams of roughly 5 to 50 engineers running event volumes in the billion-plus range per day, who currently rely on a patchwork of scheduling and processing tools like Airflow, Flink, and bespoke Python jobs. Installation is straightforward via pip, with the core package installed as `datapipe-core` and the full connector pack available as `datapipe[all]`. Datapipe is released under the MIT license.
