Datapipe is an open-source streaming ETL framework designed to help data engineers move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without writing any custom connector code. Written in Rust with Python bindings, the framework includes over forty pre-built source and sink connectors alongside exactly-once delivery semantics via two-phase commit. It also features a declarative transformation domain-specific language that compiles directly into optimized Rust for maximum performance. This platform is specifically tailored for mid-size data teams of five to fifty engineers managing massive event volumes who are looking to replace complex pipelines built on Airflow, Flink, or custom Python scripts. Getting started with the framework is straightforward and can be accomplished by installing the core datapipe package using Python's standard package installer. For teams requiring the complete suite of integration connectors, installing the all-inclusive package option provides full capabilities immediately.
