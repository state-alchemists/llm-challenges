Datapipe is an open-source streaming ETL framework designed for data engineers who need to move billions of events daily. It allows for seamless data movement between Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. Built in Rust with Python bindings, the framework offers over 40 pre-built connectors and ensures exactly-once delivery semantics. It is specifically tailored for mid-size data teams managing high event volumes who want to replace a patchwork of fragmented jobs with a unified system. Users can get started quickly by installing the core package via pip. For full functionality, the complete connector pack is available through the installation of datapipe[all].
