Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors, so teams can start streaming data immediately rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in complex distributed pipelines. Its declarative transformation DSL compiles to optimized Rust, giving users the performance of a compiled language while writing simple, readable configuration. The project is aimed at mid-size data teams of five to fifty engineers processing over one billion events daily who currently juggle a mix of Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with the core package installed as `pip install datapipe-core` and the full connector pack available as `pip install datapipe[all]`.
