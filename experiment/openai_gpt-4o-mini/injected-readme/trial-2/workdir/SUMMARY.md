Datapipe is an open-source streaming ETL framework that utilizes Rust and offers Python bindings. It caters specifically to data engineers looking to efficiently transfer billions of events daily between platforms such as Kafka, S3, Postgres, and ClickHouse without the need to write custom connector code. With over 40 pre-built source and sink connectors, Datapipe guarantees exactly-once delivery through its two-phase commit system. Furthermore, it features a declarative transformation DSL that compiles to optimized Rust code. Installation is straightforward: simply run `pip install datapipe-core`, or for the complete connector pack, use `datapipe[all]`. The framework is especially beneficial for mid-sized data teams generating more than 1 billion events per day, who may be struggling with a combination of other tools like Airflow and Flink.
