Datapipe is an open-source streaming ETL (Extract, Transform, Load) framework, built with Rust for high performance and offering convenient Python bindings. It helps data engineers efficiently move massive volumes of event data daily between various systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework includes over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and uses a declarative transformation language that compiles into optimized Rust code. It is ideal for mid-sized data teams (5-50 engineers) managing over a billion events per day, particularly those currently relying on a mix of Airflow, Flink, and custom Python solutions. To install, simply run `pip install datapipe-core`, or `pip install datapipe[all]` for the complete connector suite.
