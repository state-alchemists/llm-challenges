Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so you can skip custom integration code and focus on building pipelines instead. The framework guarantees exactly-once delivery semantics through a two-phase commit protocol, and its declarative transformation DSL compiles to optimized Rust for high-throughput performance. Datapipe is designed for mid-size data teams of five to fifty engineers who are currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs at the one-billion-plus events per day scale. To get started, install the core package with pip install datapipe-core, or install datapipe[all] to unlock the complete connector pack. If you are looking to replace fragile job orchestration with a single, fast, and reliable streaming platform, Datapipe gives you the speed of Rust and the flexibility of Python in one cohesive tool.
