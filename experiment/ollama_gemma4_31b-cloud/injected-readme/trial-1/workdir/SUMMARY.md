Datapipe is a powerful open-source streaming ETL framework built in Rust with convenient Python bindings. It is designed for data engineers who need to move billions of events daily across Kafka, S3, Postgres, and ClickHouse without the hassle of writing custom connector code. The platform features over 40 pre-built connectors, guaranteed exactly-once delivery, and a declarative transformation language that compiles to optimized Rust for maximum performance. It is the ideal solution for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke scripts. Getting started is simple by running pip install datapipe-core. For teams requiring the full suite of connectivity, the complete connector pack is available via pip install datapipe[all].
