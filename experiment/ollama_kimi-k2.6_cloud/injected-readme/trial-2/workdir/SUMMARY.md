Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data engineers move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than forty pre-built source and sink connectors, exactly-once delivery semantics backed by two-phase commit, and a declarative transformation language that compiles down to optimized Rust. The framework is built for mid-sized data teams of five to fifty engineers who are currently juggling a mix of Airflow, Flink, and custom Python jobs to handle event volumes exceeding one billion per day. Getting started is simple: install the core package with pip and optionally add the full connector pack for access to every integration. Datapipe replaces brittle glue code with a fast, reliable, and maintainable foundation so your team can focus on insights instead of infrastructure.
