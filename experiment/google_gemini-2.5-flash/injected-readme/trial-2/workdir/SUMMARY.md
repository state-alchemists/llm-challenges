Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to efficiently move billions of events daily. It connects various data sources like Kafka, S3, Postgres, and ClickHouse using over 40 pre-built connectors. The framework ensures exactly-once delivery through two-phase commit and allows for declarative data transformations. Datapipe is ideal for mid-size data engineering teams managing high event volumes who seek to streamline complex data pipelines. Installation is straightforward with `pip install datapipe-core`, or `datapipe[all]` for comprehensive connector support.
