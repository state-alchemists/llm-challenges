Datapipe is a powerful open-source streaming ETL framework, built with Rust for performance and offering convenient Python bindings. It empowers data engineers to seamlessly move massive volumes of data, exceeding a billion events daily, across popular platforms like Kafka, S3, Postgres, and ClickHouse, all without the need for custom connector development. The framework boasts over 40 pre-built source and sink connectors, ensures exactly-once delivery through two-phase commit, and provides a declarative transformation language that compiles directly into optimized Rust code. Datapipe is ideal for mid-sized data teams, typically with 5 to 50 engineers, who are managing high event throughput and are looking to consolidate disparate data pipelines currently handled by tools like Airflow, Flink, or custom Python scripts. Installation is straightforward: users can simply `pip install datapipe-core`, with an optional `datapipe[all]` for the complete suite of connectors.
