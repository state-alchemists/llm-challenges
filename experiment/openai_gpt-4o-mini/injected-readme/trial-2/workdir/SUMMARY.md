Datapipe is an open-source streaming ETL framework designed for data engineers aiming to facilitate the movement of billions of events daily between platforms such as Kafka, S3, Postgres, and ClickHouse without the need for custom connector coding. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery through two-phase commit processes and offers a declarative transformation DSL that compiles into optimized Rust code. It targets mid-sized data teams consisting of 5 to 50 engineers who typically handle over a billion events per day and are currently reliant on a mixture of Airflow, Flink, and customized Python jobs. Installing Datapipe is straightforward; simply use the command 'pip install datapipe-core'. For access to the entire suite of connectors, users should install with 'datapipe[all]'.
