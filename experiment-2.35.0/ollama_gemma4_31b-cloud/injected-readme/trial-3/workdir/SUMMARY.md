Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events daily between major data stores like Kafka, S3, Postgres, and ClickHouse. It is specifically built for mid-size data teams who need to replace complex patchworks of legacy jobs with a high-performance, unified system. The framework features over 40 pre-built connectors and ensures exactly-once delivery semantics via a two-phase commit process. Users can leverage a declarative transformation DSL that compiles directly to optimized Rust for maximum efficiency. To get started, simply install the core library using pip install datapipe-core. For those requiring the full suite of connectivity, the datapipe[all] package is available.
