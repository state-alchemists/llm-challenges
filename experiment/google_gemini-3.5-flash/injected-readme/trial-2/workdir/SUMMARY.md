Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that enables users to effortlessly move billions of events per day between Kafka, S3, Postgres, and ClickHouse. It eliminates the need for writing custom connector code by offering over forty pre-built source and sink connectors alongside a declarative transformation DSL that compiles to highly optimized Rust. This framework is specifically designed for mid-sized data teams of five to fifty engineers who handle massive event volumes and are looking to replace their complex setups of Airflow, Flink, and bespoke Python jobs. Teams can achieve reliable exactly-once delivery semantics through robust two-phase commit protocols. To get started, developers can quickly install the core library via Python's package manager using the pip install datapipe-core command. For full capabilities, the comprehensive package can be installed by running pip install datapipe with the all option.
