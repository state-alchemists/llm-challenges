Datapipe is an open-source streaming ETL framework built with Rust and Python that simplifies high-volume data movement. It is designed for data engineers at mid-size teams who manage billions of daily events across Kafka, S3, Postgres, and ClickHouse. By providing over 40 pre-built connectors and a declarative transformation DSL, it eliminates the need for custom connector code. The platform ensures reliability with exactly-once delivery semantics via two-phase commit. To get started, simply run pip install datapipe-core in your terminal. For teams requiring the complete suite of connectors, the full pack is available via pip install datapipe[all].
