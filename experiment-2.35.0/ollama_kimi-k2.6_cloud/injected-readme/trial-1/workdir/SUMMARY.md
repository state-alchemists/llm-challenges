Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It helps data engineers move billions of events every day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework includes more than forty pre-built source and sink connectors, exactly-once delivery semantics backed by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. It is aimed at mid-size data teams of five to fifty engineers who are currently juggling Airflow, Flink, and one-off Python scripts to handle event volumes exceeding one billion per day. You can get started by installing the core package with pip. For the complete set of connectors, install the full extras pack instead.
