Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that lets data engineers move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over forty pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is aimed at mid-size data teams handling a billion or more events daily who are currently juggling a patchwork of Airflow, Flink, and hand-rolled Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all] for all integrations out of the box. Datapipe is licensed under MIT, making it free to use and adapt in any project.
