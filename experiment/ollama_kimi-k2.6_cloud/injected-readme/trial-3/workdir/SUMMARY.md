Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data teams move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than forty pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The tool is aimed at mid-size data teams of five to fifty engineers who are currently juggling Airflow, Flink, and bespoke Python scripts to handle event volumes exceeding one billion events per day. Getting started is simple: install the core package with pip, or choose the full connector pack if you need the complete set of integrations. Datapipe is released under the MIT license, making it free to use and modify for both commercial and internal projects.
