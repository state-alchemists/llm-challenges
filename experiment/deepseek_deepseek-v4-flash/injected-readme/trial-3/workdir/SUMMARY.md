Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to reliably move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so teams can wire up pipelines without writing custom connector code. Datapipe guarantees exactly-once delivery through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for high performance. The framework is built for mid-size data teams of 5 to 50 engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs to handle event volumes above one billion per day. To get started, install the core library with pip install datapipe-core, or add the full connector pack with pip install datapipe[all]. Datapipe is released under the MIT license.
