Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is built for mid-size data teams of 5 to 50 engineers who are running event volumes in the billion-plus range and want to replace patchworks of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all]. Datapipe is released under the MIT license, making it free to use and adapt for any team looking to simplify their streaming data infrastructure.
