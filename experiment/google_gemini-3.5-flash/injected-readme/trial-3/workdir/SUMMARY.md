Datapipe is a high-performance, open-source streaming ETL framework written in Rust with Python bindings that enables teams to effortlessly move billions of events per day. It solves the complexity of building custom data pipelines by shipping with over forty pre-built source and sink connectors to seamlessly bridge Kafka, S3, Postgres, and ClickHouse. Designed specifically for mid-size data teams of five to fifty engineers managing massive event volumes, Datapipe provides an elegant, unified alternative to maintaining a fragmented patchwork of Airflow, Flink, and bespoke Python jobs. The framework delivers robust exactly-once delivery semantics through two-phase commits and features a declarative transformation domain-specific language that compiles directly into highly optimized Rust. Getting started is simple, as you can install the core library using Python's package installer by running pip install datapipe-core. For teams requiring the complete suite of connectors, the comprehensive package with all connectors can be installed by specifying the all extra option.
