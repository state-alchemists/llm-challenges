Datapipe is an open-source streaming ETL framework, built with Rust and offering Python bindings, designed to streamline data movement for data engineers. It empowers teams to handle billions of events daily across various systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework boasts over 40 pre-built source/sink connectors, guarantees exactly-once delivery through two-phase commit, and features a declarative transformation DSL that compiles into optimized Rust code. It caters to mid-size data teams (5-50 engineers) managing over 1 billion events per day, providing an alternative to maintaining complex setups involving Airflow, Flink, and custom Python scripts. Installation is straightforward, requiring a simple `pip install datapipe-core`, with `datapipe[all]` available for the full suite of connectors.
