Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed to streamline high-throughput data movement without the need for custom connector code. It allows users to seamlessly move billions of events per day between major data platforms like Kafka, S3, Postgres, and Clickhouse. The platform comes equipped with over forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation language that compiles to highly optimized Rust. This solution is tailor-made for mid-size data teams of five to fifty engineers managing massive event volumes who are looking to replace complex, fragmented setups of Airflow, Flink, and bespoke Python jobs. Getting started is as simple as running a single pip command to install the core package. Data teams can also easily install the full suite of connector packages to unlock the platform's complete capabilities instantly.
