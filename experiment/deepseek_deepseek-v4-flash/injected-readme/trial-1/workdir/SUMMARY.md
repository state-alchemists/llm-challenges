Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with over forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. It targets mid-size data teams of five to fifty engineers currently running event volumes in the billion-plus per day range who want to replace a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward — run pip install datapipe-core for the core framework, or pip install datapipe[all] for the full connector pack. Datapipe is released under the MIT license.
