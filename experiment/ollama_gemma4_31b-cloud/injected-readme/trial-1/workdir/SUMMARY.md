Datapipe is an open-source streaming ETL framework that simplifies moving billions of events daily across Kafka, S3, Postgres, and ClickHouse. Built in Rust with Python bindings, it eliminates the need for custom connector code through over 40 pre-built integrations. The platform ensures reliability with exactly-once delivery semantics and an optimized declarative transformation DSL. It is specifically designed for mid-sized data teams managing massive event volumes who want to replace fragmented toolchains. Installation is straightforward via pip install datapipe-core. For users requiring the full suite of connectors, the datapipe[all] package is available.
