Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed for data engineers. It efficiently moves billions of events daily across various data platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework offers over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and includes a declarative transformation language that compiles to optimized Rust code. It caters to mid-sized data teams, typically with 5-50 engineers, who manage over a billion events per day and currently rely on a mix of Airflow, Flink, and custom Python solutions. Installation is straightforward via `pip install datapipe-core`, with an option for `datapipe[all]` to include the full connector pack.
