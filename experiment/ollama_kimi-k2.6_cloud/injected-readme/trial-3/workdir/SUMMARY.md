Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. You can get started quickly by installing the core package with pip, or opt for the full connector pack to unlock every integration out of the box. Datapipe is purpose-built for mid-size data teams of five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python scripts to handle event volumes exceeding one billion events per day. The framework is licensed under MIT, so you can adopt it freely in both internal and commercial environments.
