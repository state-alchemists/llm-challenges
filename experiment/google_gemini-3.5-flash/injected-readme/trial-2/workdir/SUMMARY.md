Datapipe is a high-performance, open-source streaming ETL framework built in Rust with Python bindings for seamless development. Designed for mid-size data teams of five to fifty engineers, it solves the challenge of maintaining a complex patchwork of Airflow, Flink, and custom Python jobs. The platform enables teams to reliably transport billions of daily events between Kafka, S3, Postgres, and ClickHouse without the need to write any custom connector code. It comes equipped with over forty pre-built source and sink connectors, ensures exactly-once delivery semantics through two-phase commits, and includes a declarative transformation language that compiles directly to highly optimized Rust. Getting started is incredibly simple, requiring only a basic pip command to install the core package or the full connector pack.
