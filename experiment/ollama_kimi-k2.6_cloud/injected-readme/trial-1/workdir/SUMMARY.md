Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built connectors, so you don't have to write custom integration code. Datapipe guarantees exactly-once delivery through two-phase commit and offers a declarative transformation DSL that compiles down to optimized Rust for high performance. It is purpose-built for mid-sized data teams of 5 to 50 engineers handling more than a billion events per day, especially those juggling fragmented workflows across Airflow, Flink, and one-off Python scripts. Getting started is simple: just run pip install datapipe-core to get the core framework. If you want the complete set of connectors, install datapipe[all] instead. Licensed under MIT, Datapipe gives high-volume teams a reliable, production-ready way to unify their streaming data pipelines.
