Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers. It efficiently moves billions of events daily across various data sources like Kafka, S3, Postgres, and ClickHouse without requiring custom connector development. The framework features over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and uses a declarative transformation language that compiles to optimized Rust. It is ideal for mid-sized data teams, typically 5-50 engineers, who manage over 1 billion events per day and currently rely on a complex mix of Airflow, Flink, and custom Python jobs. Installation is straightforward: users can `pip install datapipe-core`, or `datapipe[all]` for the complete connector suite.
