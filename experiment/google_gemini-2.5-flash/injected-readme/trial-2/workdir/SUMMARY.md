Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed for efficiently moving vast quantities of data. It serves data engineers managing billions of events daily across various systems like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework provides over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and uses a declarative transformation language that compiles to optimized Rust code. It is ideal for mid-sized data teams (5-50 engineers) processing over a billion events per day who are looking to consolidate complex data pipelines. Installation is straightforward: simply run `pip install datapipe-core`, with an option for `datapipe[all]` to include the full connector pack.
