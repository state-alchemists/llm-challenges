Datapipe is a powerful, open-source streaming ETL framework engineered in Rust with high-performance Python bindings. It enables data engineers to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse without the burden of writing custom connector code. Equipped with over forty pre-built source and sink connectors, the platform guarantees exactly-once delivery semantics using robust two-phase commits. Additionally, users can leverage a declarative transformation domain-specific language that automatically compiles into optimized Rust for lightning-fast performance. This solution is tailor-made for mid-size data teams of five to fifty engineers running massive event pipelines who are looking to replace a complex patchwork of Airflow, Flink, and custom Python scripts. Getting started is simple, as the core library can be quickly installed via pip install datapipe-core. For teams requiring the complete set of connectors, installing datapipe with the all option provides the full connector package instantly.
