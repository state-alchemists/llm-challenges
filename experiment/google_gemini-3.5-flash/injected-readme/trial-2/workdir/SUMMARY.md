Datapipe is an open-source streaming ETL framework designed to seamlessly move billions of events per day across Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. Built in Rust with Python bindings, this high-performance solution offers over forty pre-built source and sink connectors alongside a declarative transformation language that compiles to optimized native code. It ensures robust data integrity and reliability through guaranteed exactly-once delivery semantics using two-phase commits. The framework is specifically tailored for mid-size data teams of five to fifty engineers managing massive event pipelines who want to simplify their patchwork of Airflow, Flink, and custom Python scripts. To get started, you can install the core framework by running the pip install datapipe-core command. For data teams requiring the complete set of pre-built integrations, the full package can be installed by specifying the all option during installation.
