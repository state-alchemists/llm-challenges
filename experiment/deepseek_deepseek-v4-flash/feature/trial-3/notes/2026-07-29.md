- **`app/main.py`**: 
  - `GET /tasks` — added optional `status`, `priority`, `assigned_to` filters + `page` (default 1) and `page_size` (default 20) pagination.

  - `DELETE /tasks/{task_id}` — requires auth, removes from list, returns 404 if not found.
