Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It is designed for data engineers at mid-size teams who manage billions of events daily across Kafka, S3, Postgres, and ClickHouse. By providing over 40 pre-built connectors and a declarative transformation DSL, it eliminates the need for custom connector code. The framework ensures reliability with exactly-once delivery semantics via a two-phase commit system. To get started, simply run pip install datapipe-core in your terminal. For teams needing the full suite of connectors, the datapipe[all] package is available.
