Datapipe is an open-source streaming ETL framework built in Rust with Python bindings designed to simplify high-throughput data pipelines. It is built specifically for data engineers and mid-size engineering teams managing billions of events daily who want to replace complex, fragmented pipelines. By eliminating custom connector code, Datapipe allows teams to seamlessly move events between Kafka, S3, Postgres, and ClickHouse. The framework comes equipped with over forty pre-built source and sink connectors, robust exactly-once delivery semantics, and a declarative transformation language that compiles to optimized Rust. This combination delivers unparalleled reliability and performance for organizations looking to streamline their data infrastructure. Getting started is straightforward, requiring only a simple pip install of the datapipe-core package. For access to the full suite of connectors, teams can easily install the complete package including all extras.
