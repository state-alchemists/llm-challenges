Datapipe is an open-source streaming ETL framework designed for data engineers who need to transfer billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse, all without the hassle of writing custom connector code. It features over 40 pre-built source and sink connectors, ensures exactly-once delivery semantics through a two-phase commit, and offers a declarative transformation DSL compiled into optimized Rust. This project specifically targets mid-size data teams composed of 5 to 50 engineers handling over 1 billion events each day, who often manage a combination of tools such as Airflow and Flink. To install Datapipe, simply run `pip install datapipe-core`. For those needing the complete suite of connectors, use `pip install datapipe[all]`. With its robust architecture and ease of use, Datapipe streamlines the data integration process, allowing teams to focus on utilizing their data effectively.
