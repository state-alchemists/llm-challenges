Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It enables data engineers to transfer billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without the need for custom connector development. The framework includes over 40 pre-built source and sink connectors, ensures exactly-once delivery through a two-phase commit process, and features a declarative transformation DSL that compiles to optimized Rust code. Ideal for mid-sized data teams of 5 to 50 engineers managing event volumes exceeding 1 billion events per day, Datapipe is a robust solution to replace a fragmented setup of tools like Airflow and Flink. Installation is straightforward via pip with the command `pip install datapipe-core`, or install the full connector suite with `pip install datapipe[all]`.
