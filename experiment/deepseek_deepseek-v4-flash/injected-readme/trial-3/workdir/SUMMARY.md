Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who move a billion or more events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust for high performance. It's aimed at mid-size data teams of 5 to 50 engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs and want a single, simpler pipeline layer. Installation takes one command: pip install datapipe-core. Teams that need the full connector pack can install datapipe[all] instead. The project is MIT-licensed and free to use.
