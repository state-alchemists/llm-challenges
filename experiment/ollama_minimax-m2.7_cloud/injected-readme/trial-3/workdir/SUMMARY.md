Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it quick to connect popular data infrastructure out of the box. The framework provides exactly-once delivery semantics through two-phase commit, ensuring data integrity even in distributed environments. Its declarative transformation DSL compiles to optimized Rust, giving users both ease of use and high performance. Installation is straightforward via pip, with a core package available as `datapipe-core` and a full connector pack under `datapipe[all]`. Datapipe targets mid-size data teams of 5 to 50 engineers processing billion-plus events daily who are currently juggling multiple tools like Airflow, Flink, and custom Python jobs.
