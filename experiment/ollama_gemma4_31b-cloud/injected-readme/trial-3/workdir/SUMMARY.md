Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events daily with ease. It allows data engineers to seamlessly transfer data between Kafka, S3, Postgres, and ClickHouse using over 40 pre-built connectors. The system ensures reliability through exactly-once delivery semantics and an optimized transformation DSL. It is specifically tailored for mid-size data teams managing massive event volumes who want to replace fragmented pipelines. To get started, simply install the core library using pip install datapipe-core. For teams requiring the complete set of connectors, the full pack is available via pip install datapipe[all].
