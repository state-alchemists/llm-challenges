Datapipe is an open-source streaming ETL framework written in Rust with Python bindings that enables data engineers to move billions of events per day across Kafka, S3, Postgres, and ClickHouse. The framework eliminates the need for custom connector code by providing over forty pre-built source and sink connectors, along with a declarative transformation language that compiles to optimized Rust. Additionally, it ensures reliable transmission with exactly-once delivery semantics powered by two-phase commit. It is designed specifically for mid-sized data teams of five to fifty engineers who currently struggle to maintain a patchwork of Airflow, Flink, and bespoke Python jobs. To install the core framework, simply use the standard Python package manager to install the datapipe-core package. For teams requiring the complete set of capabilities, the full connector pack is easily added by installing datapipe with the all option.
