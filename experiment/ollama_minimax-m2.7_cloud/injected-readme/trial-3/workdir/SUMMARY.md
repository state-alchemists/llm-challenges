Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, offers exactly-once delivery semantics via two-phase commit, and includes a declarative transformation DSL that compiles to optimized Rust. The target audience is mid-sized data teams of 5 to 50 engineers handling one billion or more events daily who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with the core package installed using pip install datapipe-core and the full connector pack installed using pip install datapipe followed by all in square brackets. The project is open-source and licensed under MIT.
