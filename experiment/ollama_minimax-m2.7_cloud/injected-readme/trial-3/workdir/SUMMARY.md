Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data systems out of the box rather than building integrations from scratch. The framework provides exactly-once delivery semantics using a two-phase commit protocol, which is critical for workloads where data integrity cannot be compromised. A declarative transformation DSL compiles to optimized Rust, giving developers a comfortable Python interface while retaining Rust-level performance for high-throughput pipelines. Datapipe targets mid-size data teams of five to fifty engineers processing one billion or more events daily who currently juggle a mix of Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a lightweight core package and an optional full connector pack for environments that need all available integrations.
