Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers managing massive event volumes. It enables seamless data movement between various platforms like Kafka, S3, Postgres, and ClickHouse without the need for custom connector development. The framework boasts over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles into optimized Rust code. It is ideal for mid-sized data teams, typically 5-50 engineers, who process over a billion events daily and aim to replace complex, fragmented data pipelines currently reliant on tools like Airflow, Flink, and custom Python scripts. Installation is straightforward using pip.
