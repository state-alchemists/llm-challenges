Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, tailored for data engineers. It enables seamless movement of billions of events daily among Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The framework comes equipped with over 40 pre-built source and sink connectors, ensuring exactly-once delivery using a two-phase commit protocol. Additionally, it features a declarative transformation DSL that compiles to optimized Rust for efficiency. Installation can be easily done via pip by running 'pip install datapipe-core', or for the complete connector pack, use 'pip install datapipe[all]'. Datapipe is particularly aimed at mid-sized data teams, comprising 5 to 50 engineers, who handle event volumes exceeding 1 billion events per day.
