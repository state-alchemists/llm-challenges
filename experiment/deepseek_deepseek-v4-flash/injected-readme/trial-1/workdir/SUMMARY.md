Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than forty pre-built source and sink connectors, provides exactly-once delivery semantics through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. It targets mid-size data teams of five to fifty engineers running event volumes in the one-billion-plus events per day range, teams that currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. To install the core package, run pip install datapipe-core. For the full connector pack, install datapipe[all]. The project is licensed under the MIT license.
