Datapipe is an open-source streaming ETL framework built in Rust and wrapped with Python bindings for everyday usability. It helps data engineers move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework includes more than forty pre-built source and sink connectors, exactly-once delivery guarantees through two-phase commit, and a declarative transformation language that compiles down to optimized Rust. It is built for mid-sized data teams of five to fifty engineers who are currently juggling a mix of Airflow, Flink, and custom Python jobs at event volumes exceeding one billion per day. You can get started quickly by installing the core package with pip, and add the full connector pack whenever you need the complete set of integrations. Datapipe lets you focus on building data pipelines instead of maintaining plumbing, all under an open MIT license.
