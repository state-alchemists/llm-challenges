# 2026-06-19

## Fixed job queue concurrency bug and missing failure handler

**Time:** 02:48

**Files modified:**
- `job_queue.py:dequeue()` — moved status update before `await` to eliminate TOCTOU race (all 5 workers were claiming the same job)
- `worker.py:process_job()` — added `queue.fail()` call in exception handler (failed jobs were silently swallowed, stuck at "processing")

**Root causes:**
1. `dequeue()` checked status, then `await`-ed, then set `processing` — all concurrent workers saw "pending" and claimed the same job
2. `process_job()` caught exceptions but never called `queue.fail()` — retry mechanism was dead code

**Result:** Done: 10/10, Failed: 2/2, Stuck: 0/0 ✅
