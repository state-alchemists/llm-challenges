Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data systems out of the box rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in distributed, high-throughput environments. The framework includes a declarative transformation DSL that compiles down to optimized Rust, letting engineers express data transformations succinctly while benefiting from Rust's performance. It is aimed at mid-sized data teams of five to fifty engineers running event volumes in the billions per day, who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a core package available as `datapipe-core` and a full connector pack available as `datapipe[all]`. Datapipe is released under the MIT license.
