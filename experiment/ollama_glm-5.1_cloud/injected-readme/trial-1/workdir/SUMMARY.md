Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that helps data engineers move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It eliminates the need to write custom connector code by providing over 40 pre-built source and sink connectors out of the box. Exactly-once delivery semantics, powered by two-phase commit, ensure data integrity even at massive scale. A declarative transformation DSL lets teams define data pipelines declaratively while the engine compiles those definitions into optimized Rust for high performance. Datapipe is built for mid-size data teams running a billion or more events daily who are tired of maintaining a patchwork of Airflow, Flink, and hand-written Python jobs. Getting started is as simple as installing the core package with pip, or pulling in the full connector pack for comprehensive source and sink support. The project is released under the MIT license.
