Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It removes the need to write custom connector code by shipping more than 40 pre-built source and sink connectors out of the box. Datapipe guarantees exactly-once delivery through two-phase commit semantics, and its declarative transformation DSL compiles down to optimized Rust for high throughput. Installation takes a single pip command, pip install datapipe-core, with an optional extended install that pulls in the full connector pack for teams that need it. It is designed for mid-size data teams of five to fifty engineers handling event volumes above one billion events per day who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. The project is released under the MIT license.
