# INC-4471: Case-sensitive `status` comparison in `metrics.py`

## Problem

`metrics.py:13` compared `r["status"] == "ok"` (lowercase) against CSV
values `OK` (uppercase). Never matched → `ok_count = 0` → `SUCCESS_RATE=0.0`.

## Fix

Changed to `r["status"].lower() == "ok"` — case-insensitive.

## Evidence

- `events.csv`: 10 rows, 8 with `OK`, 2 with `ERROR`.
- Pre-fix: `SUCCESS_RATE=0.0`
- Post-fix: `SUCCESS_RATE=80.0`

## Files changed

- `metrics.py:13` — one-character change (`.lower()`)
- `POSTMORTEM.md` — written as incident documentation
