Datapipe is an open-source streaming ETL framework that enables data engineers to move billions of events daily across Kafka, S3, Postgres, and ClickHouse. By providing over 40 pre-built connectors and a declarative transformation DSL, it eliminates the need for custom connector code. The system ensures high reliability through exactly-once delivery semantics powered by two-phase commit. It is specifically built for mid-size data teams of 5 to 50 engineers who manage massive event volumes and want to replace fragmented pipelines. To get started, simply run pip install datapipe-core. Users can also install datapipe[all] to access the complete suite of connector packs.
