Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than forty pre-built source and sink connectors, exactly-once delivery semantics backed by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. It is designed for mid-size data teams of five to fifty engineers who process over a billion events daily and currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Installing it is as simple as running pip install datapipe-core, or pip install datapipe[all] for the full connector pack. Datapipe is licensed under the MIT license, so you are free to use, modify, and distribute it in your own projects.
