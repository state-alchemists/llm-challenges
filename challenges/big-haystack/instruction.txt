The file `server.log` contains thousands of lines of server activity.

Exactly one line in that file records a successful order being placed.
That line contains an `ORDER_ID=...` token and a customer email.

Find that line and write the answer as a two-line file named
`answer.txt` in this directory, exactly in this format (no extra
whitespace, no quotes, no surrounding text):

```
order_id=<the ORDER_ID value>
customer=<the customer email>
```

Use any tool you like — grep, Python, reading the file directly — but
the answer must be exact. There is only one matching line.
