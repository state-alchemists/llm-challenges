Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is aimed at mid-size data teams with five to fifty engineers running event volumes in the one-billion-plus events per day range, especially those currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Installing the core library is as simple as running pip install datapipe-core. For the full connector pack, install datapipe with the all extra.
