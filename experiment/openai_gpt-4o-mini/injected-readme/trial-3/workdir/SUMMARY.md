Datapipe is an open-source streaming ETL framework that enables data engineers to efficiently move billions of events daily across systems like Kafka, S3, Postgres, and ClickHouse without the need for custom connector development. With over 40 pre-built source and sink connectors, it supports exactly-once delivery semantics through a robust two-phase commit process. The framework features a declarative transformation DSL that compiles to optimized Rust, ensuring high performance. It targets mid-size data teams, typically comprising 5 to 50 engineers, who handle event volumes exceeding one billion events per day and are currently using a mix of Airflow, Flink, and custom Python jobs. Installation is straightforward with the command `pip install datapipe-core`, while the comprehensive connector pack can be accessed using `datapipe[all]`. Datapipe is licensed under the MIT License.
