Datapipe is a robust, open-source streaming ETL framework, built with Rust and offering convenient Python bindings. It empowers data engineers to seamlessly transfer billions of events daily across various platforms, including Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework boasts over 40 pre-built source and sink connectors, ensures exactly-once delivery through two-phase commit, and features a declarative transformation language that compiles into highly optimized Rust code. This solution is ideal for mid-sized data teams, typically 5-50 engineers, who handle event volumes exceeding one billion per day and currently manage complex data pipelines with tools like Airflow, Flink, and custom Python scripts. To get started, users can simply install the core package using `pip install datapipe-core`, with an option for `datapipe[all]` to access the complete connector suite.
