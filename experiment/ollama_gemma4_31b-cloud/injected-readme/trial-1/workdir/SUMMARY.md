Datapipe is an open-source streaming ETL framework that enables data engineers to move billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse. By utilizing a declarative transformation DSL that compiles to optimized Rust, it eliminates the need for writing custom connector code. The framework is ideal for mid-size data teams managing massive event volumes who want to replace fragmented pipelines of Airflow, Flink, and bespoke Python jobs. It provides over 40 pre-built connectors and ensures reliable data movement with exactly-once delivery semantics. To get started, simply install the core library using pip install datapipe-core. For those needing the full suite of connectors, the datapipe[all] package is available.
