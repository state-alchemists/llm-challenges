Datapipe is an open-source streaming ETL framework built in Rust and accessible through Python bindings, purpose-built for data engineers who need to move massive event volumes between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connectors. It ships with more than 40 pre-built connectors, exactly-once delivery guarantees via two-phase commit, and a declarative transformation language that compiles down to optimized Rust for maximum throughput. The tool is designed for mid-size data teams of five to fifty engineers handling over a billion events per day and currently wrestling with a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started takes a single pip install of datapipe-core, or you can choose datapipe with all extras to unlock the full connector pack. Datapipe replaces fragile data plumbing with a single, high-performance framework that scales from day one.
