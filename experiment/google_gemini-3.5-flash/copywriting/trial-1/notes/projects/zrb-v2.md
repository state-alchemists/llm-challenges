# Zrb v2 Migration Project

Durable facts, decisions, and outcomes for the Zrb CLI v2 migration.

## Context
The Zrb CLI has released version 2, introducing several breaking changes from v1 (endpoints prefix, authentication headers, ID type migration, done field renaming, required project_id, and paginated lists).

## Key Decisions
- Created a developer-friendly migration guide at `MIGRATION.md` detailing all six breaking changes with clear code examples.
- Documented standard upgrade commands (`pip install --upgrade zrb` and `pipx upgrade zrb`).
