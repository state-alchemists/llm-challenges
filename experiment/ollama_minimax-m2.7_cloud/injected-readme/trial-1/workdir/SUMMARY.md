Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors and provides exactly-once delivery semantics via two-phase commit, along with a declarative transformation DSL that compiles to optimized Rust. The tool targets mid-size data teams of five to fifty engineers running event volumes in the billion-plus events per day range who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. To install the core package, run pip install datapipe-core, or install the full connector pack with pip install datapipe[all]. Datapipe is released under the MIT license.
