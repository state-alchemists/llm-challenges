Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, making integration straightforward across popular data platforms. The framework guarantees exactly-once delivery semantics using a two-phase commit protocol, ensuring data reliability even in distributed environments. Users define transformations using a declarative DSL that compiles to optimized Rust for high performance. Installation is simple via pip, with a core package available as datapipe-core or a full connector pack as datapipe with the all extra. Mid-size data teams handling over one billion events daily who are tired of maintaining fragmented stacks of tools like Airflow, Flink, and custom Python jobs are the primary audience for this solution. The project is open-source under the MIT license.
