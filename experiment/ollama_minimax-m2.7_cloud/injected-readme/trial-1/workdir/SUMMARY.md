Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect their data infrastructure out of the box rather than building and maintaining those integrations themselves. Datapipe provides exactly-once delivery semantics using a two-phase commit protocol, which is critical for workloads where data integrity cannot be compromised. A declarative transformation DSL lets engineers define data transformations that then compile to optimized Rust for high performance under heavy load. The project targets mid-size data teams of five to fifty engineers running at least one billion events per day, typically those currently managing a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a base package called datapipe-core and a full connector pack available as datapipe with the all extra. Datapipe is released under the MIT license.
