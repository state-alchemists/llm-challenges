Datapipe is an open-source streaming ETL framework built in Rust and delivered through Python bindings. It helps data engineers move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. With more than forty pre-built source and sink connectors, exactly-once delivery guarantees, and a declarative transformation language that compiles down to optimized Rust, Datapipe replaces fragile patchworks of Airflow, Flink, and bespoke Python jobs. It is purpose-built for mid-size data teams of five to fifty engineers who are drowning in event volumes north of a billion per day. Installation is as simple as running pip install datapipe-core, and teams that want the complete connector pack can opt for datapipe[all] instead. Datapipe lets you focus on the data, not the plumbing.
