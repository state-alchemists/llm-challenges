Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for data engineers. It efficiently moves billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector development. The framework offers over 40 pre-built source and sink connectors, guaranteeing exactly-once delivery through two-phase commit mechanisms. It also features a declarative transformation DSL that compiles directly into optimized Rust code. Datapipe is ideal for mid-sized data teams, typically 5-50 engineers, who process over a billion events per day and are looking to streamline operations currently handled by fragmented Airflow, Flink, or bespoke Python solutions. Installation is simple: `pip install datapipe-core`, with `datapipe[all]` available for the complete connector suite.
