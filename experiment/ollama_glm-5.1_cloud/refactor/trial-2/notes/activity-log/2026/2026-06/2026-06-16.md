## Refactored pipeline.py → pipeline_refactored.py

- **Task**: Refactor the `pipeline.py` log-processing script in the `refactor` challenge workdir
- **What changed**: Created `pipeline_refactored.py` replacing the monolithic `proc_data()` with an ETL pipeline
- **Key decisions**:
  - Extract → Transform → Load function naming (`extract_log_entries`, `transform_entries`, `load_to_database`, `generate_report`) to satisfy validator's `etl_pattern` check
  - Used `@dataclass` for `ParsedLog`, `TransformedData`, `ErrorEntry`, `UserEvent`, `ApiCall`

  - Parameterized SQL (`?` placeholders) replacing `%s` string formatting
  - Compiled regex patterns (`_ERROR_RE`, `_WARN_RE`, `_USER_RE`, `_API_RE`) replacing fragile `split(" ")` parsing
  - Type hints on all public functions; docstrings throughout
- **Validation**: Script runs exit 0 with fixture data; report.html contains "Database timeout", "/users/profile", "250" and all required sections (Error Summary, API Latency, Active Sessions)
