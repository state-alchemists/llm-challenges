Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors, so teams can connect to common data platforms out of the box rather than building integrations from scratch. Datapipe guarantees exactly-once delivery using a two-phase commit mechanism, which is critical for workloads where data integrity cannot be compromised. Transformations are defined using a declarative DSL that compiles down to optimized Rust, giving users the simplicity of a high-level interface with the performance of a compiled language. Installation is straightforward via pip, with a core package for lightweight use and a full connector pack available for teams that need broad platform support. Datapipe targets mid-size data teams of five to fifty engineers handling event volumes in the billions per day, typically those currently maintaining a patchwork of tools like Airflow, Flink, and custom Python jobs.
