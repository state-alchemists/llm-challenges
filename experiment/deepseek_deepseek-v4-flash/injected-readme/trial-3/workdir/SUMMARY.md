Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It's designed for mid-size data teams of 5-50 engineers running event volumes in the 1B+ events per day range who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installing is a single command: pip install datapipe-core. For the full connector pack, install datapipe[all]. The project is MIT licensed and free to use.
