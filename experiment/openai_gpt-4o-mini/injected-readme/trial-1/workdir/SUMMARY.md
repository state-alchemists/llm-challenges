Datapipe is an open-source streaming ETL framework crafted in Rust, featuring Python bindings. It empowers data engineers to efficiently transfer billions of events daily between Kafka, S3, Postgres, and ClickHouse without the hassle of writing custom connector code. With over 40 pre-built source/sink connectors, it ensures exactly-once delivery through a two-phase commit system, alongside a declarative transformation DSL that compiles to optimized Rust. Ideal for mid-size data teams of 5-50 engineers handling event volumes exceeding 1 billion events per day, it streamlines operations currently reliant on disparate systems like Airflow and Flink. To install, simply run `pip install datapipe-core`, or for the full connector suite, use `pip install datapipe[all]`.
