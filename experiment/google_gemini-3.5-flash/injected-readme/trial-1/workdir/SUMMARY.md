Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse. The platform eliminates the need for custom connector code by shipping with over forty pre-built source and sink connectors. It ensures reliability and performance with exactly-once delivery semantics via two-phase commits, alongside a declarative transformation language that compiles down to highly optimized Rust code. This solution is specifically designed for mid-sized data engineering teams of five to fifty engineers managing massive event volumes who want to replace their complex patchwork of Airflow, Flink, and bespoke Python jobs. Getting started with the framework is straightforward, requiring a simple installation of the core package using the Python package manager. For teams looking for the complete suite of connectors, the entire pack can be installed with a single command to unlock full integration capabilities immediately.
