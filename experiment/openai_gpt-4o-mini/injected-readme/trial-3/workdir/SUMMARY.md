Datapipe is an open-source streaming ETL framework written in Rust, featuring Python bindings. It is specifically designed for data engineers responsible for transferring billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse, all without the need to write custom connector code. The framework includes over 40 pre-built source/sink connectors and ensures exactly-once delivery through two-phase commit. Additionally, Datapipe provides a declarative transformation DSL that compiles to optimized Rust for efficient processing. To install Datapipe, simply run `pip install datapipe-core`, or for the complete connector pack, use `pip install datapipe[all]`. This tool is ideal for mid-sized data teams managing high event volumes and seeking to streamline their current data pipeline solutions.
