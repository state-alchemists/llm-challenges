Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It enables data engineers to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform provides over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines. To get started, simply install the core package using pip install datapipe-core. For users requiring the full suite of connectors, the datapipe[all] installation is recommended.
