LLM Challenges is a benchmark suite designed to evaluate the performance of LLM-driven coding agents on realistic software engineering tasks. It provides a collection of self-contained scenarios, ranging from bug fixes and feature implementations to complex refactoring and safety challenges. This suite is intended for researchers and engineers who need to assess and compare different LLM models and their capabilities in an automated, consistent manner. To get started, you'll need `zrb-llm-evaluator` installed via `pipx` or `poetry`, along with `zrb` configured with API keys. Then, you can execute the evaluation suite using a simple `zrb-llm-evaluator run` command, specifying the models and test cases you wish to analyze.
