# 2026-06-25

## 08:48 — Fix duplicate processing and vanishing failures in job queue

**Request**: Find root causes and fix two production bugs in a background job processor: (1) duplicate job execution, (2) jobs crashing with exceptions never being marked as failed.

**Skills used**: core-coding

**Actions**:
- Identified race condition in `job_queue.py:dequeue` — `await asyncio.sleep(0.01)` yielded control *before* setting `job["status"] = "processing"`, allowing all concurrent workers to claim the same pending job. Fixed by marking status before the await.
- Identified swallowed exception in `worker.py:process_job` — the `except` block printed the error but never called `queue.fail()`, leaving jobs stuck in "processing" indefinitely. Fixed by adding `queue.fail(job["id"], str(e))`.
- Reproduced and verified both bugs via `main.py` simulation: output went from `Done: 10, Failed: 0, Stuck: 2` to `Done: 10, Failed: 2, Stuck: 0`.

**Outcome**: completed
