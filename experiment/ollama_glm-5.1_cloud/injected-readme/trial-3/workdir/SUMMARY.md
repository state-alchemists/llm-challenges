Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The project targets mid-size data teams of 5 to 50 engineers handling over a billion events daily who are currently maintaining a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or add datapipe[all] for the full connector pack. Datapipe is released under the MIT license, making it free to use and adapt for any organization.
