Datapipe is an open-source streaming ETL framework built with Rust and Python bindings, designed to efficiently move billions of events daily between popular data systems like Kafka, S3, Postgres, and ClickHouse. It eliminates the need for custom connector development by offering over 40 pre-built source/sink connectors and ensuring exactly-once delivery semantics. The framework targets mid-sized data teams, typically with 5-50 engineers, who handle massive event volumes exceeding one billion per day and seek to streamline their existing data pipelines that might involve Airflow, Flink, and custom Python solutions. Installation is straightforward: users can get started by running `pip install datapipe-core`, with an option to install `datapipe[all]` for the complete suite of connectors.
