Datapipe is an open-source streaming ETL framework designed for data engineers. It facilitates moving billions of events daily between popular systems such as Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. With over 40 pre-built source and sink connectors, it guarantees exactly-once delivery through a robust two-phase commit system. Datapipe also includes a declarative transformation DSL that compiles to optimized Rust, ensuring high performance. It is particularly suitable for mid-size data teams of 5 to 50 engineers managing over 1 billion events per day. To install, simply run 'pip install datapipe-core', or for the complete connector pack, use 'pip install datapipe[all]'.
