Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, offers exactly-once delivery semantics through a two-phase commit mechanism, and includes a declarative transformation DSL that compiles to optimized Rust for high performance. The project targets mid-size data teams of five to fifty engineers processing one billion or more events daily, replacing fragmented stacks of Airflow, Flink, and bespoke Python jobs with a unified solution. Installation is straightforward via pip, with a core package available as datapipe-core and a full connector pack under datapipe-all. Datapipe is open-source under the MIT license.
