Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers. It enables the seamless transfer of billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for customized connector code. With over 40 pre-built source/sink connectors and robust exactly-once delivery semantics via two-phase commit, Datapipe ensures reliable data processing. Additionally, its declarative transformation DSL compiles to optimized Rust for performance improvements. Installation is straightforward; simply run `pip install datapipe-core`, with `datapipe[all]` recommended for access to the complete set of connectors. Datapipe is tailored for mid-sized data teams managing event volumes exceeding 1 billion per day, currently using a combination of tools like Airflow, Flink, and custom Python jobs.
