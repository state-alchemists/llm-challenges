Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed for efficiently moving billions of events daily. It caters to data engineers who manage high-volume data pipelines across platforms like Kafka, S3, Postgres, and ClickHouse, aiming to reduce the need for custom connector development. The framework boasts over 40 pre-built connectors, ensures exactly-once delivery through two-phase commit, and provides a declarative transformation language that optimizes to Rust. It is ideal for mid-sized data teams, typically 5-50 engineers, dealing with over a billion events per day, offering an alternative to maintaining complex setups involving tools like Airflow or Flink. To get started, users can simply install it via `pip install datapipe-core`, with an option for `datapipe[all]` for the complete connector suite.
