Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with over 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles to optimized Rust. Installation is straightforward: run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` for the full connector bundle. Datapipe is designed for mid-size data teams of 5–50 engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes above one billion per day.
