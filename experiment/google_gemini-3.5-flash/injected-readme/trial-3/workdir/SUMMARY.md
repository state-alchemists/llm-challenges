Datapipe is a high-performance, open-source streaming ETL framework written in Rust with Python bindings that enables seamless data migration across popular platforms. Designed to simplify event-driven workflows, it features over forty pre-built source and sink connectors to effortlessly move data between Kafka, S3, Postgres, and ClickHouse without requiring any custom connector code. The platform guarantees exactly-once delivery semantics using two-phase commit and provides a declarative transformation language that compiles into highly optimized Rust for maximum execution speed. This solution is built specifically for data engineers and mid-size data teams of five to fifty engineers who handle massive volumes exceeding one billion events per day. It offers a modern, unified alternative for teams currently struggling to maintain a fragmented patchwork of Airflow, Flink, and custom Python scripts. Getting started with the framework is as simple as installing the core package via the command line using the pip install datapipe-core command. For teams requiring the complete set of integrations, the full connector suite can be easily added by specifying the all option during installation.
