Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. Instead of wiring together custom connector code, teams use its 40+ pre-built source and sink connectors, combined with a declarative transformation DSL that compiles down to optimized Rust for production performance. It guarantees exactly-once delivery semantics via two-phase commit, eliminating a common source of data pipeline bugs. The primary audience is mid-size data teams of 5 to 50 engineers who currently maintain a patchwork of Airflow, Flink, and custom Python jobs and want a single, reliable framework instead. Installation is straightforward: run pip install datapipe-core for the base library, or pip install datapipe[all] for the full connector pack. Datapipe is open source under the MIT license.
