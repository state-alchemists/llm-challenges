Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so teams can stop writing custom connector code and focus on their data pipelines. The framework provides exactly-once delivery semantics through two-phase commit and includes a declarative transformation DSL that compiles directly to optimized Rust for high performance. It is designed for mid-size data teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Installing is straightforward — run `pip install datapipe-core` to get the core library, or `pip install datapipe[all]` for the full connector pack.
