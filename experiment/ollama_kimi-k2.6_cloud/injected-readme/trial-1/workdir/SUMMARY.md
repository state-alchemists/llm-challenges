Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to move massive event volumes between systems like Kafka, S3, Postgres, and ClickHouse. It comes with more than 40 ready-made connectors and a declarative transformation language that compiles down to optimized Rust, so you don't have to write custom integration code. Built for mid-size data teams handling a billion or more events per day, it replaces fragile patchworks of Airflow, Flink, and one-off Python scripts with a single, reliable pipeline. Datapipe guarantees exactly-once delivery using two-phase commit semantics, giving you correctness under high throughput without manual oversight. Getting started is as simple as running pip install datapipe-core, with the full connector pack available under datapipe[all].
