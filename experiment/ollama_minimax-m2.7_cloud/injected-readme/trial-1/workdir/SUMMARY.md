Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move massive volumes of events between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes more than 40 pre-built source and sink connectors, making it practical for teams handling a billion or more events per day. The framework provides exactly-once delivery semantics through a two-phase commit mechanism and a declarative transformation DSL that compiles to optimized Rust for performance. It targets mid-sized data teams of five to fifty engineers who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a core package available as `datapipe-core` and a full connector pack available as `datapipe[all]`. The project is open-source and released under the MIT license.
