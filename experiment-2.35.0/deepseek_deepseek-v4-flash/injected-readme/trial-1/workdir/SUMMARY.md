Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, supports exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. You can install the core package with a single pip command: pip install datapipe-core. For the full suite of connectors, install datapipe[all] instead. The project is ideal for mid-size data teams of five to fifty engineers who want to replace a patchwork of Airflow, Flink, and custom Python jobs with a single, fast, and maintainable pipeline framework. Datapipe is licensed under MIT and is ready to drop into existing infrastructure without vendor lock-in.
