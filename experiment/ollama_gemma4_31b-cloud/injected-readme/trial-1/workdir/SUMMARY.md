Datapipe is a powerful open-source streaming ETL framework built in Rust with Python bindings. It is designed specifically for data engineers who need to move billions of events daily between Kafka, S3, Postgres, and ClickHouse. The platform simplifies data movement by providing over 40 pre-built connectors and a declarative transformation language. This makes it an ideal solution for mid-size data teams looking to replace fragmented pipelines with a unified system. To get started, simply install the core package via pip using the datapipe-core command. For teams needing the complete suite of connectors, the datapipe[all] installation is recommended.
