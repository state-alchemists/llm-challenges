Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is built for mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and ad-hoc Python jobs at volumes exceeding a billion events daily. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with datapipe[all]. Datapipe is MIT-licensed and production-ready, letting teams replace fragmented pipelines with a single declarative framework that handles scale and correctness out of the box.
