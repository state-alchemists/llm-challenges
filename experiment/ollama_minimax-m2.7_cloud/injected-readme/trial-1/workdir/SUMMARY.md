Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors and uses a two-phase commit protocol to guarantee exactly-once delivery semantics. The framework includes a declarative transformation DSL that compiles to optimized Rust, letting teams define data pipelines in a high-level syntax while benefiting from Rust's performance. Datapipe targets mid-sized data teams of five to fifty engineers processing one billion or more events daily who would otherwise rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is a single pip command for the core package, or one command for the full connector pack. The project is open source and released under the MIT license.
