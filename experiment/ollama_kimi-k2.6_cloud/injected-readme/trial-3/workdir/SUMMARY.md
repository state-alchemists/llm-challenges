Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, built for data engineers who need to move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built source and sink connectors, exactly-once delivery guarantees via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. It is purpose-built for mid-size data teams of 5 to 50 engineers that are processing more than a billion events per day and are tired of maintaining a fragile mix of Airflow, Flink, and one-off Python scripts. You can get started by installing the core package with pip install datapipe-core, or choose datapipe-all for the full connector pack. Datapipe lets you build reliable data pipelines with minimal boilerplate so your team can focus on insights instead of infrastructure.
