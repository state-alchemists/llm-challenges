Datapipe is an open-source streaming ETL framework built in Rust and accessible through Python bindings, built for data engineers who need to reliably move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It comes with more than forty pre-built source and sink connectors so you can skip writing custom integration code. The framework guarantees exactly-once delivery semantics through two-phase commit and includes a declarative transformation language that compiles down to optimized Rust for high performance. It is purpose-built for mid-size data teams of five to fifty engineers who are already handling over a billion events daily and tired of maintaining a fragile mix of Airflow, Flink, and one-off Python scripts. You can get started quickly by installing the core package with pip, and if you need the complete set of connectors you can opt for the full distribution instead.
