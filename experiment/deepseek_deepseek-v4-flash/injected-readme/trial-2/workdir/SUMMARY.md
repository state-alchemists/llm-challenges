Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, purpose-built for data engineers moving billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It eliminates the need to write and maintain custom connector code by shipping with more than forty pre-built source and sink connectors, each supporting exactly-once delivery through two-phase commit. A declarative transformation DSL compiles to optimized Rust, giving teams high throughput without sacrificing expressiveness. Installation is straightforward via `pip install datapipe-core`, with `datapipe[all]` available for the full connector pack. The project targets mid-size data teams of five to fifty engineers who currently run a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes above one billion per day.
