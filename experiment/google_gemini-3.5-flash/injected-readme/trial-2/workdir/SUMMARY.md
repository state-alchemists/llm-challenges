Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. Designed to handle billions of events per day, the platform seamlessly moves data between Kafka, S3, Postgres, and ClickHouse without requiring any custom connector code. It ships with over forty pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles directly to optimized Rust. This powerful tool is built specifically for mid-size data teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. By simplifying complex data movement pipelines, Datapipe helps modern data organizations scale their event-driven architectures efficiently. To get started, you can easily install the core system by running pip install datapipe-core. For the complete suite of capabilities, the full connector pack can be installed using datapipe with the all option.
