Datapipe is an open-source streaming ETL framework built with Rust and Python bindings. It enables data engineers to move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The system features over 40 pre-built connectors, exactly-once delivery semantics, and a powerful transformation DSL. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines. Integration is simple via the pip install datapipe-core command. For those needing the complete set of capabilities, the full connector pack can be installed using datapipe[all].
