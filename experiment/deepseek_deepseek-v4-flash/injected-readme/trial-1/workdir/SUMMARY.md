Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to reliably move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It eliminates the need to write and maintain custom connector code by shipping over forty pre-built source and sink connectors out of the box. Datapipe guarantees exactly-once delivery semantics through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is built for mid-size data teams of five to fifty engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs to keep their pipelines running. To get started, install the core library with pip install datapipe-core, or install datapipe[all] for the full connector pack. Datapipe is released under the MIT license.
