Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so data engineers can pipeline data without writing custom connector code. The framework guarantees exactly-once delivery semantics through two-phase commit and offers a declarative transformation DSL that compiles down to optimized Rust for high throughput. Datapipe is built for mid-size data teams of 5 to 50 engineers handling 1B+ daily events who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. The project is released under the MIT license.
