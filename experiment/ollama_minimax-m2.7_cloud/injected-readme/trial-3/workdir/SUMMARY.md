Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, and uses a two-phase commit protocol to guarantee exactly-once delivery semantics across distributed systems. The framework includes a declarative transformation DSL that compiles to optimized Rust, giving teams a way to define data transformations without dropping down to raw code. Datapipe is aimed at mid-size data teams of five to fifty engineers handling event volumes in the billions per day, who are currently stitching together tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a base package called datapipe-core and a full connector pack available as datapipe-all. The project is open-source and released under the MIT license.
