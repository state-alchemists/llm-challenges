Datapipe is an open-source streaming ETL framework designed to help data engineers seamlessly transfer billions of events every day without writing custom connector code. Built in Rust with Python bindings, it connects diverse platforms like Kafka, S3, Postgres, and ClickHouse using more than forty pre-built source and sink connectors. The framework guarantees exactly-once delivery semantics through robust two-phase commit mechanisms, while its declarative transformation language compiles directly into optimized Rust for high performance. This powerful tool is tailor-made for mid-size data teams of five to fifty engineers who manage immense event volumes and want to replace their complex patchwork of Airflow, Flink, and custom Python jobs. To get started, you can easily install the core package by running pip install datapipe-core in your terminal. For teams needing the complete suite of connectors, installing the full pack via pip install datapipe with the all option is highly recommended.
