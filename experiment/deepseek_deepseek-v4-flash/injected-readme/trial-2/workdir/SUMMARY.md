Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data teams that move billions of events per day. It replaces the common patchwork of Airflow, Flink, and custom Python jobs with a single unified platform. Datapipe ships with over 40 pre-built source and sink connectors, making it trivial to pipe data between Kafka, S3, Postgres, ClickHouse, and many other systems without writing any custom connector code. The framework guarantees exactly-once delivery through two-phase commit and includes a declarative transformation DSL that compiles to optimized Rust for maximum throughput. It is designed for mid-size data teams of five to fifty engineers who need reliable, high-volume event processing without the operational overhead of stitching together disparate tools. Getting started takes a single pip install command, with an optional extras install that unlocks the full suite of connectors.
