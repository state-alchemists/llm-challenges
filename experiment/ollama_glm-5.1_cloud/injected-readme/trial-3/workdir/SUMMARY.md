Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, eliminating the need to write custom integration code for common data pipelines. Exactly-once delivery semantics are provided through two-phase commit, giving teams confidence that every event is processed reliably without duplication. A declarative transformation DSL lets users define data flows in a concise, readable format that compiles down to optimized Rust for high throughput. The core library installs with a single pip command, and a full connector pack is available for teams that need the complete set of integrations. Datapipe is aimed at mid-size data teams running event volumes in the billion-plus range who want to consolidate fragmented Airflow, Flink, and bespoke Python jobs into a single, maintainable platform. It is released under the MIT license.
