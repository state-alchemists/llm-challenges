Datapipe is an open-source streaming ETL framework built with Rust and Python bindings for high-performance data movement. It enables data engineers to transfer billions of events daily across Kafka, S3, Postgres, and ClickHouse using over 40 pre-built connectors. The system ensures reliability with exactly-once delivery semantics and a declarative transformation DSL that compiles to optimized Rust. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified solution. To get started, simply install the core package via pip install datapipe-core. For teams requiring the full suite of connectors, the extended installation is available via pip install datapipe[all].
