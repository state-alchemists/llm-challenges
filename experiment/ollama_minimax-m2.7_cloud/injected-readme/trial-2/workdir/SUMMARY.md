Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it possible to connect to popular data infrastructure out of the box. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, so no data is lost or duplicated during pipeline failures. Its declarative transformation DSL compiles to optimized Rust, giving data teams a safe, expressive way to define complex pipelines without dropping into low-level code. Installation is a single pip command: pip install datapipe-core, or pip install datapipe[all] to get the full connector pack. Datapipe is aimed at mid-size data teams of 5 to 50 engineers running event volumes in the billions per day, typically those replacing a patchwork of Airflow, Flink, and bespoke Python jobs with a unified, maintainable solution.
