Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high throughput. The framework targets mid-size data teams of 5 to 50 engineers handling 1B+ events daily who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is straightforward: install the core library with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. Datapipe is released under the MIT license.
