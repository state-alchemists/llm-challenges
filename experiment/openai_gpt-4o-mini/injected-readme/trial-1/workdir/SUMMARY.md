Datapipe is an open-source streaming ETL framework designed for data engineers looking to efficiently move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse. With over 40 pre-built source and sink connectors, Datapipe provides exactly-once delivery semantics and a declarative transformation DSL that compiles to optimized Rust. It is targeted at mid-size data teams, typically 5 to 50 engineers, who are managing high event volumes and currently rely on a mix of tools like Airflow and Flink. Installation is straightforward with the command: `pip install datapipe-core`. For access to the complete suite of connectors, users should install it with `datapipe[all]`. Datapipe is released under the MIT license.
