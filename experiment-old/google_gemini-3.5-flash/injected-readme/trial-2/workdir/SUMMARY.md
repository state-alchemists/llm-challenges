Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built specifically to streamline complex data pipelines. It is designed for mid-size data teams and data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without maintaining a complex patchwork of tools or writing custom connector code. With more than forty pre-built source and sink connectors, Datapipe provides high-performance data transfers and guarantees exactly-once delivery semantics using two-phase commits. Users can easily build pipelines using a declarative transformation domain-specific language that automatically compiles into optimized Rust. To get started, you can easily install the core package via pip by running pip install datapipe-core. For teams requiring the complete set of pre-built connectors, the full connector pack can be installed using pip install datapipe with the all option.
