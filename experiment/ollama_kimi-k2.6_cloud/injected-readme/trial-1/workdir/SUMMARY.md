Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The toolkit is purpose-built for mid-size data teams of five to fifty engineers that are currently juggling a patchwork of Airflow, Flink, and custom Python jobs at the billion-plus events per day scale. Getting started is as simple as running pip install datapipe-core in your environment. If you want the complete set of connectors, install datapipe with the all extra. With Datapipe, you can replace fragile bespoke pipelines with a single, high-performance platform that keeps your data flowing reliably.
