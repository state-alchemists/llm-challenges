Datapipe is an open-source streaming ETL framework designed for data engineers and mid-size teams who need to move billions of events per day without writing custom connector code. It simplifies data pipeline development by shipping with over forty pre-built source and sink connectors to seamlessly link systems like Kafka, S3, Postgres, and ClickHouse. Built in Rust with Python bindings, the platform ensures reliable data pipelines using exactly-once delivery semantics powered by a robust two-phase commit protocol. Developers can easily design high-performance data transformations using a declarative domain-specific language that automatically compiles to highly optimized Rust code. This unified framework is the perfect solution for teams handling massive event volumes who are looking to replace an unstable patchwork of Airflow, Flink, and bespoke Python scripts. Getting started is as simple as installing datapipe-core via the Python package manager, or selecting datapipe with the all option for the complete connector package.
