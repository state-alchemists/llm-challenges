Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It is built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework ships with more than 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is aimed at mid-size data teams of 5 to 50 engineers handling event volumes of one billion or more events per day, especially those currently juggling Airflow, Flink, and bespoke Python jobs. You can install the core package with pip install datapipe-core. For the full set of connectors, install datapipe with the all extra using pip install datapipe[all].
