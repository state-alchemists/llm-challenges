Datapipe is an open-source streaming ETL framework designed to help data engineers efficiently transfer billions of events daily among services like Kafka, S3, Postgres, and ClickHouse, without the need for custom coding for connectors. It includes over 40 pre-built source and sink connectors and guarantees exactly-once delivery through two-phase commit. The framework features a declarative transformation DSL that compiles down to optimized Rust for performance. Installation is straightforward with the command 'pip install datapipe-core,' or you can acquire the full connector pack with 'datapipe[all].' This tool is specifically tailored for mid-sized data teams of 5 to 50 engineers who manage high volumes of event data exceeding 1 billion events per day.
