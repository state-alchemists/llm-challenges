Datapipe is an open-source streaming ETL framework for data engineers who need to reliably move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code from scratch. It ships with over forty pre-built source and sink connectors, delivers exactly-once processing guarantees through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is designed for mid-size data teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs and want a unified, performant alternative. Written in Rust with Python bindings, Datapipe combines the ergonomics of Python with the speed of compiled code, and is available under the MIT license. Installing the core library is as simple as running pip install datapipe-core, while teams that need the full connector suite can install datapipe[all] instead.
