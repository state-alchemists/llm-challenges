Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect popular data infrastructure out of the box rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in distributed, high-throughput environments. The framework includes a declarative transformation DSL that compiles to optimized Rust, giving engineers a productive way to express data transformations while still benefiting from Rust's performance. Installation is straightforward via pip, with a lightweight core package or a full connector pack available depending on your needs. Datapipe is aimed at mid-size data teams of five to fifty engineers processing one billion or more events daily who are currently managing a fragmented mix of tools like Airflow, Flink, and custom Python jobs. It is open-source and licensed under MIT.
