Datapipe is an open-source streaming ETL framework developed in Rust with Python bindings, designed for data engineers. It facilitates the movement of billions of events daily between Kafka, S3, Postgres, and ClickHouse without the need for custom connector coding. The framework includes over 40 pre-built source and sink connectors and implements exactly-once delivery semantics through a two-phase commit process. Users can leverage a declarative transformation DSL that compiles to optimized Rust for efficient data handling. Datapipe is specifically tailored for mid-size data teams, typically comprising 5 to 50 engineers, handling event volumes exceeding one billion events per day. Installation is straightforward via pip: simply run 'pip install datapipe-core,' or 'pip install datapipe[all]' for the complete connector pack.
