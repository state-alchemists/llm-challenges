Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over forty pre-built source and sink connectors, delivers exactly-once semantics through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust. The framework targets mid-size data teams of five to fifty engineers who currently maintain a patchwork of tools like Airflow, Flink, and bespoke Python jobs. Installation is straightforward — run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` for the full connector pack. Under the hood, Rust handles the heavy lifting so you get high throughput and low latency without sacrificing the ergonomics of a Python API. Datapipe is licensed under the MIT license and is open for contributions.
