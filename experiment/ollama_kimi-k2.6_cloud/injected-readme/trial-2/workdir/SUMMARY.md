Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The tool is aimed at mid-size data teams of five to fifty engineers handling more than a billion events per day, especially those currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is simple: run `pip install datapipe-core` to get started, or install `datapipe[all]` for the full connector pack. Datapipe is released under the MIT license.
