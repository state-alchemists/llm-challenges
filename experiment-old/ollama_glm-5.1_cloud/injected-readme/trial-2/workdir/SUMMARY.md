Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework targets mid-size data teams of 5–50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs and want a unified, maintainable alternative. Getting started is straightforward: install the core package with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. Datapipe is licensed under MIT, making it free to use and modify in any environment.
