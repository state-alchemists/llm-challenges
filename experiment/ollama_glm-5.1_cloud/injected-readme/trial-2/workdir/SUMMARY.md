Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without requiring custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The framework is aimed at mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and ad-hoc Python jobs to handle event volumes in the one-billion-plus daily range. Getting started is straightforward: install the core library with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. Datapipe replaces fragmented pipeline stacks with a single, performant system that handles delivery guarantees and connector orchestration out of the box.
