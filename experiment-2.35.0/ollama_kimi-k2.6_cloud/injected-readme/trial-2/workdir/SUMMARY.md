Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without forcing teams to write custom connector code. It ships with more than forty pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation DSL that compiles down to optimized Rust for high performance. The tool is built for mid-size data teams of five to fifty engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python scripts to handle event volumes exceeding one billion per day. Instead of maintaining fragile glue code, these teams can use Datapipe to stream, transform, and load data through a single, unified pipeline. Getting started is as simple as installing the core package with pip install datapipe-core. If you need every connector out of the box, you can install the full pack by adding the all extra. Datapipe replaces complex infrastructure with one reliable pipeline so you can spend less time on plumbing and more time turning data into value.
