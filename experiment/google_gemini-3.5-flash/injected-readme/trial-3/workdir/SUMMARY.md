Datapipe is an open-source, high-performance streaming ETL framework written in Rust with Python bindings, designed to streamline data pipelines. It empowers data engineers to move billions of events every day seamlessly between Kafka, S3, Postgres, and ClickHouse without having to write any custom connector code. The platform features over forty pre-built source and sink connectors, exactly-once delivery guarantees through two-phase commit, and an elegant declarative transformation language that compiles down to highly optimized Rust code. This solution is specifically designed for mid-sized data teams of five to fifty engineers managing massive event volumes who are looking to replace complex, fragmented setups of Airflow, Flink, and bespoke Python scripts. Getting started with Datapipe is extremely straightforward, requiring only a simple command to install datapipe-core via pip. For teams needing access to the complete suite of connectors, the entire pack can be installed easily by specifying the all-inclusive package option during installation.
