Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who move billions of events per day between Kafka, S3, Postgres, and ClickHouse. It removes the need to write custom connector code by shipping more than 40 pre-built source and sink connectors. Exactly-once delivery semantics, powered by two-phase commit, guarantee reliable processing at scale, and a declarative transformation DSL compiles down to optimized Rust for high performance. It is designed for mid-size data teams of roughly 5 to 50 engineers handling event volumes in the billion-plus events-per-day range, especially those currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward: run pip install datapipe-core, or pip install datapipe[all] for the full connector pack. Datapipe is MIT-licensed and free to use.
