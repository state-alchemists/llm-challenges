Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, aimed at data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with more than forty pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework is intended for mid-size data teams of five to fifty engineers handling event volumes above one billion per day, especially those currently juggling a mix of Airflow, Flink, and one-off Python scripts. Installation is simple: run `pip install datapipe-core` to get started, or install `datapipe[all]` for the complete connector pack. Datapipe is released under the MIT license.
