Datapipe is an open-source streaming ETL framework built in Rust with Python bindings. It enables data engineers to move billions of daily events between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The system features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically designed for mid-size data teams managing high event volumes who want to replace fragmented pipelines of Airflow and Flink. To get started, simply run pip install datapipe-core. For a comprehensive setup including all connectors, use pip install datapipe[all].
