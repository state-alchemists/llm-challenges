Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The tool is aimed at mid-size data teams of 5 to 50 engineers running event volumes in the billion-plus per day range who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. To install the core package, run pip install datapipe-core, or pip install datapipe[all] for the full connector pack. Datapipe is licensed under MIT.
