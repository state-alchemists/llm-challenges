Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who move billions of events each day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, so teams can stop writing custom glue code and focus on their data pipelines instead. The framework provides exactly-once delivery semantics through two-phase commit and a declarative transformation DSL that compiles down to optimized Rust for performance. It is built for mid-size data teams of five to fifty engineers handling event volumes in the billions-per-day range, especially those currently stitching together Airflow, Flink, and ad-hoc Python jobs. Installation is straightforward — run pip install datapipe-core for the base framework, or pip install datapipe for the full suite of connectors.
