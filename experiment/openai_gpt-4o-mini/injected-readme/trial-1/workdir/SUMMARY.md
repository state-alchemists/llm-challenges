Datapipe is an open-source streaming ETL framework designed for data engineers who need to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without custom connector code. It features over 40 pre-built source and sink connectors, ensures exactly-once delivery semantics through a two-phase commit, and includes a declarative transformation DSL that compiles to optimized Rust. Datapipe is ideal for mid-size data teams, typically with 5-50 engineers, managing over 1 billion events per day. To install, simply run 'pip install datapipe-core' for the core installation, or 'pip install datapipe[all]' for the full connector pack.
