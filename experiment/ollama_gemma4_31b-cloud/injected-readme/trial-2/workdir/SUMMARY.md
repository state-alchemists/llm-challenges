Datapipe is a powerful open-source streaming ETL framework built in Rust with convenient Python bindings. It is specifically designed for data engineers who need to move billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse. The tool eliminates the need for custom connector code by providing over 40 pre-built source and sink connectors. It is ideal for mid-size data teams managing high event volumes who want to replace fragmented pipelines with a single, optimized system. To get started, simply install the core package using pip install datapipe-core. For those requiring the full suite of connectors, the datapipe[all] installation is available.
