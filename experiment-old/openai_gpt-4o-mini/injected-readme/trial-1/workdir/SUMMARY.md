Datapipe is an open-source streaming ETL framework designed for data engineers needing to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without custom connector code. With over 40 pre-built source and sink connectors, it guarantees exactly-once delivery semantics through a two-phase commit. The framework includes a declarative transformation DSL that compiles into optimized Rust. It is particularly suitable for mid-size data teams of 5 to 50 engineers handling event volumes of over 1 billion events per day. Installation can be done using `pip install datapipe-core`, or for the full connector pack, use `pip install datapipe[all]`. Datapipe aims to replace the patchwork solutions currently maintained by its target users, such as Airflow, Flink, and custom Python jobs.
