Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that lets data engineers move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics backed by two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust. The framework is purpose-built for mid-size data teams of 5 to 50 engineers who are juggling a patchwork of Airflow, Flink, and bespoke Python jobs at the 1 billion events per day scale. Getting started is simple: just run pip install datapipe-core to get the core framework, or install datapipe with the all extras to unlock the full connector pack. With Datapipe, you replace fragile glue scripts with a single, reliable streaming pipeline that scales out of the box.
