Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, made for data engineers who need to reliably move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with more than 40 pre-built source and sink connectors, so you never have to write custom connector code from scratch. The framework guarantees exactly-once delivery semantics through two-phase commit and includes a declarative transformation DSL that compiles down to optimized Rust for high performance. It is purpose-built for mid-size data teams of five to fifty engineers who are currently juggling a mix of Airflow, Flink, and bespoke Python jobs to handle event volumes exceeding one billion per day. You can get started in seconds by running pip install datapipe-core in your terminal, or choose datapipe[all] if you want the complete connector pack. With Datapipe, you replace your patchwork of data tools with a single, streamlined platform that scales with your event volume. It is open source under the MIT license, so you can adopt it with confidence and contribute back as you grow.
