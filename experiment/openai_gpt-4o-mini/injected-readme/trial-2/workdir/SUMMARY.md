Datapipe is an open-source streaming ETL framework tailored for data engineers needing to transfer billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse without the complexity of custom connector development. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery through two-phase commits. It features a declarative transformation DSL, allowing users to create optimized Rust code effortlessly. Ideal for mid-sized data teams comprising 5 to 50 engineers, Datapipe is perfect for those currently juggling Airflow, Flink, and ad-hoc Python jobs while managing high event volumes exceeding one billion events per day. To install Datapipe, simply run 'pip install datapipe-core', or for the complete connector suite, use 'pip install datapipe[all]'. This framework offers a robust solution for organizations looking to streamline their data processing workflows.
