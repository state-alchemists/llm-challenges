Datapipe is an open-source streaming ETL framework, built with Rust and Python bindings, designed to help data engineers efficiently move massive volumes of event data. It provides over 40 pre-built connectors for popular data systems like Kafka, S3, Postgres, and ClickHouse, ensuring exactly-once delivery through a robust two-phase commit system. Datapipe also features a declarative transformation language that compiles into optimized Rust code, eliminating the need for custom connector development. This powerful solution is ideal for mid-sized data teams, typically 5-50 engineers, who manage over a billion events daily and currently rely on complex, disparate systems like Airflow, Flink, and custom Python scripts. To get started, simply install the core package using `pip install datapipe-core`, or `datapipe[all]` for the complete connector suite.
