Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and includes a declarative transformation DSL that compiles to optimized Rust for maximum throughput. The framework is designed for mid-size data teams of five to fifty engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs and want a simpler, unified alternative. Installation is straightforward — run pip install datapipe-core for the core framework, or pip install datapipe[all] to add every connector. Datapipe is licensed under MIT and ready for production use.
