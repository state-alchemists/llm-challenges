Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, purpose-built for data engineers moving over a billion events per day. It eliminates the need for custom connector code by shipping with more than 40 pre-built source and sink connectors, including Kafka, S3, Postgres, and ClickHouse. Datapipe guarantees exactly-once delivery through a two-phase commit protocol and provides a declarative transformation DSL that compiles down to optimized Rust for fast, predictable performance. It targets mid-size data teams of 5 to 50 engineers who currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Installation is straightforward — just run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` for the full suite of connectors. The framework is released under the MIT license, making it free to adopt and modify.
