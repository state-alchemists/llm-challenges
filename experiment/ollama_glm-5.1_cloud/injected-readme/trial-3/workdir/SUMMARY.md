Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for high performance. The framework targets mid-size data teams of 5 to 50 engineers handling 1B+ events per day who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Installing Datapipe is straightforward: run `pip install datapipe-core` for the core package, or `pip install datapipe[all]` for the full connector pack. By combining Rust-grade throughput with a Python-friendly interface, Datapipe eliminates the need to maintain fragile custom integrations and lets teams focus on data logic rather than infrastructure plumbing. The project is released under the MIT license.
