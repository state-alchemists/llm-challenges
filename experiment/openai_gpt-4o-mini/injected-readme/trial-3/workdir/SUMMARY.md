Datapipe is an open-source streaming ETL framework built in Rust, featuring Python bindings. It allows data engineers to efficiently transfer billions of events daily across platforms like Kafka, S3, Postgres, and ClickHouse without needing to write custom connector code. The framework includes over 40 pre-built connectors, ensures exactly-once delivery with two-phase commit, and offers a declarative transformation DSL that compiles to optimized Rust for performance. Datapipe targets mid-sized data teams, typically comprising 5 to 50 engineers, handling over a billion events per day, and replacing existing solutions like Airflow and Flink. To install Datapipe, use 'pip install datapipe-core'. For access to the complete set of connectors, install using 'datapipe[all]'. This project is licensed under the MIT License.
