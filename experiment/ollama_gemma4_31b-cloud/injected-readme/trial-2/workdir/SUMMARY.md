Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It allows data engineers to transfer billions of daily events between platforms like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform features over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is specifically designed for mid-size data teams managing massive event volumes who want to replace complex patches of Airflow, Flink, and custom scripts. To get started, simply install the core package using pip install datapipe-core. For a complete set of features, users can install the full connector pack via pip install datapipe[all].
