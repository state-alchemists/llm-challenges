Datapipe is an open-source streaming ETL framework built in Rust with Python bindings to enable seamless, ultra-fast data pipelines. The platform is designed to effortlessly transfer billions of events per day between Kafka, S3, Postgres, and ClickHouse without requiring any custom connector development. This robust framework is specifically tailored for mid-size data teams of five to fifty engineers who are currently managing a complex, fragmented patchwork of Airflow, Flink, and custom Python scripts. With over forty pre-built source and sink connectors, Datapipe provides guaranteed exactly-once delivery semantics through two-phase commits and a high-performance declarative transformation language. Getting started is simple, as data teams can quickly install the core package using the Python package installer command pip install datapipe-core. For teams requiring the complete set of connectors, the comprehensive installation package can be installed by running pip install datapipe with the all option.
