Datapipe is an open-source streaming ETL framework built in Rust, complete with Python bindings. It enables data engineers to efficiently transfer billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without needing to write custom connector code. Featuring over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery with two-phase commit semantics, along with a declarative transformation DSL that compiles to highly optimized Rust. It's primarily aimed at mid-sized data teams, typically comprised of 5 to 50 engineers, who manage event volumes exceeding 1 billion events per day and often rely on a combination of existing tools like Airflow and Flink. To get started with Datapipe, simply run the command 'pip install datapipe-core' to install the core framework, or use 'pip install datapipe[all]' for the full connector pack.
