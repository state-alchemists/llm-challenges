Datapipe is an open-source streaming ETL framework that empowers data teams to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse. Written in Rust with Python bindings, it eliminates the need for custom connector code by providing over forty pre-built source and sink connectors. The framework ensures reliable data processing with exactly-once delivery semantics powered by two-phase commit, alongside a declarative transformation language that compiles directly into high-performance Rust. It is specifically designed for mid-size data teams of five to fifty engineers who handle massive event volumes and are looking to replace their complex, fragmented mixtures of Airflow, Flink, and bespoke Python scripts. Setting up the framework is straightforward, requiring only a simple installation of the core package through the Python package manager. For teams requiring the full suite of integration features, the complete connector pack can be easily added to unlock the platform's full potential.
