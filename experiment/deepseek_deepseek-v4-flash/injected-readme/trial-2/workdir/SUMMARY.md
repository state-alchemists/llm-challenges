Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, engineered for data teams processing over one billion events per day. It is purpose-built for mid-size teams of five to fifty engineers who currently maintain a patchwork of Airflow, Flink, and custom Python jobs to move data between Kafka, S3, Postgres, and ClickHouse. With more than forty pre-built source and sink connectors, Datapipe eliminates the need to write custom connector code for most pipelines. It guarantees exactly-once delivery semantics through a two-phase commit protocol and includes a declarative transformation DSL that compiles down to optimized Rust for maximum throughput. To get started, install the core package with `pip install datapipe-core` or pull in the full connector suite with `pip install datapipe[all]`.
