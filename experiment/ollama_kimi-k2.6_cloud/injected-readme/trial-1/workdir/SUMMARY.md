Datapipe is an open-source streaming ETL framework built in Rust and available through Python bindings. It helps data engineering teams move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without having to write custom connector code. The framework includes more than forty pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation language that compiles down to optimized Rust. Datapipe is built for mid-size data teams with five to fifty engineers that are currently juggling a mix of Airflow, Flink, and custom Python scripts at event volumes exceeding one billion per day. You can get started by installing the core package with pip and then add the full connector pack if you need every integration. It is released under the MIT license.
