Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day across systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics through two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The project is aimed at mid-size data teams of 5 to 50 engineers handling 1B+ daily events who are currently juggling a patchwork of Airflow, Flink, and ad-hoc Python jobs. Getting started is straightforward — install the core library with pip install datapipe-core, or grab the full connector pack with datapipe[all]. Datapipe is released under the permissive MIT license, making it easy to adopt and extend for any organization.
