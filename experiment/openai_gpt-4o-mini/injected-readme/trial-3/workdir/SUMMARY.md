Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It is tailored for data engineers who need to efficiently transfer billions of events each day between platforms like Kafka, S3, Postgres, and ClickHouse, eliminating the need for custom connector code. With over 40 pre-built source and sink connectors, Datapipe ensures exactly-once delivery semantics through a two-phase commit process. It also features a declarative transformation DSL that compiles to optimized Rust for enhanced performance. To install, simply run 'pip install datapipe-core'. For access to the complete connector pack, use 'pip install datapipe[all]'. This framework is ideal for mid-size data teams managing high event volumes from existing tools like Airflow and Flink.
