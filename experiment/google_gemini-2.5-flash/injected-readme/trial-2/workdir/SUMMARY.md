Datapipe is an open-source streaming ETL framework, built in Rust with Python bindings, designed to help data engineers manage billions of events daily. It efficiently moves data between various systems like Kafka, S3, Postgres, and ClickHouse without requiring custom connector development. The project offers over 40 pre-built source/sink connectors, guarantees exactly-once delivery through two-phase commit, and uses a declarative transformation language that compiles to optimized Rust. This solution is ideal for mid-size data teams, typically 5-50 engineers, who process more than a billion events daily and aim to streamline complex data pipelines currently reliant on tools like Airflow, Flink, or custom Python jobs. Installation is straightforward via pip: `pip install datapipe-core`, with an option for `datapipe[all]` to include the complete connector suite.
