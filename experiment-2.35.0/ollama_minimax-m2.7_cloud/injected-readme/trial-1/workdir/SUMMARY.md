Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it possible to connect to popular data systems out of the box. The framework provides exactly-once delivery semantics using a two-phase commit protocol, ensuring data integrity even in distributed environments. A declarative transformation DSL compiles to optimized Rust, giving users both ease of use and high performance. To install the core package, run pip install datapipe-core, or install the full connector pack with pip install datapipe[all]. Datapipe targets mid-size data teams of 5 to 50 engineers processing one billion or more events daily who currently rely on a mix of Airflow, Flink, and custom Python jobs.
