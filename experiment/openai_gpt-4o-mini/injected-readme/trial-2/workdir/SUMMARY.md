Datapipe is an open-source streaming ETL framework designed for data engineers who need to efficiently move billions of events per day between systems such as Kafka, S3, Postgres, and ClickHouse without custom connector development. It boasts over 40 pre-built source and sink connectors, ensures exactly-once delivery through a two-phase commit mechanism, and features a declarative transformation DSL that compiles into optimized Rust. Suitable for mid-sized data teams of 5 to 50 engineers handling event volumes exceeding 1 billion events per day, Datapipe alleviates the complexities of managing fragmented solutions like Airflow, Flink, and custom Python jobs. To install, simply run 'pip install datapipe-core', or for the complete connector package, use 'pip install datapipe[all]'.
