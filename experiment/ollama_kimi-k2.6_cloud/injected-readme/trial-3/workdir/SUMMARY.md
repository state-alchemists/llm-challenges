Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with more than forty pre-built source and sink connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation language that compiles to optimized Rust. The project is aimed at mid-sized data teams of five to fifty engineers who are already handling over a billion events daily and want to stop maintaining a patchwork of Airflow, Flink, and one-off Python jobs. Getting started is simple: install the core package with pip, or choose the full connector pack if you need the complete integration suite. With Datapipe, teams can focus on building reliable data pipelines instead of stitching together infrastructure.
