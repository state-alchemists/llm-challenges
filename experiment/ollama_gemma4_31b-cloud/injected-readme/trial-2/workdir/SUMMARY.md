Datapipe is a powerful open-source streaming ETL framework built in Rust with Python bindings for maximum performance. It is specifically designed for data engineers who need to move billions of events daily between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The platform provides over 40 pre-built connectors and ensures exactly-once delivery semantics. It is ideal for mid-size data teams looking to replace a patchwork of fragmented tools with a single, optimized system. To get started, simply install the core package using pip install datapipe-core. For users needing the full suite of connector packs, the datapipe[all] installation is available.
