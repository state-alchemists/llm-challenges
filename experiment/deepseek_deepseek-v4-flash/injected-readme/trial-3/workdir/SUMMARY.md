Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It moves billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with 40+ pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. It is built for mid-size data teams of 5 to 50 engineers running event volumes of a billion or more events per day who currently maintain a patchwork of Airflow, Flink, and bespoke Python jobs. To get started, install the core package with pip install datapipe-core, or install datapipe[all] for the full connector pack. The project is licensed under MIT.
