Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust for maximum throughput. The framework targets mid-size data teams of 5–50 engineers handling billion-plus daily event volumes—especially those currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is a single command: pip install datapipe-core gives you the core runtime, while datapipe[all] adds the full connector pack so you can start moving data right away. Datapipe is MIT-licensed, free for both open-source and commercial use.
