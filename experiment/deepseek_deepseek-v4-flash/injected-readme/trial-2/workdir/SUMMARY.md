Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built to move billions of events per day between Kafka, S3, Postgres, and ClickHouse. It ships with more than 40 pre-built source and sink connectors, so most teams never have to write custom connector code. Datapipe guarantees exactly-once delivery through two-phase commit semantics, and its declarative transformation DSL compiles down to optimized Rust for high performance. It is designed for mid-size data teams of roughly 5 to 50 engineers who process over a billion events per day and currently juggle a patchwork of Airflow, Flink, and bespoke Python jobs. Getting started takes a single command: pip install datapipe-core, with the full connector pack available via datapipe[all]. The project is released under the MIT license.
