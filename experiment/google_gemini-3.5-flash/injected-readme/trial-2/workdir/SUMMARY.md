Datapipe is an open-source streaming ETL framework written in Rust with Python bindings. It allows users to effortlessly move billions of events per day between Kafka, S3, Postgres, and ClickHouse without having to write custom connector code. The platform features over forty pre-built source and sink connectors, ensures exactly-once delivery semantics via two-phase commit, and offers a declarative transformation DSL that compiles to optimized Rust. This tool is built specifically for mid-size data teams of five to fifty engineers managing event volumes in the range of billions of events per day. It serves as an elegant replacement for teams currently maintaining a fragile patchwork of Airflow, Flink, and bespoke Python jobs. Getting started is simple, as you can easily install the core framework by running pip install datapipe-core, or obtain the full connector pack by running pip install datapipe with the all extra option.
