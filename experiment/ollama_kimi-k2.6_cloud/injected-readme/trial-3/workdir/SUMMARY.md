Datapipe is an open-source streaming ETL framework that helps data engineers move billions of events every day between systems like Kafka, S3, Postgres, and ClickHouse — all without writing custom connector code. Built in Rust with Python bindings, it combines high performance with the flexibility that data teams already know. The framework includes more than 40 ready-made connectors, exactly-once delivery guarantees, and a declarative transformation language that compiles down to optimized Rust. It is purpose-built for mid-sized data teams of five to fifty engineers who are currently juggling Airflow, Flink, and one-off Python scripts to keep their pipelines running. Getting started is simple: install the core package with pip, or choose the full connector pack for complete coverage out of the box. Datapipe replaces fragile patchwork infrastructure with a single, reliable platform designed for serious scale.
