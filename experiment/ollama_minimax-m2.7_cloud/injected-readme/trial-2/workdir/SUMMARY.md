Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It includes over 40 pre-built source and sink connectors out of the box, along with exactly-once delivery semantics powered by a two-phase commit protocol. The framework features a declarative transformation DSL that compiles to optimized Rust, giving teams the ease of a Python API with the performance of a compiled systems language. Datapipe targets mid-size data teams of five to fifty engineers processing one billion or more events daily, replacing patchwork stacks of Airflow, Flink, and bespoke Python jobs. Installation is straightforward via pip for the core package, with a full connector pack available through the all-inclusive distribution. The project is open-source under an MIT license.
