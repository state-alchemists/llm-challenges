Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data engineers move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so teams can connect their data infrastructure out of the box rather than building integrations from scratch. Datapipe guarantees exactly-once delivery through a two-phase commit mechanism, ensuring data integrity even in distributed, high-throughput environments. The framework includes a declarative transformation DSL that compiles to optimized Rust, giving engineers a productive way to express data transformations while still getting Rust-level performance. Installation is straightforward: a single pip command installs the core package, and an optional extra installs the full connector pack for teams that need broader platform support. Datapipe targets mid-size data teams of five to fifty engineers handling event volumes in the billions per day, who currently juggle a mix of tools like Airflow, Flink, and custom Python jobs. It is published under the MIT license, making it free for commercial use and easy to integrate into existing data stacks.
