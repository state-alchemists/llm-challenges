Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to seamlessly move billions of daily events between Kafka, S3, Postgres, and ClickHouse. It eliminates the need for custom connector code by providing over forty pre-built source and sink connectors out of the box. With exactly-once delivery semantics and a declarative transformation language that compiles directly to optimized Rust, the platform guarantees both reliability and maximum performance. This solution is specifically designed for mid-sized data teams of five to fifty engineers managing massive event volumes who want to replace a complex patchwork of Airflow, Flink, and custom Python scripts. To get started, you can easily install the core package using the Python package manager by running pip install datapipe-core. For teams requiring the full suite of connectors, installing the package with the all option is recommended.
