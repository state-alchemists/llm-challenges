Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, purpose-built for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, delivers exactly-once processing guarantees through two-phase commit, and includes a declarative transformation DSL that compiles down to optimized Rust for production performance. Datapipe is designed for mid-size data teams of 5 to 50 engineers running event volumes in the billions-per-day range, helping them replace fragile patchworks of Airflow, Flink, and bespoke Python jobs with a single coherent pipeline framework. Installation is straightforward via pip: run `pip install datapipe-core` for the core library, or `pip install datapipe[all]` to include the full connector pack. The project is licensed under MIT and welcomes contributions from the open-source community.
