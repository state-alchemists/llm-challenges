Datapipe is an open-source streaming ETL framework written in Rust with convenient Python bindings. It empowers data engineers to move billions of events per day seamlessly between Kafka, S3, Postgres, and ClickHouse without the hassle of writing custom connector code. With over forty pre-built source and sink connectors, exactly-once delivery guarantees, and a declarative transformation language that compiles directly to optimized Rust, it delivers both reliability and high performance. This solution is specifically designed for mid-size data teams of five to fifty engineers managing massive event volumes who are looking to replace their fragmented pipeline architectures with a unified framework. Setting up Datapipe is fast and simple; you can install the core framework by running pip install datapipe-core, or get the entire connector package using pip install datapipe[all].
