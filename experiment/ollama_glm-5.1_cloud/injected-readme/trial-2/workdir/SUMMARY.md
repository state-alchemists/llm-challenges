Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, purpose-built for moving billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles down to optimized Rust for high throughput. The project targets mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs at event volumes exceeding one billion events per day. Getting started is straightforward: install the core library with pip install datapipe-core, or pull in the full connector pack with datapipe[all] for all available integrations. Datapipe is licensed under the MIT license, making it free to use and modify in any project.
