Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, exactly-once delivery semantics via two-phase commit, and a declarative transformation DSL that compiles to optimized Rust. The target audience is mid-size data teams of 5 to 50 engineers handling event volumes in the billion-per-day range who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip for the core package, with a full connector pack available through a single extra. The project is open-source under the MIT license.
