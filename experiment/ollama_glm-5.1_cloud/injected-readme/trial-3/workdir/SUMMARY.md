Datapipe is an open-source streaming ETL framework built in Rust with Python bindings that helps data engineers move billions of events per day across Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, so you can wire up common data pipelines in minutes instead of weeks. Exactly-once delivery semantics powered by two-phase commit give you the confidence that no event is lost or duplicated in transit. A declarative transformation DSL compiles down to optimized Rust, letting you express complex data reshaping logic without sacrificing throughput. Datapipe is designed for mid-size data teams of 5 to 50 engineers who are currently juggling a patchwork of Airflow, Flink, and bespoke Python jobs to handle event volumes in the billion-per-day range. Getting started is straightforward: install the core library with pip install datapipe-core, or grab the full connector pack with pip install datapipe[all]. The project is released under the MIT license, so you can use and extend it freely in any environment.
