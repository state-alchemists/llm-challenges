Datapipe is an open-source streaming ETL framework built in Rust and accessible through Python bindings, purpose-built to move massive volumes of data between systems like Kafka, S3, Postgres, and ClickHouse without requiring engineers to write custom connector code. It ships with more than forty pre-built connectors, guarantees exactly-once delivery through two-phase commit, and offers a declarative transformation DSL that compiles to optimized Rust. The framework is aimed at mid-sized data teams of five to fifty engineers who process over a billion events per day and currently maintain a fragile mix of Airflow, Flink, and bespoke Python jobs. Rather than managing brittle patchwork pipelines, these teams can centralize their streaming workloads under one reliable, high-performance system. Getting started is simple: run pip install datapipe-core for the essentials, or install datapipe with the all extras flag to unlock the complete connector pack. From ingesting real-time events to loading analytics warehouses, Datapipe helps you operate at scale with minimal operational overhead.
