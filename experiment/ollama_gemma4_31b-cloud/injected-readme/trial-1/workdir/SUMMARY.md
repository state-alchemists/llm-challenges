Datapipe is an open-source streaming ETL framework that simplifies moving billions of events daily between platforms like Kafka, S3, Postgres, and ClickHouse. Built with Rust and featuring Python bindings, it eliminates the need for custom connector code. The platform provides over 40 pre-built connectors and ensures exactly-once delivery via two-phase commit. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented workflows. Users can leverage a declarative transformation DSL that compiles to highly optimized Rust code. To get started, simply run pip install datapipe-core. For full access to all connectors, install the package using pip install datapipe[all].
