Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed to help data teams move billions of events daily between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It comes with over 40 pre-built connectors, exactly-once delivery guarantees through two-phase commit, and a declarative transformation language that compiles down to optimized Rust. Datapipe is built for mid-size data teams of 5 to 50 engineers who are currently juggling Airflow, Flink, and custom Python scripts to handle event volumes exceeding one billion per day. You can get started quickly by installing the core package with pip, or choose the full installation to unlock every available connector. Whether you are replacing a fragile patchwork of legacy tools or scaling up your streaming pipelines, Datapipe gives you the performance of Rust with the familiarity of Python. It is released under the MIT license.
