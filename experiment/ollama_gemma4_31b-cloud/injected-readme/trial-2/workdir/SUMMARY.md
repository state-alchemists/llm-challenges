Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for high-performance data movement. It is designed for data engineers who need to move billions of events per day between Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework provides over 40 pre-built connectors, exactly-once delivery semantics, and a declarative transformation DSL. It is ideal for mid-size data teams managing event volumes of one billion or more per day who want to replace complex patches of Airflow, Flink, and bespoke Python jobs. To get started, simply run pip install datapipe-core. For access to the full connector pack, use the pip install datapipe[all] command.
