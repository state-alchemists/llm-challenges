Datapipe is an open-source streaming ETL framework developed in Rust with Python bindings, tailored for data engineers tasked with transferring billions of events daily among data systems like Kafka, S3, Postgres, and ClickHouse. It features over 40 pre-built connectors, ensures exactly-once delivery through two-phase commits, and includes a declarative transformation DSL optimized for performance. Ideal for mid-sized data teams of 5-50 engineers managing over one billion events per day, Datapipe simplifies the complexities of ETL workflows, replacing a patchwork of tools such as Airflow and Flink. Installation is straightforward: users can install the core package with 'pip install datapipe-core', and for full capabilities, the complete connector pack is available via 'datapipe[all]'.
