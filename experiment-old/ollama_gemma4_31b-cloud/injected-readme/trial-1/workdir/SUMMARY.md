Datapipe is an open-source streaming ETL framework built in Rust with Python bindings for maximum performance. It enables data engineers to move billions of events daily between services like Kafka, S3, Postgres, and ClickHouse without the need for custom connector code. The platform provides over 40 pre-built connectors, a declarative transformation DSL, and guaranteed exactly-once delivery. It is specifically designed for mid-size data teams managing massive event volumes who want to replace fragmented pipelines with a unified system. To get started, simply install the core library using pip install datapipe-core. For users requiring the full suite of connectors, the datapipe[all] package is available.
