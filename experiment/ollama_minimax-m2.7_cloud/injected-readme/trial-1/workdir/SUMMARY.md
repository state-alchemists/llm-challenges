Datapipe is an open-source streaming ETL framework built in Rust with Python bindings, designed for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. It ships with over 40 pre-built source and sink connectors, making it easy to connect to common data infrastructure out of the box. The framework provides exactly-once delivery semantics using a two-phase commit protocol, ensuring data integrity even in distributed environments. A declarative transformation DSL compiles to optimized Rust, giving users both developer productivity and high runtime performance. Datapipe is aimed at mid-sized data teams of five to fifty engineers handling a billion or more events daily who currently rely on a patchwork of tools like Airflow, Flink, and custom Python jobs. Installation is straightforward via pip, with a core package available as `datapipe-core` or a full connector pack using `datapipe[all]`.
