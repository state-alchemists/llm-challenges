Datapipe is an open-source streaming ETL framework built in Rust and wrapped with Python bindings, made for data engineers who need to move billions of events every day. It connects Kafka, S3, Postgres, and ClickHouse out of the box with more than forty pre-built connectors, so you never have to write custom connector code. Exactly-once delivery via two-phase commit keeps your pipelines reliable, while a declarative transformation DSL compiles down to optimized Rust for maximum performance. If you are part of a mid-sized data team juggling Airflow, Flink, and one-off Python scripts, Datapipe is designed for you. Getting started is as simple as running pip install datapipe-core. For the complete connector suite, install datapipe with the all extras.
