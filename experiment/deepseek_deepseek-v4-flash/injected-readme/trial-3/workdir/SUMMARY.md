Datapipe is an open-source streaming ETL framework written in Rust with Python bindings, built for data engineers who need to move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse. It ships with over 40 pre-built source and sink connectors, offers exactly-once delivery semantics through two-phase commit, and provides a declarative transformation DSL that compiles down to optimized Rust. Installation is straightforward — run `pip install datapipe-core` for the core library, or `pip install datapipe[all]` to include every connector. The framework is designed for mid-size data teams of 5 to 50 engineers who currently manage a patchwork of Airflow, Flink, and custom Python jobs. Its goal is to eliminate the need for writing bespoke connector code at high event volumes. Datapipe is licensed under the MIT license.
