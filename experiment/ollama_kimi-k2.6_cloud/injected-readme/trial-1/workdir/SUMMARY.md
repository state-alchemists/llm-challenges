Datapipe is an open-source streaming ETL framework built in Rust and exposed through Python bindings. It helps data engineers reliably move billions of events per day between systems like Kafka, S3, Postgres, and ClickHouse without writing custom connector code. The framework includes over forty pre-built source and sink connectors, exactly-once delivery semantics powered by two-phase commit, and a declarative transformation language that compiles down to optimized Rust. It is built for mid-sized data teams of five to fifty engineers handling event volumes exceeding one billion per day and struggling with fragmented combinations of Airflow, Flink, and custom Python scripts. You can get started quickly by installing datapipe-core with pip, or choose the full datapipe package with the all extra to unlock the complete connector pack. Datapipe simplifies large-scale streaming pipelines by replacing brittle bespoke jobs with a unified, high-performance platform.
